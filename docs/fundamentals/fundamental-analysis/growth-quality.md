# 成长与质量

## 一句话理解
成长看"跑得多快"，质量看"底盘有多稳"——最好的公司是既快又稳，成长与质量兼顾。

## 核心内容

### 成长的度量

| 指标 | 公式 | 看什么 |
|------|------|--------|
| 营收增速 | 本期营收 ÷ 上期 - 1 | 需求真实增长，最难造假 |
| 净利润增速 | 本期净利 ÷ 上期 - 1 | 赚钱能力的扩张 |
| 复合增速（CAGR） | 多年增速的几何平均 | 剔除单年基数效应 |
| 利润增速 - 营收增速 | 两者之差 | 经营杠杆与利润率变化 |

要区分**有机增长**（靠自身经营）与**并购/资本堆积增长**——靠不断发债并购撑起的营收，质量与可持续性都差。

### 自由现金流：质量的试金石
自由现金流 = 经营现金流 - 资本开支。它是公司能自由分配给股东的钱，是"赚钱机器"判断与 DCF 估值的核心。

| 情形 | 解读 |
|------|------|
| 净利润高 + 自由现金流低 | 利润可能是"纸面富贵"，钱没真到手 |
| 自由现金流稳定为正 | 真造血，可分红/回购/再投资 |
| 持续负现金流 | 烧钱扩张，需融资输血，风险高 |

### 护城河：可持续的超额利润
护城河是公司维持高盈利的能力来源：

| 类型 | 例子 | 验证方式 |
|------|------|----------|
| 品牌 | 高端消费品 | 高毛利率 + 定价权 |
| 网络效应 | 社交、支付平台 | 用户越多越有价值 |
| 转换成本 | 企业软件 | 客户流失率低 |
| 成本优势 | 规模制造、资源垄断 | 毛利率高于同行且稳定 |
| 牌照/特许权 | 公用事业、券商 | 政策壁垒 |

**ROE 长期高位**往往是护城河的最简验证：如果高 ROE 持续 5-10 年且无需高杠杆，大概率存在壁垒。

## 对量化交易的意义
- **成长因子**与**质量因子**是多因子模型的常客：先质量筛选（高 ROE、低杠杆、现金流好）再按成长排序，能有效规避"高增长陷阱"
- 自由现金流收益率（FCF ÷ 市值）是高质量价值因子的优选指标
- 营收增速的**超预期**（相对分析师预期）是事件驱动策略的核心信号
- 成长股对利率极度敏感——折现率高企时，远期利润缩水，成长股首先杀估值

## 常见误区
- <span class="qw-no">✕</span> 只看利润增速、不看营收增速——利润可被裁员/一次性收益美化，营收更难
- <span class="qw-no">✕</span> 把"高增长"当护城河——没有壁垒的高增长终会均值回归
- <span class="qw-no">✕</span> 忽视增长的质量——负债推动的增长和自由现金流支撑的增长完全不同
- <span class="qw-ok">✓</span> 成长、质量、估值三角验证：又快、又稳、又便宜才是好标的
