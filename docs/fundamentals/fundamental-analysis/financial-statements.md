# 三张财务报表

## 一句话理解
上市公司的财务状况由三张表刻画：资产负债表看"家底"，利润表看"赚了多少"，现金流量表看"钱到底到没到手"。

<PlainTalk>把公司想象成一个开包子铺的老板：资产负债表是体检单——铺子、存款、欠供应商的钱一目了然；利润表是记账本——这个月卖了多少钱、剩了多少；现金流量表是钱包——账本上说赚了两万，可钱到底真落到手里没有，只有翻钱包才知道。三个本子对不上号的时候，往往就藏着问题。</PlainTalk>

## 核心内容

### 三张表各管什么

| 报表 | 回答的问题 | 核心恒等式 | 关键科目 |
|------|------------|------------|----------|
| 资产负债表 | 此刻拥有什么、欠什么 | 资产 = 负债 + 所有者权益 | 现金、存货、应收、有息负债 |
| 利润表 | 一段时间内赚了多少 | 收入 - 成本 - 费用 = 净利润 | 营收、毛利、三费、净利润 |
| 现金流量表 | 钱实际进出如何 | 经营 + 投资 + 筹资 = 净变动 | 经营现金流、资本开支、自由现金流 |

### 三张表的流转关系
利润表"赚的钱"不等于现金流——利润是**权责发生制**（按权属确认收入），现金是**收付实现制**（按实际收到确认）。三张表的勾稽关系如下：

### 利润与现金的背离
- **应收账款暴增**：收入确认了但钱没收到，利润"虚胖"
- **存货堆积**：货物卖不动，现金被锁在仓库
- **折旧摊销**：非现金费用，压低利润但不流出现金

判断盈利质量的关键就是：**净利润能否被经营现金流印证**。

### 生活化案例：老王包子铺的三张表

老王开了家包子铺，一年卖包子收入 **100 万元**（示意数据）。三张表各说各话：

- **利润表**：扣除面粉、肉馅、房租和人工 **80 万元**，净利润 **20 万元**——看着赚了不少。
- **资产负债表**：这 20 万利润其实多是「白条」——机关食堂订了 **30 万元**包子还没付钱（应收账款），账上真金白银只剩 **2 万元**现金。
- **现金流量表**：经营现金流是 **-15 万元**——货发了、钱没回，还得垫钱进货，老王只能去借钱周转。

第二年食堂欠款继续拖，老王把结算方式改成「先付定金再供货」，现金流才转正。财报上利润照样 20 万，但公司从「纸面富贵」变成「真造血」，估值完全不同。量化上这就是「净利润高 + 自由现金流低」的盈利质量警示——应收暴增、存货堆积都要拉响警报。

### 真实案例：康美药业财务造假监管处罚（2020 年）

**公开事实**

中国证监会《行政处罚决定书〔2020〕24 号》认定，康美药业披露的 2016 年年报、2017 年年报、2018 年半年报和 2018 年年报存在虚假记载，包括虚增营业收入、利息收入和营业利润；相关期间还存在虚增货币资金，2018 年年报另有虚增固定资产、在建工程和投资性房地产等事项。这里采用监管机关认定的事实，不对相关人员动机作推断。

**怎么读**

这类问题不能只靠利润表发现。收入和利润上升时，要从资产负债表检查应收账款、货币资金及新增资产是否匹配，再从现金流量表检查销售回款与经营现金流能否印证。证监会列示的证据还包括账簿、发票、税务信息、银行流水和对账单，说明交叉验证应延伸到报表附注与外部凭证。

**不要误读**

三表勾稽异常是需要继续核查的信号，不是对任何公司的自动“造假判定”；现金流也并非绝对不能被操纵。结论应以审计、监管调查和可核验凭证为准。案例不构成投资建议。

**资料来源**

- [中国证监会行政处罚决定书〔2020〕24 号](http://www.csrc.gov.cn/csrc/c101928/c1042341/content.shtml)

## 对量化交易的意义
- 基本面量化（多因子）最核心的数据源就是三张表——价值、质量、成长因子都由它们衍生
- **盈利质量因子**（应计利润、现金流利润率）常作为质量的代理变量
- 财务数据按季发布，做基本面量化要处理**滞后性**与**预期差**：实际值 vs 分析师预期才是股价催化剂
- 警惕造假信号：应收账款/营收异常升高、经营现金流长期远低于净利润

## 常见误区
- <span class="qw-no">✕</span> 只看净利润不看现金流——利润可被会计手段修饰，现金流更难造假
- <span class="qw-no">✕</span> 只看单季度同比，不看环比与存货/应收的联动
- <span class="qw-no">✕</span> 把"利润增长"直接等同于"价值增长"——还要看增长消耗了多少资本
- <span class="qw-ok">✓</span> 三张表要合起来读，单看任何一张都可能误判
