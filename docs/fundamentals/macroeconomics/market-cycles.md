# 市场周期

## 一句话理解
市场不会只涨不跌、也不会只跌不涨——它沿着"复苏 → 过热 → 滞胀 → 衰退"的规律循环，不同阶段有不同资产和板块占优。量化要识别自己处在周期的哪个位置。

## 核心内容

### 牛熊的基本结构
- **牛市**：经济与盈利上行 + 资金宽松，风险偏好回升，估值扩张
- **熊市**：盈利下修 + 流动性收紧，估值收缩，负反馈杀跌
- 牛熊转折的信号常是**利率拐点、信贷周期、估值极端值**三者共振

| 阶段 | 典型特征 | 市场状态 |
|------|----------|----------|
| 初升段 | 估值极低、流动性转松 | 底部放量，价值股先启动 |
| 主升段 | 盈利 + 估值双击 | 普涨，动量策略表现最佳 |
| 顶部段 | 情绪亢奋、估值极端 | 波动放大，散户涌入 |
| 下跌段 | 流动性收紧、盈利下修 | 防御板块抗跌 |
| 底部段 | 悲观到极致、成交萎缩 | 缩量筑底，反转信号出现 |

### 美林时钟

### 板块轮动的规律

| 周期阶段 | 占优板块 | 逻辑 |
|----------|----------|------|
| 复苏 | 周期股（地产、有色、制造） | 盈利弹性最大 |
| 过热 | 资源股、能源 | 通胀受益 |
| 滞胀 | 公用事业、必需消费 | 防御属性 |
| 衰退 | 债券、高股息 | 避险 + 利率下行 |

## 对量化交易的意义
- **周期择时**可作趋势/宏观因子的叠加：衰退末期加仓成长、过热期降低仓位
- 风格轮动（价值/成长、大盘/小盘）与利率周期强相关——可建模风格因子暴露
- 美林时钟是"自上而下"的配置框架，可落地为行业 ETF 轮动策略
- 周期判断要**容忍滞后**——拐点只能事后确认，用"概率权重"而非"二元判断"来配仓

## 常见误区
- <span class="qw-no">✕</span> 认为"这次不一样"——人性不变，周期会迟到但不会缺席
- <span class="qw-no">✕</span> 用美林时钟刻舟求剑——时钟会顺时针也可能逆转（如滞胀直接转入衰退）
- <span class="qw-no">✕</span> 把"长期主义"当作扛单借口——趋势反转时执行止损也是纪律的一部分
- <span class="qw-ok">✓</span> 周期是"大概率倾向"而非"精确日历"——用组合管理应对不确定性
