# 地缘政治与黑天鹅

## 一句话理解
地缘政治事件（战争、制裁、选举）和黑天鹅（极小概率、极大冲击）无法精确预测，但它们的冲击模式是可研究、可对冲的——量化要做的是"预案"而不是"预测"。

<PlainTalk>黑天鹅就像地震：没人能提前算出哪天、几点震，但住在断层带的人早就买了保险、加固了房子。量化应对地缘事件也是同一套思路——不去猜哪个国家哪天开战、哪条制裁落地，而是提前给组合装好「保险」：单票仓位设上限、平时留足现金、买点虚值看跌期权当「地震险」。预案备好了，真震起来才不至于慌到在最底部割肉离场。</PlainTalk>

## 核心内容

### 事件的类型与冲击路径

| 类型 | 代表 | 主要冲击 |
|------|------|----------|
| 战争/冲突 | 地缘冲突 | 能源、贵金属大涨，风险资产普跌 |
| 制裁/贸易壁垒 | 出口管制、关税 | 特定行业供应链重估 |
| 大选/政策突变 | 大选、政策急转弯 | 政策敏感板块剧烈波动 |
| 金融黑天鹅 | 雷曼、瑞信事件 | 信用紧缩，流动性危机 |
| 公共卫生 | 疫情 | 需求休克，风格剧烈切换 |

### 黑天鹅的共性特征
1. **极小概率**：历史数据几乎无法建模，尾部风险被系统性低估
2. **极大冲击**：单日波动远超正态分布假设
3. **事后可解释**：发生后总是"早有征兆"，事前却没人当真

### 传导机制
地缘冲击通常经过三层传导：
- **第一层 · 情绪**：避险资产（黄金、国债、日元、美元）飙升，风险资产急跌——最快，但常是脉冲
- **第二层 · 供应链**：制裁/断供改变实际供需，影响持续数月——能源、粮食、芯片
- **第三层 · 政策**：央行被迫调整政策（如能源危机下的通胀应对）——决定中期方向

### 生活化案例：一次「模拟」关税冲击演习

小张管理一笔模拟盘（示意数据），组合里 40% 是出口板块。某天新闻突然爆出两大经济体互相加征关税，市场瞬间炸开：

1. **情绪层（当天）**：黄金、国债应声上涨，出口股开盘跌 **5%**，组合单日回撤 **3%**。小张按预案先砍了 10% 仓位，没有追跌。
2. **供应链层（随后几周）**：关税落地，出口企业成本上升、盈利预期下修，股价继续阴跌。他事先埋的虚值看跌期权开始兑现，对冲掉大部分亏损。
3. **政策层（数月后）**：央行表态降息托底，内需消费板块反弹，组合逐步回血。

整个过程他并没有「预测」到关税事件，但「集中度上限 + 期权保险 + 熔断止损」的预案让他最坏回撤控制在 **6%**；同期满仓不设防的模拟账户回撤超过了 **20%**。预案，永远好过预测。

## 对量化交易的意义
- 量化模型天然**轻视尾部风险**——正态分布假设在黑天鹅日会崩塌，回测中的最大回撤常被低估
- 应对框架：**持仓集中度上限、压力测试（最坏 3-5 天假设）、波动率目标、VIX 对冲**
- 期权是黑天鹅对冲的主要工具：买入远月虚值 Put 相当于给组合买"尾部保险"
- 事件后的情绪脉冲与均值回归可被量化捕获，但要设置极端行情下的熔断式止损

## 常见误区
- <span class="qw-no">✕</span> 认为"模型没回测过的事件不会发生"——黑天鹅恰恰发生在模型盲区
- <span class="qw-no">✕</span> 满仓单一市场——地缘冲击往往是区域性的，跨市场分散能显著降低伤害
- <span class="qw-no">✕</span> 恐慌时手动干预策略——情绪化离场往往卖在最低点
- <span class="qw-ok">✓</span> 预案优于预测：先定义"什么情况发生我会怎么办"，而不是试图猜中事件
