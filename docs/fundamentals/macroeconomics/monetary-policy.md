# 货币政策

## 一句话理解
货币政策是央行调控"钱的价格和数量"的工具箱——通过调节利率与流动性影响经济冷热，进而牵动所有资产价格。

<PlainTalk>货币政策就是央行握在手里的一把「水龙头」：经济太热，就拧紧龙头（加息、缩表），让市场里的钱变少、变贵，给需求降温；经济太冷，就开大龙头（降息、降准、QE），让钱变多、变便宜，把需求浇活。所有资产都泡在这池水里——放水时水涨船高，股债同涨；收水时水位下降，估值集体承压。量化真正盯的不是水龙头今天拧了几度，而是市场「预期」下一步往哪拧——预期差才是价格跳动的直接引擎。</PlainTalk>

## 核心内容

### 四大工具

| 工具 | 操作 | 传导逻辑 | 通俗理解 |
|------|------|----------|----------|
| 加息/降息 | 调整政策利率（如联邦基金利率） | 利率↑ → 借贷成本↑ → 需求降温 | 拧紧水龙头 |
| 降准 | 降低存款准备金率 | 银行可放贷资金↑ → 信用扩张 | 让银行多放贷 |
| 公开市场操作 | 买卖国债投放/回笼资金 | 短期流动性调节 | 日常"滴灌" |
| QE / 缩表 | 央行大规模购债 / 卖出回收 | 直接压低 / 抬升长端利率 | 超大剂量放水 / 收水 |

### 加息与降息周期
货币政策是**逆周期**的：经济过热时加息降温，衰退时降息刺激。利率是估值的"地心引力"，资产价格随利率反向波动。

| 阶段 | 政策 | 对资产的影响 |
|------|------|--------------|
| 加息周期 | 紧缩 | 债券跌、成长股承压、美元走强、黄金承压 |
| 降息周期 | 宽松 | 债券涨、成长股反弹、风险偏好回升 |
| 量化宽松（QE） | 放水 | 股债双牛，新兴市场受益 |
| 缩表（QT） | 收水 | 流动性收紧，估值全面承压 |

### 什么是 QE 与缩表
- **QE（量化宽松）**：央行直接在市场上买入国债等资产，向金融体系注入天量资金、压低长期利率。它不是把钞票发给个人，而是先把资金注入银行体系，再经由信贷传导到实体。
- **缩表**：QE 的反向操作，卖出或不再续买到期的债券，从体系里抽走流动性。

### 降准与降息的区别

| | 降准 | 降息 |
|--|------|------|
| 影响什么 | 货币供应量（数量） | 资金价格（利率） |
| 传导速度 | 较慢，经银行信贷 | 较快，直接改变负债成本 |
| 典型场景 | 中小银行流动性紧张 | 经济明显下行 |

### 生活化案例：降息那晚，小李家发生了什么

假设央行把基准利率下调 0.25%（示意数据），从一个普通家庭看全链条：

- 小李的房贷月供从 **6000 元**降到 **5700 元**，每月多出 300 元结余，他顺手加仓了成长型基金。
- 小李开的奶茶公司融资成本下降，扩张意愿回升，多招了两名店员——消费与就业都被「便宜的钱」托了一把。
- 同一时间，远期利润的折现值抬升，成长股反弹最猛；债券价格上涨，储蓄存款利率下降。

反过来，加息周期启动时，同样的链条倒着走一遍，成长股最先被「估值的地心引力」按下去。

量化启示：**利率是跨资产的锚**——盯住「政策利率预期」和「股债性价比（ERP）」两个信号，就能把这种家庭场景里的事，翻译成大类资产轮动策略。

## 对量化交易的意义
- 利率是**跨资产定价的锚**：宏观量化策略常围绕"政策利率预期"建模，利率期货、收益率曲线形状都是交易标的
- **股债性价比**（ERP）随利率升降，可做大类资产轮动的择时
- 货币政策事件（如美联储 FOMC 决议）是**事件驱动策略**的高波动窗口
- 成长股久期长、对利率最敏感——利率上行期，多因子模型应降低成长暴露

## 常见误区
- <span class="qw-no">✕</span> 认为降准 = 马上利好股市——传导有时滞，且要看市场是否已提前定价
- <span class="qw-no">✕</span> 混淆"央行加息"与"市场利率上升"——政策利率起引导作用，市场利率受预期驱动
- <span class="qw-no">✕</span> 认为 QE 就是"印钱发给大家"——它先作用于金融机构的资产负债表
- <span class="qw-ok">✓</span> 关注"预期差"：政策结果重要，但与市场预期相比的"鹰/鸽程度"更重要
