# 金融基础

## 一句话定位

量化交易不是凭空造工具，它建立在一件事上：**你交易的市场到底怎么运转**。这个板块补的正是这块地基——有哪些可交易的品种、怎么给一家公司估值、宏观政策怎么传导到价格、你的委托单最终怎么成交。

<PlainTalk>买股票就像开车：指标和策略是方向盘和油门（怎么操作），金融基础是路况和交通规则（为什么这么开）。不懂规则就上高速，代码写得再漂亮也是裸奔。</PlainTalk>

## 一个例子：同一个想法，在不同市场是完全不同的生意

同样是"低估值买入"，买一只[股票](./asset-classes/stocks)和在[期货](./asset-classes/futures)上做同一件事，风险完全不同：

- **股票**：没有强制杠杆，可以长期持有，判断错了可以等。
- **期货**：自带杠杆、有到期日，方向判断对了也可能被中途强平。

理解每个品种的**脾气**（杠杆、流动性、结算规则），是选对策略的第一步——这正是本板块的价值。

## 学习建议

- **做技术分析**：至少把[市场机制](./market-mechanics/)读透——不了解撮合与委托，连"止损怎么触发"都说不清。
- **做价值投资**：重点读[基本面分析](./fundamental-analysis/)和[宏观经济](./macroeconomics/)。
- **纯新手**：先读[市场基础](../getting-started/market-basics)了解全局，再回来看本板块。
- 其余页面按需查阅，不需要一次读完。
