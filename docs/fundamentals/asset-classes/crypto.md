# 加密货币

## 一句话理解
加密货币是基于区块链的数字资产，没有中央发行机构，靠分布式记账保证稀缺性与可转让性；与量化关系最大的是它的 7×24 交易、极端波动与独特的杠杆结构。

<PlainTalk>加密市场就像一家「永不打烊的数码集市」：全球买家和卖家 7×24 小时随时撮合交易，没有休市，也没有中央银行在背后记账。你资产的余额记在遍布全球的「公共账本」（区块链）上，谁也篡改不了历史。只是这家集市不仅开门时间长，还自带「加速器」——最高上百倍的杠杆，把原本就剧烈的波动再放大一百倍。</PlainTalk>

## 核心内容

### 现货与永续合约
加密交易主要有两种载体：

| 维度 | 现货 | 永续合约 |
|------|------|----------|
| 是否持有真实资产 | 是（链上或交易所托管） | 否，纯价格合约 |
| 到期日 | 无 | 无，但需定期结算资金费率 |
| 杠杆 | 无（现货 1 倍） | 通常最高 100-125 倍 |
| 做空 | 通常不支持（或借币做空） | 直接做空 |
| 用途 | 长线配置、链上数据策略 | 日内、套利、杠杆策略 |

### 资金费率
永续合约没有交割日，为了让合约价格锚定现货价格，交易所引入**资金费率**：多头与空头定期相互支付资金费。

| 资金费率 | 含义 | 谁付给谁 |
|----------|------|----------|
| 正（如 0.01%/8 小时） | 合约价高于现货，多头情绪强 | 多头支付给空头 |
| 负 | 合约价低于现货，空头情绪强 | 空头支付给多头 |
| 极端值（>0.05%） | 市场过热或过度恐慌 | 常被当作反向信号 |

资金费率的结算周期通常是 8 小时，它可以看作一个"持仓成本"或"市场情绪指标"。

### 与传统市场的差异

| 特征 | 加密 | 股票/期货 |
|------|------|-----------|
| 交易时间 | 7×24 无休 | 有限时段 |
| 涨跌幅限制 | 无 | 多数市场有 |
| 清算风险 | 交易所宕机、插针 | 相对规范 |
| 波动率 | 极高 | 较高 |

### 生活化案例：从「永不眠」到「一夜爆仓」

小林在牛市中用 1 万元本金，以 10 倍杠杆做多某加密资产（示例数据）。价格涨了 3%，账户浮盈 30%——他心一热，加仓到 20 倍。此时永续合约的资金费率冲到 0.08%（每 8 小时结算一次），这是市场过热的典型信号，他没在意。结果凌晨流动性最差时来了一根「插针」，价格 5 分钟内回落 10%。20 倍杠杆下，10% 的回调意味着两倍本金的损耗——仓位瞬间爆仓清零。回想起来，资金费率这个公开的「情绪温度计」早就亮了红灯：超过 0.05% 就该警惕回调。加密市场 7×24 交易看似机会更多，实则杠杆、资金费率与插针三重风险叠加，仓位管理远比方向判断重要。

## 对量化交易的意义
- 7×24 交易让**全时段策略**成为可能，但也意味着半夜的闪崩（流动性枯竭时的"插针"）会打穿止损
- 资金费率是加密独有的信号源：极端正费率常伴随回调，可用于均值回归策略
- 杠杆 + 无涨跌幅 + 低流动性的组合，使**滑点与清算风险**成为比方向更重要的变量
- 跨所套利、期现套利（现货 vs 永续）是加密量化最成熟的策略之一

## 常见误区
- <span class="qw-no">✕</span> 满杠杆"梭哈"——10 倍杠杆下 10% 回调即爆仓，而加密日内波动超 10% 很常见
- <span class="qw-no">✕</span> 忽略资金费率成本——高资金费率会长期拖拽持仓收益
- <span class="qw-no">✕</span> 只看交易所深度图、不看链上数据——部分"深度"是机器人刷单
- <span class="qw-ok">✓</span> 把永续合约当作"加密版的期货"来理解风险，而不是彩票
