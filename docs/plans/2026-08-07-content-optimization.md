# 内容优化：大白话解释 + 使用案例

> 更新：试点已完成并验证（2026-08-07）。`PlainTalk` / `CaseWalk` 两个组件已落地并注册，6 个大白话页 + 3 个策略走读页 + 3 个 fundamentals 案例页完成。**注意：Vue 组件属性 JS 表达式内不能出现 ASCII 双引号，强调用「」直角引号；组件插槽不解析 markdown，不能用 `**粗体**`，用行内 `<b>` 或纯文本。**

## 背景

全站 103 页结构完整、交互组件覆盖率高，但存在两个内容缺口（量化数据支撑）：

1. **大白话解释不成体系**：指标页有「一句话总结」但仍偏术语化，生活类比零散（仅布林策略页有"橡皮筋"比喻）。对零基础读者，"背离 / 均值回归 / 动能"仍是门槛。
2. **使用案例覆盖不均**：12+ 个 fundamentals 页面零案例（资产类别 / 宏观 / 基本面）；策略页有回测表但缺少"一笔完整交易走读"的叙事。

## 成熟做法参照

- **Babypips**（外汇教学）：每个概念先用生活语言+比喻讲一遍，再进公式。
- **Investopedia**：每页固定"Key Takeaways"，配一个"它对你意味着什么"的平实段落。
- **交易课程**：策略教学普遍采用"一笔真实交易走读"（背景→信号→入场→管理→出场→复盘）的叙事，比规则清单更好记忆。

## 方案

新增两个全局组件，不新增依赖，复用既有 GSAP / VitePress 机制：

### 1. `PlainTalk` —— 大白话块
- 放置于页面标题之后、「一句话总结」之前的顶部位置。
- 结构：金色点缀的说明卡（左金边 + 金色浅底 + 聊天气泡图标），内容为一段生活化类比。
- Props：`title`（默认"用大白话说"），默认插槽承载正文。
- 示例（RSI）：*"RSI 就像把最近 14 天的涨跌放到天秤上比力气。涨得明显比跌得多 → 读数高，买方占上风……"*

### 2. `CaseWalk` —— 一笔交易走读
- 放置于策略页规则清单之前或之后，替代纯文本回放说明。
- 结构：纵向时间线，6 步默认骨架（观察→信号→入场→持仓/止损→止盈→复盘），步骤带彩色类型标签（观察/信号/入场/持仓/止损/止盈/复盘），末尾可接结果小结。
- 动画：GSAP ScrollTrigger 滚动逐条浮现（与 SignalFlow 一致的克制强度）。
- Props：`title`、`:steps`（`{ label, detail, type }`）、`result`。

### 3. fundamentals 生活化案例（纯 markdown）
- 给零案例的资产类别 / 宏观 / 基本面页面各补一节"生活化案例"，用具体人设 + 场景 + 数字讲清概念，不新增组件。

## 试点范围（本阶段）

- **大白话**：MA、MACD、RSI、布林带 4 个核心指标页 + 市场基础、时间框架 2 个入门页
- **交易走读**：布林回归、均线交叉、RSI 反转 3 个策略页
- **生活化案例**：股票、ETF、经济指标 3 个 fundamentals 页

验证通过后，把大白话/案例批量铺开到其余页面。
