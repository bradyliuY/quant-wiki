# 量化术语词典

量化交易涉及大量专业术语。本词典按类别整理，中英对照，帮助快速查阅。

## 行情与 K 线

| 术语 | 英文 | 说明 |
|------|------|------|
| 开盘价 | Open | 周期开始的价格 |
| 最高价 | High | 周期内最高价 |
| 最低价 | Low | 周期内最低价 |
| 收盘价 | Close | 周期结束的价格 |
| 成交量 | Volume | 成交的数量 |
| K 线/蜡烛图 | Candlestick | 记录 OHLC 的图表形式 |
| 阳线/阴线 | Bullish/Bearish candle | 上涨/下跌的 K 线 |
| 影线 | Wick/Shadow | K 线实体的上下延伸 |

## 交易机制

| 术语 | 英文 | 说明 |
|------|------|------|
| 做多 | Long | 买入，期望上涨 |
| 做空 | Short | 卖出，期望下跌 |
| 杠杆 | Leverage | 放大资金使用效率的比例 |
| 保证金 | Margin | 交易所需的最小抵押资金 |
| 爆仓 | Liquidation | 保证金不足被强制平仓 |
| 点差 | Spread | 买卖价之间的差距 |
| 滑点 | Slippage | 期望成交价与实际成交价的差距 |
| T+0/T+1 | — | 当日/次日才能卖出 |

## 金融工具

| 术语 | 英文 | 说明 |
|------|------|------|
| 股票 | Stock | 股份所有权的凭证 → [股票](../fundamentals/asset-classes/stocks) |
| ETF | Exchange Traded Fund | 在交易所交易的一篮子资产 → [ETF](../fundamentals/asset-classes/etf) |
| 期货 | Futures | 约定未来按既定价格买卖的合约 → [期货](../fundamentals/asset-classes/futures) |
| 期权 | Option | 买方付权利金后获得的选择权 → [期权](../fundamentals/asset-classes/options) |
| 外汇 | Forex | 不同货币之间的兑换交易 → [外汇](../fundamentals/asset-classes/forex) |
| 加密货币 | Crypto | 基于区块链的数字资产 → [加密货币](../fundamentals/asset-classes/crypto) |
| 衍生品 | Derivative | 价格衍生自其他标的的合约 → [资产类别](../fundamentals/asset-classes/) |

## 技术指标

| 术语 | 英文 | 说明 |
|------|------|------|
| 移动平均线 | MA/SMA/EMA | 价格的平均值，趋势指标 |
| 相对强弱 | RSI | 超买超卖指标 |
| MACD | — | 双均线差，趋势/动量指标 |
| 布林带 | Bollinger Bands | 波动率通道 |
| 平均真实波幅 | ATR | 波动率衡量 |
| 金叉/死叉 | Golden/Death cross | 快线上穿/下穿慢线 |
| 背离 | Divergence | 价格与指标方向不一致 |

## 策略类型

| 术语 | 英文 | 说明 |
|------|------|------|
| 趋势跟踪 | Trend following | 顺势而为 |
| 均值回归 | Mean reversion | 价格回归平均 |
| 动量策略 | Momentum | 强者恒强 |
| 配对交易 | Pairs trading | 相关性对冲 |
| 网格交易 | Grid trading | 区间内低买高卖 |
| 高频交易 | HFT | 毫秒级高频交易 |
| 多因子 | Multi-factor | 多维度因子选股 |

## 投资理论

| 术语 | 英文 | 说明 |
|------|------|------|
| 有效市场假说 | EMH | 价格已反映全部信息，难以持续战胜市场 → [市场基础](../getting-started/market-basics) |
| 价值投资 | Value investing | 买入价格低于内在价值的资产 → [价值低估](../strategies/value/) |
| 多因子模型 | Multi-factor model | 用多个因子维度解释资产收益 → [多因子](../strategies/quantitative/factor-model) |
| 风险平价 | Risk parity | 按风险贡献配比资产而非按资金 → [风险平价](../strategies/quantitative/risk-parity) |
| 现代投资组合理论 | MPT | 用均值方差在给定风险下求最优组合 → [统计与概率基础](../methodology/statistics/) |

## 风险与绩效

| 术语 | 英文 | 说明 |
|------|------|------|
| 最大回撤 | Max Drawdown | 从高点到低点的最大跌幅 |
| 夏普比率 | Sharpe Ratio | 风险调整后收益 |
| 卡玛比率 | Calmar Ratio | 收益/最大回撤 |
| 胜率 | Win rate | 盈利交易占比 |
| 盈亏比 | Profit/Loss ratio | 平均盈利/平均亏损 |
| 贝塔 | Beta | 相对大盘的波动 |
| 阿尔法 | Alpha | 超越基准的超额收益 |

## 回测与数据

| 术语 | 英文 | 说明 |
|------|------|------|
| 回测 | Backtest | 历史数据模拟 |
| 过拟合 | Overfitting | 模型过度适配历史 |
| 幸存者偏差 | Survivorship bias | 只统计存活标的 |
| 未来函数 | Look-ahead bias | 用未来数据做决策 |
| 样本外 | Out-of-sample | 未参与优化的数据 |
| 随机游走 | Random walk | 价格无法预测的假设 |
