# 关于本站

## 本站是什么

**量化交易知识库**是一个个人维护的量化投资学习平台，目标是让"想学量化但不知从何下手"的人，能通过**动态可视化演示**直观理解指标、策略和方法论。

## 为什么做这个站

传统量化资料的两个痛点：

1. **太抽象**：指标公式一堆，但不知道在行情上长什么样
2. **碎片化**：指标、策略、风控散落各处，没有体系

本站的解法：

- **每个指标配动态图表演示**——拖动时间轴，看指标如何演化
- **每个策略配行情回放**——看买卖点如何触发
- **每个公式配交互式计算器**——拖动滑块，看结果变化
- **系统化组织**——从金融基础到策略库的完整知识树

## 技术栈

- [VitePress](https://vitepress.dev) — 静态站点框架
- [lightweight-charts](https://github.com/tradingview/lightweight-charts) — TradingView 官方开源图表库
- [GSAP](https://gsap.com) — 滚动动画引擎
- Vue 3 + TypeScript

## 内容来源

- **方法论板块**：基于开源交易分析技能的知识体系整理改写
- **指标/策略板块**：参考经典技术分析文献与量化社区最佳实践
- **金融基础板块**：面向量化初学者的系统化科普

## 覆盖边界

本站是一套**从入门到回测与模拟盘**的学习工具链，明确止于模拟盘：

- ✅ **覆盖**：金融基础、指标、策略、方法论；Python 环境、数据获取、pandas 处理、回测、模拟盘
- ❌ **不覆盖**：实盘执行（IB API / CCXT / vn.py 等自动化下单）、实时行情推送、具体标的推荐、投资建议

工具链再往前的实盘环节涉及真实资金与合规，超出本站定位。
