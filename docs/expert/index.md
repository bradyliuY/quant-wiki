# 专家进阶

一句话：专家不是知道更多指标，而是能提出假设、验证策略、识别过拟合，并决定一个策略是否值得进入模拟盘。

<PlainTalk>入门者像在看菜谱：这个指标怎么用、那个策略怎么买。专家像厨师：先判断食材新不新鲜、火候合不合适、换个厨房还能不能做出来。量化也是一样——会背 RSI、MACD 不算专家，能说明“为什么这个信号可能有效、什么时候会失效、换一段数据还灵不灵”才算真正入门研究。</PlainTalk>

## 为什么新增这个板块

现有板块已经帮你完成两件事：

1. **看懂**：知道市场、K 线、指标、策略和风险管理是什么
2. **做出来**：能在浏览器里跑回测，能搭 Python 环境，能走到模拟盘

专家进阶要回答第三个问题：**这个结果可靠吗？**

一个策略回测赚钱，不代表它真的有价值。它可能只是刚好踩中一段趋势，也可能是参数扫太多之后钓到的噪声，还可能是一加手续费就从盈利变亏损。专家进阶不是鼓励你更快实盘，而是让你更慢、更严谨地做判断。

## 一体三线四阶段

| 层级 | 目标 | 你要学会问的问题 |
|------|------|------------------|
| 共同基础 | 市场基础 → 指标 → 策略 → 回测 → 风控 → 实战 | 这套规则怎么运行？ |
| 量化研究员线 | 验证策略是否可靠 | 它为什么赚钱？是不是运气？ |
| 系统化交易者线 | 把策略变成可执行系统 | 成本、回撤、滑点会不会吃掉收益？ |
| 量化开发者线 | 把研究流程工程化 | 数据、代码、实验结果能不能复现？ |

四个阶段这样衔接：

| 阶段 | 学习目标 | 代表输出 |
|------|----------|----------|
| ① 看懂市场 | 理解资产、K 线、指标 | 能解释一个交易信号 |
| ② 写出策略 | 把想法翻译成入场/出场/仓位规则 | 一套可回测规则 |
| ③ 验证策略 | 样本外、过拟合、成本检查 | 一份稳健性分析 |
| ④ 形成闭环 | 报告、模拟盘、复盘 | 一份研究报告 |

## 三条专家路线

### 量化研究员路线

核心问题：**策略为什么会赚钱，结果是不是运气？**

先从 [研究方法总览](./research-methods/) 开始，再看：

- [策略假设](./research-methods/strategy-hypothesis)：先问为什么会赚钱
- [多重检验](./research-methods/multiple-testing)：参数扫多了总会碰巧
- [样本外验证](./research-methods/out-of-sample)：换一段数据还灵吗
- [过拟合识别](./research-methods/overfitting)：漂亮曲线最危险

### 系统化交易者路线

核心问题：**策略能不能执行，能不能拿得住？**

第一步先看 [交易成本](./system-trading/trading-costs)。很多策略不是逻辑错，而是纸面收益太薄，手续费、滑点和点差一扣就没有了。

后续会扩展滑点、执行偏差、策略组合、回撤控制和模拟盘日志。

### 量化开发者路线

核心问题：**研究流程能不能稳定复现？**

这条线后续会补真实数据清洗、数据质量检查、回测项目结构、实验记录和可复现研究流程。程序员可以重点走这条线，但也必须先懂研究纪律，否则工程越强，越容易高效地制造错误结论。

### 机器学习与量化路线（后续专题）

机器学习值得有，但不应该作为第一入口。原因很简单：如果你还不会样本外验证、多重检验和过拟合识别，机器学习只会让你更快过拟合。

本站后续会把机器学习放在专家进阶下，重点讲：

| 主题 | 解决什么问题 |
|------|--------------|
| 特征工程 | 把行情和基本面变成模型能读的变量 |
| 训练/验证/测试切分 | 避免模型偷看未来 |
| 时间序列交叉验证 | 金融数据不能随机打乱 |
| 模型过拟合 | 准确率高不等于能赚钱 |
| ML 策略评估 | 看收益、回撤、换手，而不是只看预测分数 |

建议顺序是：**先学研究方法，再学因子研究，最后学机器学习**。

## 一个例子：双均线策略的专家问法

入门者看到双均线，常问：

> 金叉是不是买？死叉是不是卖？

专家会把问题拆成一串：

1. 这个策略赚的是趋势延续的钱，还是随机波动的钱？
2. 它在哪些行情最容易亏？震荡市会不会反复打脸？
3. 快线和慢线参数是不是一换就失效？
4. 只在这一段数据有效，还是换一段数据仍然有效？
5. 加上手续费和滑点后，平均每笔利润还够不够厚？
6. 如果进入模拟盘，实际成交价和回测假设差多少？

这就是从“使用策略”到“研究策略”的差别。

## 这个板块的边界

- 所有案例均为教学示意，不构成投资建议
- 不提供具体股票推荐
- 不提供实时行情
- 不提供实盘交易指令
- 模拟盘仍是本站工具链终点

专家进阶的目标是让你更会怀疑回测结果，而不是更冲动地交易。
