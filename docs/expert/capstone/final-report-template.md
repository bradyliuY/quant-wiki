# 最终研究报告模板

一句话：一份合格的量化研究报告，不是证明策略赚钱，而是说明它为什么可能赚钱、在哪里会失效、是否值得进入模拟盘。

<PlainTalk>研究报告像体检报告：不是只写“身体很好”，而是把血压、血脂、肝功能、风险项都列出来。策略研究也一样，不能只写收益很好，还要写回撤、成本、样本外、失败场景。真正有价值的报告，能帮你冷静决定“继续观察”还是“放弃”。</PlainTalk>

## 报告结构

一份最小可用研究报告至少包含 10 项：

| # | 项目 | 要回答的问题 |
|---|------|--------------|
| 1 | 策略假设 | 它为什么可能赚钱？ |
| 2 | 数据范围 | 用了哪些数据，时间段是什么？ |
| 3 | 信号规则 | 什么时候买、什么时候卖？ |
| 4 | 回测规则 | 成交价、仓位、止损怎么处理？ |
| 5 | 成本假设 | 手续费、滑点、点差怎么设？ |
| 6 | 样本内结果 | 研究数据上表现如何？ |
| 7 | 样本外结果 | 没见过的数据上是否还有效？ |
| 8 | 风险与回撤 | 最大回撤、连续亏损、失败月份是什么？ |
| 9 | 失败场景 | 哪些行情里会亏？ |
| 10 | 是否进入模拟盘 | 下一步观察什么？ |

## 一个简短示例：双均线策略

以下是教学示意，不代表真实收益：

```text
策略假设：趋势形成后会延续一段时间，短期均线能比长期均线更早反映趋势变化。

信号规则：MA5 上穿 MA20 买入，MA5 下穿 MA20 卖出。

样本内结果：年化 18%，最大回撤 -12%，交易 42 笔。

样本外结果：年化 8%，最大回撤 -17%，交易 15 笔。

成本压力：基础成本下仍为正，2 倍成本后收益接近 0。

失败场景：震荡市反复金叉死叉，连续小亏。

结论：不适合直接实盘，可进入模拟盘观察。重点记录滑点、假信号次数、震荡市回撤。
```

这个结论不夸张，但有价值。它没有说“策略稳赚”，而是说明：这个策略可能有趋势收益来源，但成本和震荡市是主要风险。

## 评分表

| 项目 | 合格标准 |
|------|----------|
| 策略假设 | 能说清收益来源和失败场景 |
| 数据范围 | 时间、标的、频率写清楚 |
| 信号规则 | 入场/出场/仓位能被代码复现 |
| 回测规则 | 明确无未来数据，成交假设合理 |
| 成本假设 | 至少包含手续费和滑点 |
| 样本外 | 参数冻结后验证 |
| 风险分析 | 不只看收益，还看回撤和连续亏损 |
| 结论 | 能明确继续、观察或放弃 |

## 是否进入模拟盘

进入模拟盘前，至少满足：

- 策略假设说得清
- 样本外没有明显崩盘
- 成本压力测试后仍有安全边际
- 最大回撤在可承受范围内
- 已写清楚放弃条件

模拟盘不是“准备实盘”的兴奋阶段，而是继续验证的冷静阶段。

## 常见误区

- <span class="qw-no">✕</span> 只贴收益曲线，不写策略假设
- <span class="qw-no">✕</span> 样本外失败后改参数再报告
- <span class="qw-no">✕</span> 不写成本，默认完美成交
- <span class="qw-no">✕</span> 结论只写“效果很好”
- <span class="qw-ok">✓</span> 把失败场景、放弃条件和模拟盘观察点写清楚
