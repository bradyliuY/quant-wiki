# 毕业项目

一句话：把"看得懂"变成"做得出来"的最后一步——用一份完整研究报告，证明你能独立走完一次量化研究。

<PlainTalk>毕业项目像考驾照的科目三：前面你学了刹车、油门、看后视镜，这一关是完整开一圈。中途可能熄火、可能压线，但只要你能按规范开完全程，就说明你不是"会背操作"，而是"能上路"。量化也是一样，完整跑完一个策略的研究流程，才算真正毕业。</PlainTalk>

## 为什么需要毕业项目

知识库能教你每个概念，但专家能力只能在**完整做一遍**中形成。毕业项目要求你把散落的知识串起来：

```text
策略假设 → 数据 → 规则 → 回测 → 成本 → 样本外 → 风险 → 结论
```

它不要求你发明新策略，也不要求收益很高。它的考核点是：**你懂不懂每一步为什么这么做。**

## 第一步：先拿报告模板

[最终研究报告模板](./final-report-template) 是毕业项目的脚手架——10 项结构就是一次完整研究的清单。照着它填空，你会发现自己哪里还模糊。

## 完成标准

| 项目 | 合格标准 |
|------|----------|
| 策略假设 | 能说清赚谁的钱、何时失效 |
| 数据与规则 | 入场/出场/仓位能被复现 |
| 回测 | 明确无未来数据，成交假设合理 |
| 成本 | 至少含手续费和滑点，并做压力测试 |
| 样本外 | 参数冻结后验证，不反复调参 |
| 风险 | 写清回撤、连续亏损、失败月份 |
| 结论 | 明确继续/观察/放弃，而不是"效果很好" |

## 建议的项目路径

1. **复现一个均线策略**：从最熟悉的策略开始，完整走一遍报告结构
2. **复现一个动量因子**：从"一个策略"升级到"一个因子"，体验分层检验
3. **加入成本重新评估**：同一个策略，分别评估 0 成本 / 基础成本 / 2 倍成本
4. **最终研究报告**：选一个你真正想深入的方向，产出一份完整报告

## 和机器学习的关系

如果将来想学机器学习，毕业项目是它的**入场券**。一个连均线策略的样本外和成本都讲不清的人，学 ML 只会更快过拟合。
