# 系统化交易者路线

一句话：研究员回答"这个策略值不值得做"，系统化交易者回答"它能不能拿得住、执行得出来"。

<PlainTalk>研究员和系统化交易者的区别，像菜谱作者和掌勺厨师：菜谱写得再好，火候、油温、翻锅时机不对，端上桌的还是不一样。策略也一样——纸面收益再漂亮，手续费、滑点、回撤和心理一上来，能不能坚持执行才是关键。</PlainTalk>

## 这条线解决什么

很多策略不是逻辑错，而是**执行层**的问题：

- 回测假设完美成交，现实有滑点和点差
- 纸面收益很薄，扣成本后没剩多少
- 高换手策略被手续费一口口吃光
- 单独一个策略回撤不小，组合后反而更稳
- 连亏几笔后，人拿不住单、临时改规则

系统化交易者路线就是把"研究结果"变成"能稳定执行的东西"。

## 第一步：先看交易成本

从 [交易成本](./trading-costs) 开始——它是这条线的入口，也是进入模拟盘前最该做的一次"体检"。很多策略不需要更多研究，只需要回答一句：**扣掉成本还赚钱吗？**

## 这条线会怎么扩展

| 主题 | 解决什么问题 | 状态 |
|------|--------------|------|
| [交易成本](./trading-costs) | 手续费/滑点/点差如何吃掉收益 | ✅ 已有 |
| 滑点与成交偏差 | 回测假设成交价和实际成交差多少 | 规划中 |
| 执行偏差 | 信号有了，人没按纪律执行怎么办 | 规划中 |
| 策略组合 | 多个策略放一起，回撤会不会降低 | 规划中 |
| 回撤控制 | 怎么让回撤落在可承受范围内 | 规划中 |
| 模拟盘日志 | 用日志记录每笔偏离预期的成交 | 规划中 |

## 与研究员路线的分工

- [研究员路线](../research-methods/)：先确认策略逻辑可靠（假设、样本外、过拟合）
- **系统化交易者路线**：再确认它能执行（成本、滑点、回撤、心理）
- 两者都做完，才轮到 [最终研究报告模板](../capstone/final-report-template)

## 一个例子

双均线策略回测年化 15%，看似可以接受。但进入执行层你会发现：

1. 交易 80 笔，每笔来回成本 0.2%，年化被吃掉约 8 个百分点
2. 信号在收盘后出现，实际次日开盘成交，滑点又吃掉一部分
3. 震荡市连续 6 笔小亏，人开始怀疑系统、想改参数

这些问题研究阶段看不见，但模拟盘阶段全都会冒出来。
