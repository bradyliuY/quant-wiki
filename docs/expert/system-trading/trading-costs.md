# 交易成本

一句话：回测里的收益是纸面收益，扣掉手续费、滑点、点差和冲击成本后，才接近真实可执行收益。

<PlainTalk>交易成本像水管漏水：每次只漏一点，看起来不严重；但如果你一天开关水龙头几十次，最后水桶可能是空的。交易也是一样，低频策略可能只被成本咬一小口，高换手策略可能被一口口吃光。</PlainTalk>

## 成本有哪些

| 成本 | 说明 | 常见影响 |
|------|------|----------|
| 手续费 | 券商、交易所或平台按笔/金额收取 | 每笔交易都扣，交易越多越明显 |
| 滑点 | 预期成交价和实际成交价的差 | 回测用理想价格，现实成交更差 |
| 点差 | 买一价和卖一价之间的差 | 流动性差的标的更明显 |
| 冲击成本 | 大单把价格推向不利方向 | 仓位越大、成交越急，成本越高 |

回测如果不写成本假设，相当于假设你每次都能免费、精准、无限量成交。这在真实市场里几乎不可能。

## 为什么高换手最怕成本

看两个教学示意策略：

| 策略 | 交易频率 | 单笔毛收益 | 成本影响 |
|------|----------|------------|----------|
| 低频趋势策略 | 每月 1–3 笔 | 每笔 3%–8% | 成本通常不是主矛盾 |
| 高频震荡策略 | 每周多笔 | 每笔 0.2%–0.5% | 成本可能吃掉大部分收益 |

如果一个策略平均每笔只赚 0.25%，而来回交易成本是 0.16%，那扣完成本只剩 0.09%。再遇到一点滑点扩大，策略就可能由盈转亏。

## 一个示意计算

假设某策略一年交易 100 笔：

| 项目 | 数值（示意） |
|------|--------------|
| 单笔平均毛收益 | 0.25% |
| 单边手续费 + 滑点 | 0.08% |
| 买入 + 卖出总成本 | 0.16% |
| 单笔扣后收益 | 0.09% |
| 100 笔扣后收益 | 约 9% |

如果单边成本从 0.08% 上升到 0.15%：

```text
单笔扣后收益 = 0.25% - 0.30% = -0.05%
```

策略从赚钱变成亏钱，不是因为信号变差，而是因为毛利润太薄。

## 怎么在研究报告里写成本假设

不要只写“已考虑手续费”。要写得能复现：

```text
成本假设：
- 手续费：单边 0.03%
- 滑点：单边 0.05%
- 总交易成本：买入 + 卖出共 0.16%
- 成本压力测试：基础成本、2 倍成本、3 倍成本各跑一次
```

然后报告一张表：

| 成本情景 | 年化收益（示意） | 最大回撤（示意） | 结论 |
|----------|------------------|------------------|------|
| 0 成本 | 18% | -12% | 纸面结果 |
| 基础成本 | 10% | -14% | 仍可研究 |
| 2 倍成本 | 3% | -18% | 边际很薄 |
| 3 倍成本 | -4% | -22% | 不适合执行 |

## 小实验

拿一个策略，先不要改信号，只改成本：

1. 设 0 成本，记录收益和回撤
2. 设基础成本，记录变化
3. 设 2 倍成本，记录变化
4. 设 3 倍成本，判断策略是否仍值得研究

如果策略只在 0 成本下好看，它不是交易系统，只是纸面游戏。

## 和模拟盘的关系

回测成本是假设，模拟盘成本是现实反馈。进入 [模拟盘实操](../../practice/paper-trading) 后，重点不是看账户每天赚亏，而是记录：

| 项目 | 要记录什么 |
|------|------------|
| 计划成交价 | 回测或信号假设中的价格 |
| 实际成交价 | 模拟盘真实成交价格 |
| 偏差 | 实际比计划差多少 |
| 原因 | 滑点、延迟、挂单未成交、流动性不足 |

这些偏差积累起来，就是策略从“研究结果”走向“可执行系统”的关键差距。

## 常见误区

- <span class="qw-no">✕</span> 回测时先不算成本，等策略赚钱再说
- <span class="qw-no">✕</span> 只写手续费，不写滑点和点差
- <span class="qw-no">✕</span> 高频策略用低频策略的成本假设
- <span class="qw-ok">✓</span> 把成本压力测试作为进入模拟盘前的必做项
