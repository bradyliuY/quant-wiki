# 过拟合识别

一句话：过拟合就是策略把历史细节背得太熟，以至于换一段市场就不会了。

<PlainTalk>过拟合像按去年的天气定制一把伞：去年 3 月 5 日下雨，你就在伞面那个角度加厚；去年 4 月 12 日刮风，你又给伞柄做特殊弯曲。结果这把伞完美适配去年天气，今年一出门就湿透。策略也是一样，太贴合历史细节，未来反而更脆弱。</PlainTalk>

## 为什么漂亮曲线最危险

很多过拟合策略的样本内曲线都很好看：回撤小、收益高、几乎一路向上。但这不是安全信号，反而可能是危险信号。

真实策略通常会经历：

- 连续亏损
- 横盘期
- 假信号
- 风格失效
- 成本侵蚀

如果一条曲线平滑得像提前知道未来，就要警惕它是不是用了太多参数、太多过滤条件，或者只挑了最有利的一段行情。

## 五个过拟合信号

| 信号 | 说明 | 为什么危险 |
|------|------|------------|
| 参数必须非常精确 | MA(17,43) 赚钱，MA(16,42) 就不行 | 可能只是贴合历史噪声 |
| 交易次数太少 | 三笔交易贡献全部收益 | 样本不足，运气成分大 |
| 只在一段行情有效 | 趋势段暴赚，震荡段亏光 | 策略适用环境太窄 |
| 成本一加就亏 | 毛利润很薄 | 真实执行不可行 |
| 邻近参数差很多 | 没有稳定参数平台 | 未来轻微变化就失效 |

## 一个具体案例

双均线策略在强趋势行情里很容易表现漂亮：

```text
上涨趋势开始 → 快线上穿慢线 → 持有到趋势结束 → 收益很好
```

但同一套规则在震荡市里可能变成：

```text
金叉买入 → 小跌止损
死叉卖出 → 小涨踏空
再次金叉 → 再次被打脸
```

如果你只用趋势段调参，策略会看起来很强；但一进入震荡段，它可能连续亏损。这不是执行问题，而是策略假设本身只适合趋势行情。

## 检查清单

每次看到漂亮回测，先问 8 个问题：

| 问题 | 如果答案是“否” |
|------|----------------|
| 策略假设说得清吗？ | 可能只是规则堆砌 |
| 邻近参数也有效吗？ | 可能是参数孤岛 |
| 样本外还赚钱吗？ | 可能只背熟样本内 |
| 扣成本后还赚钱吗？ | 可能不可执行 |
| 交易次数足够吗？ | 可能样本太少 |
| 经历过不同市场环境吗？ | 可能适用范围太窄 |
| 失败月份能解释吗？ | 可能不知道风险来源 |
| 规则能简单复述吗？ | 可能复杂到只是在拟合历史 |

## 怎么降低过拟合

1. **规则少一点**：少量有逻辑的条件，比一堆过滤器更稳
2. **参数粗一点**：宁可选稳定区域，不迷信精确数字
3. **样本分开**：样本内研究，样本外验证
4. **报告失败**：失败场景比漂亮曲线更能说明策略边界
5. **加入成本**：很多过拟合策略只在零成本世界里赚钱

## 和机器学习的关系

机器学习模型可以自动捕捉复杂关系，也能自动记住噪声。金融市场样本少、噪声大、环境会变，所以 ML 过拟合尤其常见。

如果一个简单均线策略都会过拟合，那么一个包含几十个特征、多个模型参数的机器学习策略更需要严格验证。

## 小实验

拿任意一个回测结果，试着做三件事：

1. 把参数上下调一点，看结果是否剧烈变化
2. 加入一个保守成本假设，看收益是否还为正
3. 换一段数据，看最大回撤是否明显扩大

三项里只要有两项崩掉，就不要急着优化参数，先回到 [策略假设](./strategy-hypothesis)。

## 常见误区

- <span class="qw-no">✕</span> 觉得曲线越平滑越安全
- <span class="qw-no">✕</span> 用更多过滤条件修补每一次亏损
- <span class="qw-no">✕</span> 样本外失败后继续调到成功
- <span class="qw-ok">✓</span> 把失败场景写进研究报告，而不是藏起来
