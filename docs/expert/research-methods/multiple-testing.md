# 多重检验

一句话：你试的参数越多，越容易碰巧找到一个“看起来很赚钱”的结果，但那不一定代表策略真的有效。

<PlainTalk>多重检验就像买彩票：买 1 张没中奖很正常，买 1000 张总可能中几张小奖。但中奖不代表你发现了彩票规律，只代表你试得足够多。回测里也是一样，参数扫得越多，总会有几组在历史上特别漂亮。</PlainTalk>

## 为什么重要

很多人以为自己在优化策略，其实是在历史噪声里钓鱼。

以双均线为例：

```text
快线：3 到 30
慢线：10 到 100
```

如果每个组合都试一遍，你会得到上千个结果。最后挑年化最高的那个，看起来像“最优参数”。但它可能只是刚好适配这段合成行情或历史行情，并不代表未来也有效。

真正的问题不是“能不能找到最优参数”，而是：

> 邻近参数也好吗？换一段数据还好吗？扣掉成本还好吗？

## 一个具体案例

假设你在某段教学数据上测试双均线：

| 参数 | 样本内年化（示意） | 最大回撤（示意） |
|------|-------------------|------------------|
| MA(5, 20) | 18% | -12% |
| MA(8, 30) | 21% | -13% |
| MA(13, 40) | 19% | -14% |
| MA(17, 43) | 62% | -6% |
| MA(20, 50) | 16% | -15% |

如果只有 MA(17, 43) 特别漂亮，而周围参数都普通，它很可能不是“圣杯”，而是“参数孤岛”。

参数孤岛的意思是：策略只有在非常精确的一组参数上好看，稍微动一下就失效。这通常说明它记住了历史细节，而不是抓住了稳定规律。

## 怎么判断

| 现象 | 风险 | 更稳健的做法 |
|------|------|--------------|
| 参数范围很宽 | 容易钓到噪声 | 先用逻辑限定合理范围 |
| 最优参数孤零零一个点 | 大概率不稳定 | 看邻近参数是否也不错 |
| 换样本后排名大变 | 样本内过拟合 | 做 [样本外验证](./out-of-sample) |
| 只报告最好结果 | 隐藏失败样本 | 报告参数分布和失败案例 |
| 交易次数很少但收益很高 | 可能靠少数幸运交易 | 检查每笔交易来源 |

## 小实验

打开 [回测实验室](../../practice/backtest-lab)：

1. 选择“双均线交叉”
2. 点“找最优参数”
3. 记下最优参数和年化收益
4. 点“换一段数据”
5. 观察这组参数是否仍然好看

如果换一段数据后表现明显变差，你看到的就是多重检验风险：参数在当前数据里好看，不代表在别的数据里可靠。

## 怎么降低多重检验风险

1. **先写策略假设**：不要无目的地扫参数
2. **限制参数范围**：参数范围要来自交易逻辑，不是随便试
3. **看参数平台**：一片区域都表现不错，比单个尖峰更可信
4. **冻结参数再验证**：样本外不能继续调
5. **报告失败结果**：不要只展示最好看的那一组

## 和机器学习的关系

机器学习模型通常会尝试更多特征、更多参数、更多模型结构，所以多重检验风险更大。你越会自动化实验，越要有实验纪律。

这也是为什么机器学习专题应该放在研究方法之后：先学会避免“彩票式回测”，再学更复杂的模型。

## 常见误区

- <span class="qw-no">✕</span> 认为“扫出来的最优参数”就是答案
- <span class="qw-no">✕</span> 样本外不好就回头继续改参数
- <span class="qw-no">✕</span> 只给读者看最漂亮的曲线
- <span class="qw-ok">✓</span> 优先选择有逻辑、有参数平台、样本外衰减可接受的结果
