# 研报批判性阅读

一句话：研报是别人帮你做了一半的研究——有价值的不是它的结论，而是你能从里面提炼出的假设、证据和陷阱。

<PlainTalk>券商研报像餐厅评论家的推荐。评论家吃过很多馆子，比路人更值得听；但他不用自己的钱买单，也可能为一道"招牌菜"忽略其他。研报也一样：分析师比你专业，但回测亏的不是他的钱，他也有业绩压力。所以正确的读法不是"照单全收"，而是把它当半成品——你自己把它验证完。</PlainTalk>

## 为什么读研报

研报的价值不在"它推荐买什么"，而在三样东西：

1. **假设**：好的研报会讲清楚收益来源（比如"低估值 + 高盈利质量跑赢大盘"），这是你[策略假设](./strategy-hypothesis)的现成素材
2. **证据**：它给出了可检验的样本区间和回测框架，你可以用自己的数据复核
3. **风险清单**：研报会提到它在什么条件下失效、有哪些局限——这比收益曲线更有用

但研报有三层天然局限：

- **利益相关**：卖方研报的目标是促成交易，不是教你严谨研究
- **选择性展示**：只展示做出来的漂亮结果，扫过的失败参数不会写进报告
- **时点性**：结论基于某段历史，换一段数据未必成立

## 研报的四层结构

把一篇研报拆成四层来读：

| 层 | 内容 | 你要问的问题 |
|----|------|--------------|
| 结论 | 最终推荐了什么、目标价多少 | 这个结论背后的假设是什么？ |
| 证据 | 回测区间、因子表现、样本 | 区间多长？多空是否对称？含不含成本？ |
| 实现 | 因子定义、调仓频率、标的选择 | 定义能精确落地吗？数据我拿得到吗？ |
| 披露 | 风险提示、免责声明、局限 | 它在什么条件下会失效？ |

## 四步批判阅读法

### 第一步：先找假设

不看结论，先问：**这篇研报在赌什么？**

- 赌"便宜会回归"？→ [价值低估策略](../../strategies/value/)
- 赌"强者恒强"？→ [双动量轮动](../../strategies/momentum/dual-momentum)
- 赌"财报超预期会持续漂移"？→ [财报后动量](../../strategies/event-driven/earnings-drift)

把研报的结论翻译成一句"为什么可能赚钱"，再对照[策略假设](./strategy-hypothesis)的标准检查它是否成立。

### 第二步：再查证据质量

| 证据要素 | 好证据 | 危险信号 |
|----------|--------|----------|
| 样本区间 | 跨越牛熊、10 年以上 | 只取最近 2 年的一段趋势 |
| 多空 | 同时展示做多和做空 / 对冲 | 只做多（A 股牛市区间） |
| 成本 | 明确手续费、滑点假设 | 完全不含成本 |
| 参数 | 邻近参数都稳定 | 只有孤峰最优，周边全差 |
| 频率 | 调仓频率明确 | 高频调仓却不计费用 |

### 第三步：检查回测陷阱

用你在专家板块已经学过的三件武器：

- [过拟合识别](./overfitting)：研报的最优参数是不是扫出来的孤峰？
- [多重检验](./multiple-testing)：它试了多少个因子才"找到"这一个？
- [样本外验证](./out-of-sample)：它的区间够不够长、有没有留白？

一个判断口诀：**研报给你看的永远是样本内，样本外得你自己做。**

### 第四步：判断可复现性

再好的因子，落不了地就是零：

- **定义能否精确**："低估值"是 PE 还是 PB？是行业中性还是全市场？
- **数据是否可得**：用的因子数据你能买到吗？
- **资金容量**：策略在机构体量下还成立吗？
- **执行**：按研报的调仓频率，扣掉成本后还剩多少？

## 常见陷阱清单

- <span class="qw-no">✕</span> 只读结论不看假设：你记住的是"推荐买入"，而不是它在赌什么
- <span class="qw-no">✕</span> 把研报回测当自己的回测：它没扣成本、没留样本外，不等于你也可以这么做
- <span class="qw-no">✕</span> 用一篇研报的结论直接实盘：研报不是投资建议，本站也不提供任何投资建议
- <span class="qw-no">✕</span> 只看单边展示：一份诚实的研报会同时讲失败场景
- <span class="qw-ok">✓</span> 每次读完写三行：它在赌什么？证据靠谱吗？我能复现吗？

## 实例走读：多因子研报

以常见的"多因子选股"研报（如华泰、中信的多因子系列）为例，走一遍四步：

1. **假设**：多因子研报的底层假设是"市场并非完全有效，某些维度（价值 / 质量 / 动量）能获得长期溢价"——先确认你认同这个前提
2. **证据**：看它样本区间是否覆盖牛熊、因子多空收益是否对称、是否报告分年度表现
3. **陷阱**：多因子最容易过拟合——它可能扫了几百个候选因子才留下几个；还要警惕因子换手带来的成本被低估
4. **可复现**：因子定义是否行业中性？加权方式、调仓频率、处理停牌的方式有没有写清？这些细节决定你能否复现

多因子模型本身可以看本站的[多因子模型](../../strategies/quantitative/factor-model)和[组合风险管理](../../methodology/risk-management/portfolio-risk)。
