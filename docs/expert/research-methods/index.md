# 研究方法总览

一句话：量化研究不是找一条漂亮曲线，而是证明一个策略在什么条件下可能有效、在什么条件下会失效。

<PlainTalk>很多人做回测像拍证件照：只挑最好看的角度。真正的量化研究更像体检：不只看你哪里健康，还要主动找哪里有隐患。收益曲线漂亮只是第一眼，样本外、成本、回撤、失败场景才是体检报告里的关键指标。</PlainTalk>

## 量化研究流程

一套完整研究不应该从“调参数”开始，而应该按这条线走：

```text
策略假设 → 数据准备 → 样本内验证 → 样本外验证 → 成本检查 → 失败场景 → 研究报告
```

| 步骤 | 要问的问题 | 对应页面 |
|------|------------|----------|
| 策略假设 | 这个策略为什么可能赚钱？ | [策略假设](./strategy-hypothesis) |
| 数据准备 | 数据有没有复权、缺失、幸存者偏差？ | 后续量化开发者路线 |
| 样本内验证 | 在研究数据上规则是否说得通？ | [回测的正确流程](../../methodology/backtesting/how-to-backtest) |
| 样本外验证 | 换一段没见过的数据还灵吗？ | [样本外验证](./out-of-sample) |
| 成本检查 | 扣掉手续费和滑点后还赚钱吗？ | [交易成本](../system-trading/trading-costs) |
| 失败场景 | 它在哪些市场环境会亏？ | [过拟合识别](./overfitting) |
| 研究报告 | 结果能不能被别人复现？ | [最终研究报告模板](../capstone/final-report-template) |

## 好研究和坏研究的区别

| 坏研究 | 好研究 |
|--------|--------|
| 先扫参数，挑收益最高的 | 先写策略假设，再定义规则 |
| 只展示最漂亮的一段曲线 | 同时展示样本内和样本外 |
| 只看年化收益 | 同时看回撤、胜率、盈亏比、交易次数 |
| 忽略手续费和滑点 | 明确成本假设，并做压力测试 |
| 失败后继续调参直到好看 | 记录失败场景，判断逻辑是否失效 |
| 只说“策略赚钱” | 写清楚“为什么可能赚钱、什么时候不该用” |

## 一个完整例子

以双均线策略为例，研究方法不是这样：

> 快线从 3 到 30，慢线从 10 到 100，全扫一遍，哪个年化最高就用哪个。

更合理的研究流程是：

1. **假设**：趋势一旦形成，短期价格会延续一段时间
2. **规则**：快线上穿慢线买入，下穿卖出
3. **样本内**：用一段历史数据检查逻辑是否有效
4. **参数稳定性**：看邻近参数是否也表现不错，而不是只看尖峰
5. **样本外**：把最终参数冻结，放到另一段数据上验证
6. **成本**：扣掉手续费和滑点
7. **失败场景**：记录震荡市中反复假信号
8. **结论**：是否值得进入模拟盘，而不是直接实盘

## 为什么机器学习不能跳过这一步

机器学习听起来更高级，但它并不会自动解决研究纪律问题。相反，如果没有样本外验证和过拟合意识，模型会更擅长记住历史噪声。

所以本站后续会有机器学习专题，但顺序一定是：

```text
研究方法 → 因子研究 → 机器学习与量化
```

先学会判断“结果是否可靠”，再学更复杂的模型。

## 小实验

打开 [回测实验室](../../practice/backtest-lab)，做三件事：

1. 选择双均线策略，点“找最优参数”
2. 记下最优参数和年化收益
3. 点“换一段数据”，观察同样参数是否还漂亮

如果变化很大，说明你看到的不是“确定答案”，而是一段数据里的结果。

## 常见误区

- <span class="qw-no">✕</span> 认为回测赚钱就等于策略可靠
- <span class="qw-no">✕</span> 反复使用样本外数据调参
- <span class="qw-no">✕</span> 用机器学习模型替代研究纪律
- <span class="qw-ok">✓</span> 每个策略都先写假设，再做样本外和成本检查
