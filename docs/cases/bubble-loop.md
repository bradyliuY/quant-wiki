# 泡沫循环(反身性)

## 一句话

价格上涨被「赚钱效应」自我强化——早期买者赚钱吸引更多资金与杠杆,价格再涨,直到接盘者或杠杆资金耗尽,循环反转踩踏。郁金香、南海、2000 互联网、2015 A 股、2021 加密,同一个循环反复上演了三百年。

<PlainTalk>泡沫就像滚雪球:最开始只是一小撮人发现"这东西在涨",他们赚钱的消息传开,更多人带着更多钱冲进来,雪球越滚越大。但雪球没有刹车,等没人再有新钱可滚、或大家突然发现雪球里面其实是空气,它就散架了。关键在于:泡沫不是"骗局",它每一步都是真的在赚钱——正因为真的赚,才停不下来。</PlainTalk>

## 机制拆解:这个循环为什么转得起来

1. **反身性(Soros《金融炼金术》)**:价格上涨本身就强化"还要涨"的信念,信念吸引资金,资金再推高价格。基本面不再是唯一驱动——**预期本身成了基本面**。
2. **赚钱效应是燃料**:早期买者真实赚到钱,这是最有效的广告。它把场外资金(包括从没做过交易的人)拉进来。
3. **杠杆是加速器**:融资、配资、保证金贷款放大每一轮的购买力,让循环转得更快、涨得更猛——也把反转时的杀伤力放大到同比例。
4. **没有内在刹车**:正反馈循环没有"涨多了就该停"的机制,它只会转到外力打断为止。

## 经典实例时间线

| 年份 | 事件 | 关键数字 | 循环走到哪一步 |
|------|------|----------|----------------|
| 1637 | 荷兰郁金香狂热 | 一株珍稀球茎的价格一度相当于一名工匠十年以上的收入,甚至有人用实物资产交换;数月内崩盘至一文不值 | 叙事 → 杠杆(物物交换) → 崩塌 |
| 1720 | 南海泡沫 | 南海公司股价 1 月约 £128,8 月冲上约 £1000,9 月崩盘至约 £150;牛顿亏损后自嘲"我能计算天体的运行,却无法计算人们的疯狂" | 叙事 → 场外资金 → 崩塌 |
| 2000 | 互联网泡沫 | 纳指 2000-03-10 冲上 5048 点,2002-10 最低约 1114 点(回撤约 78%);大量"新经济"公司没有盈利 | 叙事证伪 → 崩塌 |
| 2015 | A 股杠杆牛 | 上证 2015-06-12 最高 5178 点,两融余额峰值约 2.27 万亿元;6–8 月两轮千股跌停、流动性枯竭 | 杠杆加速 → 强平 → 崩塌 |
| 2021 | 加密市场 | 比特币 2021-11 冲上约 $69,000,2022 最低约 $15,500(回撤约 78%) | 场外资金 + 杠杆 → 崩塌 |

## 打断机制:为什么停不下来,又怎么断的

正反馈没有刹车,历史上泡沫的终结只有两种方式:

- **资金/杠杆耗尽**:增量资金买完了,高位只剩存量博弈,上涨失去燃料。
- **叙事被证伪**:基本面跟不上价格(2000 年盈利证伪),或政策/监管收紧(2015 年清理配资、2021 年多国监管),让"还要涨"的信念瞬间崩塌。

顶部有可识别的**警示信号**,但它们在情绪里总被无视:

- 人人都在谈论、新手开始"指导"老手
- 融资余额创历史新高、新增开户数激增
- 成交量放大但价格滞涨(边际买盘在衰竭)

## 对普通交易者的启示

- **别把「赚钱效应」当「基本面确认」**:涨得越猛,越可能离边界越近。赚钱效应是最危险的信息,因为它真实、且天然滞后于拐点。
- **识别自己是不是"最后一批接盘者"**:靠情绪和 FOMO 进场的资金,几乎总在循环的最后一环入场。
- **杠杆是泡沫的加速器,也是你账户的风险放大器**:泡沫期最不该做的事,就是加杠杆参与。
- **顶部不靠预测,靠规则**:事前定好"什么信号出现就离场"(如跌破趋势线、融资余额见顶),别靠感觉判断顶点。
