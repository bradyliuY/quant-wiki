# 追涨杀跌死循环

## 一句话

情绪驱动的负循环:大涨时眼红追高,回调时恐慌割肉,反弹后踏空懊悔,下一次大涨再追高——账户越滚越小。同一波行情,策略玩家赚期望值,情绪玩家在循环里反复做反动作。

<PlainTalk>追涨杀跌就像"自己给自己设的陷阱":看到行情大涨、别人都赚钱,你忍不住追进去;结果买在情绪顶点,一回调就慌,割肉离场;刚割完它又涨了,你懊悔得要命,心想"下次一定拿住";等下一次大涨,你又全忘了,再次追高。循环的每一步,单看都"有道理",合起来就是稳定的亏损机器。</PlainTalk>

## 机制拆解:为什么人总在循环里做反动作

1. **损失厌恶**:割肉很痛,但"赶快止损免得亏更多"的解脱感,让人在**最该拿住的时候卖出**;而浮盈时的落袋为安,又让人在**最该拿住的时候卖出**——两头都做反。
2. **羊群效应**:别人都在赚钱是最强的信号。赚钱效应天然滞后,等你看到"人人都赚"时,往往是情绪顶点。
3. **锚定**:总想着"回本"在买入价,导致该走的时候不走、该拿的时候拿不住,行动被买入价绑架,而不是被信号绑架。
4. **本质**:用**情绪代替信号**做决策。策略没问题,是人在循环里把买入/卖出的时机全做反了。

## 同一波行情:策略玩家 vs 情绪玩家

| 时点 | 情绪玩家(追涨杀跌) | 策略玩家(规则交易) |
|------|---------------------|---------------------|
| 行情启动 | 观望,"等确认" | 按信号入场 |
| 主升浪 | 忍不住追高 | 持仓,让利润奔跑 |
| 高点 | 满仓在最贵处 | 按止盈/趋势信号分批离场 |
| 回调 | 恐慌割肉,亏损兑现 | 已离场或止损纪律执行 |
| 反弹 | 踏空,懊悔,再追 | 等待下一次信号 |

同样的行情,前者是"高买低卖",后者是"低买高卖"。差的不是行情,是**有没有规则**。

## 怎么打断这个循环

把负循环变成正循环,不需要更高明的策略,只需要三件事:

- **计划交易,不盘中拍脑袋**:入场、止损、止盈都在事前定好,写下来。行情火热时的决定,十有八九是错的。
- **交易日志,找出自己卡在循环的哪一环**:每次复盘记录"我当时为什么买/为什么卖、情绪是什么",几笔之后就能看到自己反复踩的坑(追高?割肉太早?踏空报复?)。
- **用规则代替感觉**:信号触发才入场,止损触发才离场。判断买卖的唯一标准是"我的计划",不是"我感觉"。
