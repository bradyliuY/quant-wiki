# 轧空闭环(做空挤压)

## 一句话

空头持仓越重,上涨时越要回补,回补买盘再推高价格,逼出更多空头——形成"空头割肉喂饱上涨"的轧空闭环。VW/保时捷 2008 两天涨 4 倍、GameStop 2021 一月涨 17 倍,是"基本面无关"的极端上涨。

<PlainTalk>做空就是"赌它会跌":先借股票卖掉,等跌了再买回来还掉,赚差价。但空头的亏损没有上限——股价能涨多高,取决于多头的疯狂。一旦股价启动,空头要么主动割肉买回,要么被强平买回,而"买回"本身就是买盘,把股价推得更高,逼出更多空头。这就是"轧空":空头越多,上涨起来越猛,因为他们一个个都得回来买。</PlainTalk>

## 机制拆解:为什么空头是上涨的燃料

1. **风险不对称**:做多最多亏 100%(价格归零),做空**亏损无上限**(价格能涨多高不确定)。空头天然处于被动。
2. **回补是硬性买盘**:价格启动后,空头浮亏触发保证金线或被逼平仓,必须买入回补。回补是**不计价格的买盘**——买得越急,涨得越猛。
3. **轧空量越大,涨得越疯**:做空持仓占流通盘比例越高,潜在的回补买盘越重。当这个比例超过 100%,理论上空头需要买回的股票比市场上流通的还多。
4. **结束于空头出清**:轧空一旦把空头打爆到出清,上涨动力消失,价格往往快速回落——这是投机性上涨,不是价值重估。

## 打断机制:轧空怎么结束

- **空头出清**:空头要么割肉回补完毕,要么被强平爆掉,回补买盘消失,上涨失去燃料。
- **多头接不住**:轧空上涨缺乏基本面支撑,一旦空头出清,剩余多头获利了结,价格快速回落(2021 年 GameStop 高点后数月内跌去大半)。
- **监管/交易规则变化**:限制开新空头、暂停交易、提高保证金,人为改变多空力量。

## 对普通交易者的启示

- **不要裸做空**:做空的风险不对称,散户裸做空等于把"亏损无上限"挂在自己账户上。
- **极端上涨别急着用基本面解释**:可能是逼空。在轧空标的里谈估值,会被打得体无完肤。
- **顺势但要知道风在哪**:动量策略可能恰好站在轧空的风口上,顺势很爽,但拐点同样极端——用仓位和止损保护自己,别把轧空的上涨当成自己的本事。
- **警惕"轧空后"的接盘**:轧空回落又快又猛,追在轧空尾部的人损失惨重。
