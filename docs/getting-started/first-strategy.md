# 构建第一个策略

## 一句话理解

把"想法"变成"可执行的规则"，再验证它能不能赚钱——这就是构建量化策略的全部过程。本页带你从零完成第一个**双均线交叉策略**。

## 策略思想

经典的趋势跟随思想：

> 短期均线代表最近的价格动能，长期均线代表中期趋势。
> **短期上穿长期**（金叉）→ 趋势向上，买入；
> **短期下穿长期**（死叉）→ 趋势向下，卖出。

## 策略要素拆解

一个完整策略必须有 5 个要素：

```
① 信号生成  什么时候开仓（金叉买入）
② 仓位管理  买多少（固定比例/凯利）
③ 止损规则  亏多少离场（跌破长期均线/固定%）
④ 止盈规则  赚多少兑现（跟随趋势移动止盈）
⑤ 回测验证  历史数据上是否有效
```

## 完整策略定义

### 参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 短期均线周期 | 5 | 快速线 |
| 长期均线周期 | 20 | 慢速线 |
| 单笔风险 | 2% | 单次最大亏损占比 |
| 止损 | 跌破长期均线 | 趋势反转信号 |

### 交易规则

**开仓**：短期均线上穿长期均线（金叉）→ 买入

**加仓**：价格持续站上长期均线 → 持有

**平仓**：短期均线下穿长期均线（死叉）→ 卖出

**止损**：若持仓跌破长期均线且下穿 5 日均线 → 无条件离场

## 用代码表达

```python
def generate_signal(ma5, ma20, position):
    if position == 0 and ma5 > ma20:
        return "BUY"      # 金叉开仓
    elif position == 1 and ma5 < ma20:
        return "SELL"     # 死叉平仓
    return "HOLD"
```

## 验证策略的流程

1. **写规则**：把想法转化为明确的入场/出场/仓位规则
2. **历史回测**：在多年历史数据上模拟交易
3. **检查指标**：看年化收益、最大回撤、夏普、胜率、盈亏比
4. **样本外验证**：用没参与优化的数据检验（防过拟合）
5. **实盘小仓位**：先跑模拟盘或极小仓位，验证滑点/延迟
6. **逐步放大**：确认稳定后再加大仓位

## 常见误区

- ❌ **一上来就追求复杂模型**：简单模型先跑通，再逐步加复杂度
- ❌ **只优化收益不看回撤**：回撤 50% 的策略你根本拿不住
- ❌ **用全部数据优化又验证**：这是过拟合，必须留样本外数据
- ✅ **先解决"能不能执行"**：规则要能写进代码，否则不是策略
