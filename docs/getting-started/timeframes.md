# 时间框架

## 一句话理解

时间框架（Timeframe）就是你观察市场的"颗粒度"——用 1 分钟图还是 1 周图看同一段行情，看到的信息完全不同。**多周期分析是专业交易的标配。**

<PlainTalk>时间框架就像拍照的焦距：用周线看，你看到的是「这座山的整体走向」；切到分钟线，你看到的是「脚下每一步的碎石子」。同一个品种，看大图定方向、看小图找买点——这就是「大周期定方向、小周期找入场」这句口诀的由来。</PlainTalk>

## 常见时间框架

| 周期 | 单根 K 线跨度 | 适合 | 特点 |
|------|--------------|------|------|
| **1m / 5m** | 分钟级 | 日内超短、高频 | 噪声大，手续费敏感 |
| **15m / 30m** | 分钟级 | 日内波段 | 折中 |
| **1h / 4h** | 小时级 | 日内到数日 | 趋势与波段平衡 |
| **日线 D** | 1 天 | 中期趋势 | 多数人的主周期 |
| **周线 W** | 1 周 | 中长期趋势 | 过滤噪声，方向准 |
| **月线 M** | 1 月 | 大级别牛熊 | 极少交易，方向最稳 |

## 多周期分析框架

成熟的做法是 **"大周期定方向，中周期看趋势，小周期找入场"**：

```
┌─────────────────────────────────────────────┐
│ 大周期（周线/月线）                           │
│  定方向：现在是牛市还是熊市？                  │
│  回答"做什么"                                 │
├─────────────────────────────────────────────┤
│ 中周期（日线）                                │
│  看趋势：回调还是反转？                       │
│  回答"何时做"                                 │
├─────────────────────────────────────────────┤
│ 小周期（小时线）                              │
│  找入场：精确的买卖点                        │
│  回答"在哪做"                                 │
└─────────────────────────────────────────────┘
```

### 具体步骤

1. **周线定方向**：周线均线向上 → 只做多
2. **日线找趋势结构**：日线回调到支撑 → 关注入场机会
3. **小时线精确入场**：小时线出现反转信号 → 买入
4. **统一止损**：止损设在结构破坏位（日线支撑下方）

## 周期缩放关系

周期之间存在**倍数关系**，一个周期出信号，往往在更高周期有对应表现：

```
4 根 15m K 线 = 1 根 1h K 线
4 根 1h K 线  = 1 根 4h K 线
6 根 4h K 线  = 1 根日线
5 根日线      = 1 根周线
```

## 周期与策略的匹配

**选周期的关键：你的持仓时间决定周期。**

| 持仓时长 | 主周期 | 策略类型 |
|----------|--------|----------|
| 几秒~几分钟 | 1m/5m | 高频、做市 |
| 几小时~几天 | 15m/1h | 日内波段、网格 |
| 几天~几周 | 日线 | 趋势跟踪、均线 |
| 几月~几年 | 周线/月线 | 价值投资、宏观轮动 |

>  **周期错配是新手最大误区**：用周线定方向却用分钟图止损，会被日常波动打出局。

## 周期与信号质量

**周期越大，信号越可靠，但机会越少。**

| 周期 | 信号频率 | 信号质量 | 止损宽度 |
|------|----------|----------|----------|
| 小周期 | 多 | 弱（噪声多） | 窄 |
| 大周期 | 少 | 强（过滤噪声） | 宽 |

## 常见误区

- <span class="qw-no">✕</span> **频繁切换周期**：今天看 5m，明天看 4h，系统混乱
- <span class="qw-no">✕</span> **小周期逆大周期**：日线下跌趋势中在 5m 图抄底，风险极高
- <span class="qw-no">✕</span> **忽略周期切换的成本**：缩小周期意味着信号更频繁，手续费侵蚀利润
- <span class="qw-ok">✓</span> **固定周期体系**：确定主周期+次周期，严格执行多周期规则
