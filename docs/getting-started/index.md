# 🚀 新手指南

零基础渐进式学习路径，从 K 线、时间框架到构建第一个策略。

## 学习路径

按顺序学习，每篇 5-10 分钟：

| 步骤 | 主题 | 你将掌握 |
|------|------|----------|
| 1 | [什么是量化投资](./what-is-quant) | 量化的四大支柱、与主观投资的区别 |
| 2 | [市场基础](./market-basics) | 资产类别、参与者、交易机制 |
| 3 | [K 线入门](./candlestick-101) | 读懂 K 线、经典买卖形态 |
| 4 | [时间框架](./timeframes) | 多周期分析的核心思想 |
| 5 | [构建第一个策略](./first-strategy) | 完成一个可回测的量化策略 |

## 路径总览

```
[什么是量化] → [市场基础] → [K线入门] → [时间框架] → [第一个策略]
      │            │            │            │              │
      │            ├─→ 金融基础（深入）        │              │
      │            └─→ 指标大全（工具）        │              │
      └──────────────────────────────────────┴──→ 方法论（系统化）
```

## 学完这个板块后

你已经掌握了量化的核心概念和第一个策略骨架。下一步：

- **想补金融知识** → [🏛️ 金融基础](../fundamentals/)
- **想学指标工具** → [📊 指标大全](../indicators/)
- **想学策略体系** → [🎯 策略库](../strategies/)
- **想系统化方法** → [📐 方法论](../methodology/)
