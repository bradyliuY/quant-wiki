# 新手指南

## 一句话定位

这套知识库有 127 页，新手不可能一次看完。这个板块是**最短路径**：按顺序读 5 篇，每篇 5–15 分钟，最后你能写出第一个可回测的策略。这是全站唯一的纵向主线，其他板块都是你在主线上横向展开的工具。

## 学完你能做到什么

> 你能说清量化和主观的区别 → 看懂 K 线和时间周期 → 并动手写下第一版双均线策略。

一句大白话：**从"什么是量化"走到"我自己写了一个策略"**，这就是这个板块的全部目标。
