# K 线入门

## 一句话理解

K 线（蜡烛图）是记录价格走势最经典的图表形式，每根 K 线浓缩了一个时间周期内的**开盘、最高、最低、收盘**四个价格。

## K 线的构成

```
          ╭──╮
        │    │        上影线（最高价）
        │    │
        ├────┤
        │    │        实体（开盘↔收盘）
        ├────┤
        │    │
        │    │        下影线（最低价）
          ╰──╯
```

| 部分 | 含义 |
|------|------|
| **实体** | 开盘价到收盘价的区间 |
| **上影线** | 最高价到实体上沿（盘中冲高回落的痕迹） |
| **下影线** | 实体下沿到最低价（盘中杀跌被买回的痕迹） |
| **颜色** | A股红涨绿跌；欧美绿涨红跌（本站采用红涨绿跌） |

## 单根 K 线解读

### 按实体大小

- **大阳线**：收盘远高于开盘，买方主导
- **大阴线**：收盘远低于开盘，卖方主导
- **小实体（十字星）**：多空力量均衡，方向未定

### 按影线

| 形态 | 特征 | 含义 |
|------|------|------|
| **上影线长** | 冲到高位被砸回 | 上方抛压重 |
| **下影线长** | 跌到低位被拉起 | 下方承接强 |
| **上下影线都长** | 剧烈多空争夺 | 变盘信号（高波动） |

## K 线组合：买卖信号

### 看涨信号

| 组合 | 形态 | 出现位置 |
|------|------|----------|
| **锤子线** | 小实体 + 长下影线 | 下跌末期，止跌信号 |
| **看涨吞没** | 大阳线完全包住前一根阴线 | 下跌末期，反转信号 |
| **早晨之星** | 大阴→小实体→大阳 | 三根组合，强烈反转 |

### 看跌信号

| 组合 | 形态 | 出现位置 |
|------|------|----------|
| **射击之星** | 小实体 + 长上影线 | 上涨末期，见顶信号 |
| **看跌吞没** | 大阴线完全包住前一根阳线 | 上涨末期，反转信号 |
| **黄昏之星** | 大阳→小实体→大阴 | 三根组合，强烈反转 |

## 不同周期的 K 线

同一个市场，切不同周期看，信号完全不同：

```
1分钟 K 线 → 日内噪声极大，适合高频
1小时 K 线 → 日内波段
日线 K 线   → 中期趋势（多数人的主周期）
周线 K 线   → 中长期趋势，过滤噪声
月线 K 线   → 大方向（牛熊判断）
```

> **核心原则**：**大周期定方向，小周期找入场**。例如日线处于上升趋势，就只在小时级别回调时买入。

## 常见误区

- <span class="qw-no">✕</span> **单根 K 线定乾坤**：单根 K 线信号很弱，要结合位置、量能、组合
- <span class="qw-no">✕</span> **只在小周期交易**：1 分钟图噪声大，容易反复止损
- <span class="qw-no">✕</span> **把 K 线形态当必然**：形态只是概率，不是确定
- <span class="qw-ok">✓</span> **多周期共振 + 成交量确认**：信号质量大幅提升
