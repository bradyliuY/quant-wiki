# 什么是量化投资

## 一句话理解

量化投资，就是用**数学模型和程序**代替人的主观判断来做投资决策。你不必每天盯盘、凭感觉买卖，而是把一套规则写成代码，让系统自动执行。

## 与主观投资的区别

| 维度 | 主观投资 | 量化投资 |
|------|----------|----------|
| 决策依据 | 经验、直觉、盘感 | 数据、模型、统计规律 |
| 决策速度 | 慢，受情绪影响 | 快，毫秒级执行 |
| 可回测性 | 无法验证"如果当初" | 可用历史数据完整回测 |
| 纪律性 | 易受情绪干扰 | 严格执行既定规则 |
| 覆盖面 | 盯几只股票 | 全市场扫描 |
| 核心能力 | 洞察力 | 数据处理 + 建模能力 |

## 量化投资的四大支柱

### 1. 数据（Data）

一切的起点。包括：

- **行情数据**：OHLC（开盘/最高/最低/收盘）、成交量、成交额
- **基本面数据**：财务指标（营收、利润、PE/PB）、行业数据
- **另类数据**：新闻情绪、社交媒体热度、卫星图像等

> 数据质量决定模型上限。**垃圾进，垃圾出**（GIGO）是量化第一铁律。

### 2. 策略（Strategy）

把投资想法转化为可执行的规则。一个完整的策略包含：

```
信号生成（何时买入/卖出）
    ↓
仓位管理（买多少）
    ↓
风险控制（亏多少离场）
    ↓
交易执行（怎么下单）
```

### 3. 回测（Backtest）

用历史数据验证策略是否有效。这是量化和主观投资最本质的区别——**先验证，后实盘**。

### 4. 执行（Execution）

把策略部署到实盘。包括下单系统、风控系统、监控系统。

## 一个最简单的量化策略长什么样

```python
# 双均线交叉策略（示意伪代码）
def generate_signal(closes):
    ma5 = average(closes[-5:])   # 5日均线
    ma20 = average(closes[-20:]) # 20日均线

    if ma5 > ma20:               # 金叉
        return "买入"
    elif ma5 < ma20:             # 死叉
        return "卖出"
    else:
        return "持有"
```

虽然简单，但它具备了量化策略的全部要素：**明确的规则 + 可复现 + 可回测**。

## 量化的常见误解

- ❌ **量化 = 稳赚不赔**：量化只是提高赢面，任何策略都有亏损期
- ❌ **量化 = 高频交易**：高频只是量化的一种，更多是低频的中长线策略
- ❌ **量化 = 复杂数学**：很多有效策略逻辑很简单（如均线、动量），关键是纪律执行
- ✅ **量化 = 用规则约束人性**：核心价值在于避免情绪化决策
