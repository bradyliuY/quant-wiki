# 动量策略

"强者恒强"——过去的强势会延续，买入表现最好的资产，卖出表现最差的。

## 策略一览

| 策略 | 核心思想 | 适合市场 |
|------|----------|----------|
| [双动量轮动](./dual-momentum) | 绝对动量 + 相对动量双重过滤 | 多资产配置 |
| [RSI 动量](./rsi-momentum) | RSI 50 上方运行代表趋势延续 | 趋势+动量 |
| [相对强弱排名](./strength-ranking) | 定期买入排名靠前的资产 | 多品种轮动 |

## 共性特征

- **定期再平衡**：动量策略靠定期调仓捕捉持续性，非每日交易
- **趋势过滤器**：先确认市场整体环境（牛市做多、熊市空仓）
- **避免逆向**：不碰逆势品种，即使它"便宜"
- **择时重要**：动量在趋势市场中表现优异，在急转行情中回撤大
