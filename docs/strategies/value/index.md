# 价值低估策略

不看股价涨跌，看"这家公司到底值多少钱"——用估值与分红，赚基本面回归的钱。

## 策略一览

| 策略 | 难度 | 核心思想 | 适合市场 |
|------|------|----------|----------|
| [低估值筛选](./low-valuation) | <span class="dlv dlv-intermediate">进阶</span> | 用 PE/PB 挑便宜的好公司，赚估值修复 | 股票池 |
| [高股息收息](./dividend-yield) | <span class="dlv dlv-intermediate">进阶</span> | 买高分红的公司，赚分红 + 复利 | 现金流需求 |

> 难度：入门 → 进阶 → 挑战。本族为「进阶」——需要读懂财报、耐得住长期不涨的寂寞，适合技术面入门后想再走一条路的同学。

## 共性特征

- **基本面数据驱动**：靠财务报表（盈利、负债、现金流）而非 K 线信号。
- **长线持有**：估值修复以季度/年为周期，不是日内的买卖。
- **价值陷阱风险**：便宜可能是"合理"——基本面持续恶化时，越跌越买最危险。
- **需要财报阅读能力**：会看 PE/PB/ROE/现金流，才有能力过滤陷阱。
