# 低估值筛选策略（便宜买好货）

## 一句话

用 PE、PB 等估值指标从全市场挑"便宜的好公司"，分批买入后等价格回归价值——赚的是**估值修复**的钱，而不是靠猜短期涨跌。

<PlainTalk>低估值策略就像逛超市买打折的好货：同样一箱牛奶，别人标 80 元、这家标 50 元，只要不是快过期，聪明人都会先买打折的。股票也一样——用 PE（回本年限）和 PB（打折力度）给公司"标价"，等它打折到你满意再出手，剩下的交给时间让它涨回去。</PlainTalk>

## 核心逻辑

价值投资的信念是：**价格短期由情绪决定，长期由价值决定**。一只优质公司可能因为市场恐慌、行业冷门被错杀到"便宜"的价格，但只要公司基本面没坏，价格迟早会回归合理估值——这段"低估 → 合理"的距离，就是策略的利润来源。

## 交互演示：PE 到底是什么意思？

先弄懂策略的"标尺"再谈买卖。PE = 股价 ÷ 每股收益，白话就是"按现在赚钱速度，多少年能回本"。拖拖滑块感受一下：

<PESim />

**关键**：PE 越低越"便宜"，但前提是**盈利稳定**——如果明年利润下降，回本年限会被拉长。所以低估值策略必须搭配质量过滤（ROE、负债率、现金流），只买"便宜且健康"的。

## 入场规则

- **估值便宜**：PE 历史分位 < 20%，或 PB < 1（破净）；不同行业阈值不同，要和同行比。
- **质量过关**（防价值陷阱）：ROE > 10%、资产负债率 < 60%、经营现金流为正。
- **股息兜底**：股息率 > 2% 更佳——即使估值不修复，分红也降低持有成本。
- **分批建仓**：分 3 批，每批 1/3，价格再低 5% 补一批，避免"接飞刀接满仓"。

## 出场规则

- **估值修复**：PE/PB 回到历史 50% 分位以上（合理中枢），分批止盈。
- **基本面恶化**：业绩连续两季下滑、ROE 跌破门槛、现金流恶化 → 无条件离场（**这是唯一硬止损**）。
- **时间止损（可选）**：持有 2-3 年仍未修复，说明"便宜"可能另有原因，重新审视是否看错。

## 仓位管理

- 分散 10-20 只，单只不超过 5%，稀释个股"价值陷阱"风险。
- 每只分 3 批建仓，避免一次性满仓。
- 价值策略不加杠杆——低估可以更低估，杠杆会让你在修复前先爆仓。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：大市值、数据完整、财报透明的市场（A 股、美股）。
- <span class="qw-ok">✓</span> 适合：长期配置型资金，能接受 1-2 年不涨的心理考验。
- <span class="qw-no">✕</span> 不适合：纯题材炒作、无基本面可言的标的。
- <span class="qw-no">✕</span> 不适合：短期交易者——估值修复以季度/年为单位，等不了就做别的。

## 常见误区

- <span class="qw-no">✕</span> 便宜就等于安全：业绩持续下滑的公司，低 PE 会一直"低"，这是价值陷阱。
- <span class="qw-ok">✓</span> 用 [ROE/负债率/现金流](../../fundamentals/fundamental-analysis/financial-statements) 过滤，只买"便宜且健康"。
- <span class="qw-no">✕</span> 不看历史分位只比绝对数值：银行 5 倍 PE 正常、科技股 5 倍可能有问题，要和自身历史比。
- <span class="qw-ok">✓</span> 结合 [PEG（增速）](../../fundamentals/fundamental-analysis/valuation) 看：便宜 + 增长停滞，可能只是"合理"。
