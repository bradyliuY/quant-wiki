# 高股息收息策略（稳稳的分红）

## 一句话

买入股息率高且分红稳定的公司，靠**分红**赚钱而非靠价差——股价不动你也有现金流进账，是小白最容易上手的"睡后收入"策略。

<PlainTalk>把高股息股票当成一个"会分红的存钱罐"：你存钱进去，它每年定期往你手里塞利息（分红），而且利息还在逐年复利变多。你不必天天盯盘、不必猜涨跌——只要公司还在赚钱、还在分红，你的现金流就不会断。这正是退休人群和长期投资者最爱的收息打法。</PlainTalk>

## 核心逻辑

高股息策略的信念是：**长期看，分红贡献了股票收益里很大一块**。与其赌一只股票能不能翻倍，不如锁定一批"稳定赚钱、愿意分红"的公司，让它们每年给你发钱。指数长期回报里，股息再投资（红利复投）占相当比例——这就是"收息 + 复利"的威力。

## 入场规则

- **股息率 > 4%**：低于这个数，不如买低风险理财（还要承担股价波动）。
- **分红可持续**：连续 5 年以上分红、派息率（分红/利润）< 70%、经营现金流为正。
- **行业分散**：银行、公用事业、能源、消费轮着配，别全押一个行业。
- **质量底线**：负债率不过高、业绩稳定，避免"高息陷阱"（靠借债维持分红的公司）。

## 出场规则

- **股息率失真**：股价大涨导致股息率跌破 3% → 换到更高息的标的（锁定价差收益）。
- **分红削减**：公司下调或取消分红 → 无条件清仓（收息逻辑已破坏）。
- **基本面恶化**：连续两季亏损或现金流恶化 → 离场，别为了收息扛亏损股。

## 仓位管理

- 分散 15-30 只，单只不超过 5%。
- **红利再投资**：分红不取出、继续买入，享受复利——这是高股息策略最大的复利来源。
- 可搭配 [低估值筛选](./low-valuation) 一起用：高息 + 低估双条件，选出的更靠谱。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：股息文化成熟的市场（A 股红利、港股、美股公用事业）。
- <span class="qw-ok">✓</span> 适合：追求现金流的人——退休人群、长期定投者。
- <span class="qw-no">✕</span> 不适合：追求高成长、高波动的投资者——收息策略一年 8% 左右，涨得慢。
- <span class="qw-no">✕</span> 不适合：高利率环境（无风险利率高时，分红吸引力下降，股价承压）。

## 常见误区

- <span class="qw-no">✕</span> 只看股息率不看可持续性：有的公司用借债维持分红，分红迟早砍掉。
- <span class="qw-ok">✓</span> 检查[派息率与现金流](../../fundamentals/fundamental-analysis/financial-statements)，分红必须由真金白银撑起来。
- <span class="qw-no">✕</span> 把「高息」当「高回报」：除息日股价会扣掉分红，别以为"白赚"。
- <span class="qw-ok">✓</span> 坚持[红利再投资](../../methodology/risk-management/position-sizing)：取出消费 vs 复投，长期收益差一倍不止。
