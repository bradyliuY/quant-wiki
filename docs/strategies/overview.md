# 策略总览

## 一句话总结

策略的本质是对"**行情会如何演变**"的一个假设——趋势会延续、价格会回归、强者恒强……假设对了赚钱，假设错了亏钱。所以选策略的第一步不是挑工具，而是认清现在是什么行情。

## 策略族对比

| 策略族 | 核心假设 | 收益特征 | 主要风险 | 持仓周期 | 复杂度 | 资金要求 |
|--------|----------|----------|----------|----------|--------|----------|
| [趋势跟踪](../strategies/trend-following/) | 趋势会延续 | 趋势段赚大钱，震荡段小亏 | 震荡市反复止损 | 中长线（日-周） | 低 | 中 |
| [均值回归](../strategies/mean-reversion/) | 价格会回归均值 | 震荡市稳定收益 | 强趋势中逆势被套 | 短中线（时-日） | 低 | 低 |
| [动量策略](../strategies/momentum/) | 强者恒强 | 趋势加速段超额收益 | 风格切换急回撤 | 中长线（周-月） | 中 | 中 |
| [形态交易](../strategies/pattern-trading/) | 形态会重演 | 突破行情收益可观 | 假突破频发 | 中短线（日） | 中 | 低-中 |
| [量化进阶](../strategies/quantitative/) | 组合比单标的优 | 持续小胜靠统计优势 | 极端行情集中暴露 | 自定义 | 高 | 高（多因子/网格） |

## 怎么选策略（决策路径）

```
现在是什么行情？
│
├─ 强趋势（单边上涨/下跌）→ 趋势跟踪 / 动量
├─ 震荡（区间来回）→ 均值回归 / 网格
├─ 高波动（波动放大）→ 趋势跟踪（吃波动），但要严止损
├─ 低波动（窄幅收敛）→ 均值回归 / 突破形态（蓄势）
└─ 恐慌暴跌 → 空仓 / 对冲，别接飞刀
```

## 新手入门路线

完全新手别 18 个策略都学。按难度阶梯先走通一条线，建立"完整一笔交易"的体感：

1. **双均线交叉**（入门）——理解"顺势 + 金叉死叉"，是全站的入门范本
2. **通道突破**（入门）——理解"突破入场 + 追踪离场"，同样是顺势思路
3. **RSI 反转**（进阶）——换个方向：顺势里的回调买点
4. **布林带回归**（进阶）——理解"震荡市 + 均值回归"与趋势策略互为补充

每学完一个，回看它页内的「一笔交易的走读」时间线，比规则清单更接近实战。之后再按上方「策略 × 行情矩阵」扩展到别的策略族。

## 策略组合建议

成熟做法不是"选一个最优策略"，而是**多策略互补**：

- **趋势跟踪 + 均值回归**：一个吃趋势、一个吃震荡，覆盖大部分行情——这是最常见的攻守搭配。
- **动量 + 风险平价**：一个进攻、一个防守，平滑组合曲线。
- 关键是用[组合管理](../methodology/risk-management/portfolio-risk)控制整体回撤，而非追求单策略最优。
