# 网格交易策略

## 一句话

在震荡区间内预设若干等间距的网格价位，价格每下一格买入、每上一格卖出，靠震荡行情的反复波动"机械套利"，赚区间内的高抛低吸差价。

## 核心逻辑

网格交易放弃对方向的预测，用**机械纪律**在震荡区间内反复收割：把资金分成 N 份，每跌到一格就买入一份，每涨到一格就卖出一份。只要价格不脱离网格区间，每一次上下震荡都能锁定一格利润。策略的盈亏结构是"赚小钱高频、亏大钱低频"——最大的风险是价格单边跌破网格下沿，导致仓位被套。

回放中可见：价格在网格区间内来回穿越，每一格都被"买在跌、卖在涨"——区间震荡越充分，网格收益越稳定。但当价格单边下行突破下沿时，网格会累积满仓套牢，这是策略的主要亏损场景。

## 入场规则

- **区间判定**：用布林带、ATR 或历史高低点确定震荡区间上下沿（如过去 60 日高/低点）。
- **网格划分**：区间均分 10–20 格，每格间距 ≥ 1×ATR（避免过密被噪声反复扫单）。
- **初始仓位**：先在区间中部建立 30%–50% 底仓，余下资金按格位分批承接。
- **品种选择**：波动规律、无明显单边趋势的品种（区间震荡的币种、商品、指数）。

## 出场规则

- **每格止盈**：每上涨一格卖出对应买入的份额，落袋为安。
- **越界止损**：价格有效跌破区间下沿（收盘价 + 1×ATR），止损离场。
- **越界止盈**：价格放量突破上沿，清仓兑现，可转用趋势策略跟进。
- **网格收敛**：波动率显著收窄时暂停开新网格，避免手续费损耗。

## 仓位管理

- 总投入不超过总资金的 30%–50%，剩余作为"越界自救"的缓冲。
- 每格仓位 = 网格总资金 / 网格数，等额分配，勿因下跌加重仓位（避免摊平思维）。
- 单边趋势中网格越套越深，必须设硬性止损，不能无限摊薄。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：震荡区间明确、波动反复的品种（区间震荡的 BTC、黄金、指数）。
- <span class="qw-ok">✓</span> 适合：现货/无杠杆账户——网格持仓时间较长，杠杆会放大越界风险。
- <span class="qw-no">✕</span> 不适合：单边上涨（网格会过早卖飞）或单边下跌（网格不断套牢）行情。
- <span class="qw-no">✕</span> 不适合：手续费高的市场，高频来回成交会吃掉大部分利润。

## 常见误区

- <span class="qw-no">✕</span> 网格永不失败：单边下跌突破下沿时网格会满仓深套，必须设止损。
- <span class="qw-ok">✓</span> 网格本质是"区间判断 + 纪律执行"，区间错了方向就全错。
- <span class="qw-no">✕</span> 越跌越加、无限摊薄：这是网格最大的诱惑与陷阱。
- <span class="qw-ok">✓</span> 动态调整网格：用 [ATR](../../indicators/volatility/atr) 或波动率自适应网格间距，波动大时放宽、波动小时收紧。
