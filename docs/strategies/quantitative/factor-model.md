# 多因子模型

## 一句话

用价值、动量、质量、低波动等量化因子给全市场打分，按因子得分构建组合，赚取系统性因子溢价的收益，是机构量化最核心的选股/选资产框架。

## 核心逻辑

多因子模型的信念是：市场存在可重复、可解释的**风险溢价来源**（因子）。例如小市值股票长期跑赢大盘（规模因子）、前期上涨的继续上涨（动量因子）、财务质量好的公司风险更低（质量因子）。模型把多个因子合成一个综合得分，定期买入得分最高的组合，卖出得分最低的，让组合长期暴露在多个有效因子上。

## 入场规则

- **因子选择**：价值（PB/PE）、动量（过去 6–12 个月收益）、质量（ROE/毛利率）、低波动（历史波动率）、规模（市值）。
- **打分合成**：各因子标准化（z-score）后按权重加权，如价值 30% + 动量 25% + 质量 25% + 低波 20%。
- **组合构建**：买入综合分前 10%–20% 的标的，等权或按因子得分加权。
- **基准过滤**（可选）：仅在市场整体趋势向上时满仓暴露股票因子。

## 出场规则

- **定期再平衡**：月度或季度重算因子得分，排名跌出前 30% 即剔除。
- **因子止损**：组合相对基准超额收益连续 N 期走弱，可降低股票因子暴露、增配防守资产。
- 不做单票止损：多因子模型的"风控"在组合层面，而非个股层面。

## 仓位管理

- 分散持仓 20–50 只，稀释个股特异风险。
- 因子暴露控制：单一因子权重不超过 40%，避免风格极端暴露。
- 结合 [风险平价](../quantitative/risk-parity) 思想，用波动率预算分配股票/债券仓位。

## 回测参考

| 市场 | 周期 | 胜率 | 年均收益 | 最大回撤 | 夏普 |
|------|------|------|----------|----------|------|
| A 股全市场 | 月度 | 58% | 16% | 22% | 0.7 |
| 美股全市场 | 月度 | 60% | 14% | 18% | 0.9 |

> 示意数据：因子模型收益高度依赖因子选择与权重，且受风格轮动影响显著。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：标的数量多、数据完整的市场（A 股、美股全市场）。
- <span class="qw-ok">✓</span> 适合：长期配置型资金，能承受因子回撤期的波动。
- <span class="qw-no">✕</span> 不适合：标的稀少的小市场，因子暴露无法充分分散。
- <span class="qw-no">✕</span> 不适合：短期交易者——因子溢价需要以月/季度为单位兑现。

## 常见误区

- <span class="qw-no">✕</span> 叠加过多因子：因子之间高度相关，看似多元实则重复暴露。
- <span class="qw-ok">✓</span> 用 [相关性分析](../../methodology/risk-management/portfolio-risk) 检查因子冗余，保留低相关因子的组合。
- <span class="qw-no">✕</span> 忽视 [过拟合](../../methodology/backtesting/common-pitfalls)：用历史数据反复调权重得到的"最优"参数，未来大概率失效。
- <span class="qw-ok">✓</span> 做 [样本外检验](../../methodology/backtesting/walk-forward)：因子模型最容易自欺，必须用滚动样本外验证。
