# 头肩形态交易

## 一句话

识别由左肩、头部、右肩构成的头肩顶/底形态，在跌破/突破颈线时顺势离场或入场，是反转形态中置信度最高、目标测算最明确的策略之一。

## 核心逻辑

头肩形态是趋势反转的"全景图"：头肩顶出现在上升趋势末端，中间的头部创新高但量能不配合（顶背离），随后的右肩无法再创新高，最终跌破颈线确认反转；头肩底是其镜像。形态的可靠性来自**三个低点/高点的节奏**——第一次回落、强力反弹、衰竭反弹，清晰刻画了多空力量的此消彼长。头部成交量最大（情绪顶峰），右肩缩量（动能衰竭）。

## 入场规则

- **形态条件**：头部比肩部低/高 > 5%，两肩价差 < 5%，头肩形态时间跨度 > 20 天。
- **头肩底入场**：收盘价放量突破颈线，或突破后回抽颈线不破时买入。
- **头肩顶离场/做空**：收盘价跌破颈线，或反抽颈线受阻时做空/清仓。
- **量能验证**：头肩底头部放量、右肩缩量；头肩顶头部量能不配合。

## 出场规则

- **目标止盈**：目标价 = 颈线价 +（颈线价 − 头部价）[头肩底] 或颈线价 −（头部价 − 颈线价）[头肩顶]。
- **止损**：头肩底止损设于右肩下方；头肩顶止损设于颈线上方。
- **回抽逃命**：头肩顶跌破颈线后的回抽，是最后的离场机会，勿心存侥幸。

## 仓位管理

- 单笔风险 ≤ 2% 总资金；头肩形态置信度高，可适度放大仓位。
- 突破颈线建半仓，回抽确认加半仓，降低一次性入场风险。
- 头肩形态完成后的目标空间大，可采用"半仓止盈 + 半仓移动止盈"的结构。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：趋势末端、形态清晰且时间跨度足够（> 20 天）的大级别反转。
- <span class="qw-ok">✓</span> 适合：指数与大盘股——参与者多、形态更标准。
- <span class="qw-no">✕</span> 不适合：快速震荡的短线行情，头肩形态时间跨度不足，容易误判。
- <span class="qw-no">✕</span> 不适合：无颈线支撑、形态不完整的情况，宁可不做。

## 常见误区

- <span class="qw-no">✕</span> 凭"长得像"就交易：头肩形态必须满足颈线、量能、时间三重条件。
- <span class="qw-ok">✓</span> 用**量价背离**佐证：头部创新高但量能萎缩（或 RSI 顶背离），反转概率大增。
- <span class="qw-no">✕</span> 头肩顶出现却不减仓：多数散户等到深度套牢才离场，头肩形态是"预警系统"。
- <span class="qw-ok">✓</span> 形态完成后的回抽是机会而非威胁：回抽颈线不破是更优的入场/加仓点。
