# 三角形突破策略

## 一句话

在价格收敛成三角形（上升/下降/对称）后，等待放量突破三角形边界时顺势入场，目标价为"突破点 ± 三角形高度"，赚取整理结束后趋势继续延伸的钱。

## 核心逻辑

三角形是趋势中期的"换挡整理"：多空双方在逐渐收窄的空间里博弈，成交量萎缩说明分歧在收敛。当某一方最终胜出（放量突破边界），价格将沿突破方向快速运行。三角形不预测方向（对称三角形尤其如此），策略的本质是**双向等待突破**——向上突破追多、向下突破做空/离场，把方向选择权交给市场。

## 入场规则

- **形态条件**：触碰边界 ≥ 4 次、形成时间 10–30 天、量能持续萎缩。
- **突破入场**：收盘价突破边界 + 放量（> 20 日均量 1.5 倍）。
- **回踩入场**：突破后回踩边界（此时支撑/压力互换）不破，二次入场。
- **方向纪律**：上升三角形突破上沿做多；下降三角形跌破下沿做空；对称三角形双向等待。

## 出场规则

- **目标止盈**：目标价 = 突破点 ± 三角形高度，到位分批止盈。
- **止损**：放回三角形内部（突破失败），或止损设于对侧边界外 1×ATR。
- **时间止损**：突破后 5 个交易日未走出行情，减仓观察。

## 仓位管理

- 单笔风险 ≤ 1.5% 总资金，三角形高度越大的形态目标空间越大。
- 突破当日建半仓，回踩确认后加仓，避免一次性追高。
- 三角形形态频繁出现在趋势中继，突破后顺势持仓，用移动止盈保护利润。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：趋势中继的整理形态，出现在明显趋势中途时可靠性最高。
- <span class="qw-ok">✓</span> 适合：波动收敛明显、形态清晰的标的。
- <span class="qw-no">✕</span> 不适合：横盘终局的无趋势市场——三角形可能演变为矩形或反转。
- <span class="qw-no">✕</span> 不适合：接近顶点仍未突破的"迟到突破"，力度弱、假突破多。

## 常见误区

- <span class="qw-no">✕</span> 预设方向：对称三角形方向不明，必须双向等待突破，不可提前下注。
- <span class="qw-ok">✓</span> 用**量能**区分真伪突破：放量突破有效，缩量突破大概率假突破。
- <span class="qw-no">✕</span> 把三角形当精确价位：边界是区间而非精确线，突破需以收盘价确认。
- <span class="qw-ok">✓</span> 形态出现的位置决定性质：趋势中继的三角形是顺势信号，底部/顶部的三角形更可能是反转。
