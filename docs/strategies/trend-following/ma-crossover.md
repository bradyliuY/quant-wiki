# 双均线交叉策略

## 一句话

用快速均线与慢速均线的关系判断趋势的方向与转折，金叉做多、死叉做空/离场，吃趋势启动到衰竭中间最肥美的一段，是最经典的顺势而为策略。

## 核心逻辑

双均线交叉的核心思想是：**用滞后换取确定**。慢速均线代表市场平均持仓成本的长期方向，快速均线代表短期资金动向。当短期成本上穿长期成本（金叉），说明买方力量正在压倒卖方；反之死叉则说明卖方占优。交叉策略放弃抄底逃顶的完美时机，只赚趋势确认后的确定性收益。

## 入场规则

- 快速均线（如 MA5）上穿慢速均线（如 MA20），且穿越点之前两条均线已纠缠或下行过（避免高位追进）。
- 收盘价站上慢速均线，确认金叉有效性。
- 过滤条件（可选）：金叉时价格位于前 20 日高点上方 5% 以内，或成交量大于 5 日均量的 1.2 倍。
- 只做多不逆势：只在慢速均线方向向上时接受金叉信号。

## 出场规则

- **止盈/离场**：快速均线下穿慢速均线（死叉）离场，让利润奔跑。
- **止损**：跌破入场 K 线最低点或固定 3%–5% 止损。
- **移动止盈**：持仓中价格跌破 10 日均线可先减半仓，死叉清仓。

## 仓位管理

- 单笔风险控制在总资金的 1%–2%，即：仓位 = 可承受亏损 / (入场价 − 止损价)。
- 顺势行情可逐步加仓：价格沿 20 日均线企稳时金字塔加仓，每次加仓不超过底仓一半。
- 震荡市信号频繁，此时应降低仓位或暂停交易，避免"左右挨打"。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：有明确趋势的品种，如宽基指数、主流加密货币、大宗商品。
- <span class="qw-ok">✓</span> 适合：日线及以上周期，趋势持续时间长。
- <span class="qw-no">✕</span> 不适合：长期横盘震荡的品种（信号频繁、止损不断）。
- <span class="qw-no">✕</span> 不适合：A 股无涨跌幅限制的小市值妖股，假突破极多。

## 常见误区

- <span class="qw-no">✕</span> 金叉就一定涨：金叉只是概率优势，必须配合止损控制单笔风险。
- <span class="qw-no">✕</span> 参数越灵敏越好：短周期均线信号多、损耗大；长周期均线信号少但单笔质量高。
- <span class="qw-ok">✓</span> 先确认市场环境：用 [ADX](../../indicators/trend/adx) 判断趋势强弱，ADX > 25 时才启用交叉策略。
- <span class="qw-ok">✓</span> 与 [RSI](../../indicators/momentum/rsi) 结合：趋势中 RSI 回踩 50 不破再金叉，信号质量更高。
