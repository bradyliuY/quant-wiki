# MACD 交易系统

## 一句话

MACD 交易系统用快慢 EMA 的差值（DIF）与其信号线（DEA）的金叉死叉，结合零轴位置判断趋势方向与动能变化，是一套完整的"方向 + 入场 + 离场"交易系统。

## 核心逻辑

MACD 本质是**双 EMA 平滑后的趋势跟随工具**：DIF = EMA12 − EMA26，代表短期动量相对长期动量的偏移；DEA 是 DIF 的 9 日均线，起平滑过滤作用；柱状图为 DIF − DEA，直观显示动能加速还是衰减。零轴是多空分界线，DIF 在零轴上方代表多头市场，下方代表空头市场。金叉发生在零轴上方时是**强势顺势买点**，发生在零轴下方时只是**弱势反弹**。

## 入场规则

- **多头入场**：DIF > 0 且 DIF 上穿 DEA，柱状图由绿转红。
- **零轴上方回踩金叉**（优选）：价格回调后 MACD 在零轴上方二次金叉，属于趋势中继买点。
- **过滤**：配合价格站上 60 日均线，或 ADX > 25 确认趋势存在。
- 放弃零轴下方的金叉（除非做短线反弹且严格止损）。

## 出场规则

- **死叉离场**：DIF 下穿 DEA 且价格跌破 20 日均线，坚决离场。
- **柱状图预警**：柱状图连续三根缩短，可先减半仓。
- **止损**：跌破入场 K 线最低点，或 DIF 快速回落穿越零轴时无条件离场。

## 仓位管理

- 单笔风险 ≤ 总资金 2%，止损位设在入场 K 线低点下方。
- 柱状图放大（动能加速）阶段可持有或小幅加仓，柱状图缩短阶段只减不加。
- 顶部区域（DIF 高位钝化、价格创新高但 MACD 不创新高形成顶背离）应主动降仓。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：趋势明确的指数、商品期货、主流币种，日线及以上周期。
- <span class="qw-ok">✓</span> 适合：与均线、趋势线组合成多条件过滤的交易系统。
- <span class="qw-no">✕</span> 不适合：低波动横盘品种——金叉死叉反复出现，手续费与滑点损耗大。
- <span class="qw-no">✕</span> 不适合：消息驱动的暴涨暴跌行情，MACD 反应太慢。

## 常见误区

- <span class="qw-no">✕</span> 把 MACD 当预测工具：它只是动量确认工具，永远滞后于价格。
- <span class="qw-no">✕</span> 死叉必走、金叉必买：必须结合零轴位置和趋势环境过滤信号。
- <span class="qw-ok">✓</span> 用**背离**做辅助：价格创新高、MACD 高点走低（顶背离）是减仓预警，详见 [MACD 指标](../../indicators/trend/macd)。
- <span class="qw-ok">✓</span> 多周期确认：日线金叉 + 周线 DIF 上穿零轴，共振时可靠性大幅提升。
