# 布林带回归策略

## 一句话

利用价格向均值回归的特性，在价格触及布林带下轨且波动收敛时买入、反弹到中轨或上轨时卖出，赚震荡市中"价格偏离均线后回归"的钱。

## 核心逻辑

布林带由中轨（20 日均线）和上下轨（中轨 ± 2 倍标准差）构成，约 95% 的价格落在带内。回归策略的前提是**市场处于震荡状态**：此时价格过度偏离均线后，就像被拉长的橡皮筋，倾向于弹回均值。策略的关键不是"触下轨就买"，而是确认震荡环境 + 偏离动能衰竭 + 出现反转确认信号。

## 闭环视角

均值回归是一个天然的循环：价格偏离均值 → 买入 → 价格回归 → 卖出 → 再偏离 → 再循环。赚的是"偏离后修复"的钱，单次利润薄，靠震荡市里的反复循环积累期望值。

这个循环只在**震荡市**成立。若带宽张开进入趋势，价格"骑着下轨"持续偏离，循环的"回归"环节迟迟不来，策略就从正期望变成负期望——所以判定环境（带宽收窄）是这个循环能否持续的前提。

## 入场规则

- 价格触及或跌破布林带下轨（2 倍标准差）。
- 带宽（Band Width）收窄或走平，排除强趋势（趋势中带是张开的）。
- 确认信号：当日收阳收回带内，或出现长下影线、看涨吞没等 K 线组合。
- RSI(14) 进入超卖区（< 30）或出现底背离，形成共振。

## 出场规则

- **止盈**：价格反弹至中轨（20 日均线）附近减半仓，上轨附近全部离场。
- **止损**：跌破下轨后继续放量下行超过 2×ATR，或收盘价连续 3 日收于下轨外，立即止损。
- **时间止损**：入场后 5 个交易日仍未反弹，离场（资金效率优先）。

## 仓位管理

- 单笔风险 ≤ 1.5% 总资金，止损距离用 ATR 衡量：仓位 = 风险额 / 止损距离。
- 震荡市信号较多，单品种仓位宜低于趋势策略，保留多品种分散。
- 一旦带宽开始张开（变盘），立即停止回归交易，避免在趋势启动初期逆势抄底。

## 适合/不适合的市场

- <span class="qw-ok">✓</span> 适合：长期横盘、波动率稳定的品种（黄金、国债 ETF、大盘蓝筹）。
- <span class="qw-ok">✓</span> 适合：有明确价格中枢（如区间震荡、水平通道）的市场。
- <span class="qw-no">✕</span> 不适合：单边强趋势品种——"骑着下轨"持续下跌会让策略连续亏损。
- <span class="qw-no">✕</span> 不适合：事件驱动、消息频繁的标的，价格偏离缺乏回归动力。

## 常见误区

- <span class="qw-no">✕</span> 触下轨就抄底：趋势中的触轨不反弹，抄底抄在半山腰。
- <span class="qw-ok">✓</span> 先判震荡还是趋势：用 [ADX](../../indicators/trend/adx) 或带宽历史分位区分环境。
- <span class="qw-no">✕</span> 忽略带宽形态：带宽收窄后的"张口突破"是趋势信号，此时应反向使用突破策略。
- <span class="qw-ok">✓</span> 配合 [RSI](../../indicators/momentum/rsi) 与 K 线确认：触轨 + 超卖 + 反转 K 线三者共振，胜率显著高于单触轨信号。
