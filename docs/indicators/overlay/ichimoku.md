# 一目均衡表（Ichimoku Kinko Hyo）

## 一句话总结

一目均衡表用五条线 + 一片"云"把趋势方向、支撑阻力、买卖点、波动区间浓缩到一张图上，"一眼看平衡"，适合趋势跟踪与多周期过滤。

## 公式

```
转换线 = (9 日最高 + 9 日最低) / 2
基准线 = (26 日最高 + 26 日最低) / 2
先行带 A = (转换线 + 基准线) / 2，向前平移 26 期
先行带 B = (52 日最高 + 52 日最低) / 2，向前平移 26 期
云层   = 先行带 A 与 B 之间的区域
迟行线 = 当日收盘价，向后平移 26 期（画在当前 K 线上）
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 转换线 | 9 | 短周期平衡 | 短线可缩 |
| 基准线 | 26 | 中周期平衡 | 长线可放 |
| 先行带 B | 52 | 长周期平衡 | 决定云层厚度 |
| 平移 | 26 | 时间位移 | 一般不动 |

## 信号解读

### 买入/看多信号
- 价格在**云层上方**运行：整体多头结构，回调至云顶/基准线是买点。
- **转换线上穿基准线**且云层由薄转厚：多头行情启动。
- 迟行线在 26 期前价格上方：历史走势确认当前强势。

### 卖出/看空信号
- 价格在**云层下方**：整体空头，反抽云底/基准线是卖点。
- 转换线下穿基准线且云层转薄：空头行情展开。
- 迟行线在历史价格下方：确认弱势。

### 背离或其他高级信号
- **云层厚度 = 波动预期**：云厚说明多空分歧大、支撑阻力强；云薄则易突破。
- 价格穿越云层是"变色龙"式的状态切换，配合 RSI 背离判断真假突破。
- "乌云翻转 / 三武士"等 K 线形态在云层边界处效果更强。

## 实战用法

- **多周期过滤**：周线在云上、日线回踩云顶，顺势做多——这是最经典的一目用法。
- **入场三要素**：转换线金叉基准线 + 价格在云上 + 迟行线在高位，三者共振。
- **止损参考**：云层边界和基准线是天然的动态止损位。

## 常见误区

- ❌ 只看一条线：一目均衡表的精髓是"线 + 云 + 迟行线"整体配合。
- ✅ 把它当成多周期一体化的框架而非单一信号。
- ❌ 云层被突破就立刻追：先确认是真突破还是"云薄假突破"。
- ✅ 用 RSI/成交量等验证突破质量。
