# 一目均衡表（Ichimoku Kinko Hyo）

## 一句话总结

一目均衡表用五条线 + 一片"云"把趋势方向、支撑阻力、买卖点、波动区间浓缩到一张图上，"一眼看平衡"，适合趋势跟踪与多周期过滤。

<PlainTalk>一目均衡表像把好几个时间周期叠在同一张「天气云图」上：转换线、基准线是两条快慢不同的均线，中间夹着的那片「云」是多空交战的地带。云层厚，说明两边力量都强、谁也吃不掉谁，支撑压力自然扎实；云层薄，说明一方没力气，行情容易一口气穿过去。看这张图，就像看云图判断天气：价格在云上、云下还是云里，对应三种不同的打法。</PlainTalk>

## 公式

```
转换线 = (9 日最高 + 9 日最低) / 2
基准线 = (26 日最高 + 26 日最低) / 2
先行带 A = (转换线 + 基准线) / 2，向前平移 26 期
先行带 B = (52 日最高 + 52 日最低) / 2，向前平移 26 期
云层   = 先行带 A 与 B 之间的区域
迟行线 = 当日收盘价，向后平移 26 期（画在当前 K 线上）
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 转换线 | 9 | 短周期平衡 | 短线可缩 |
| 基准线 | 26 | 中周期平衡 | 长线可放 |
| 先行带 B | 52 | 长周期平衡 | 决定云层厚度 |
| 平移 | 26 | 时间位移 | 一般不动 |

## 计算演示：手把手算一目均衡表

一目均衡表五条线各自是不同周期高低点的平均。核心两条（26 日周期用示意值）：

```
转换线 Tenkan = (HH₉ + LL₉) / 2
基准线 Kijun = (HH₂₆ + LL₂₆) / 2

示例：最近 9 日最高 115、最低 98 → 转换线 = (115 + 98) / 2 = 106.5
      最近 26 日（示意）最高 116、最低 96 → 基准线 = (116 + 96) / 2 = 106
```

**关键理解**：转换线反映短期重心、基准线反映中期重心；两者交叉类似"均线金叉死叉"。云层 = 前值两线的中点带，价格在云上偏多、云下偏空，云厚薄反映趋势稳固度。

## 信号解读

### 买入/看多信号
- 价格在**云层上方**运行：整体多头结构，回调至云顶/基准线是买点。
- **转换线上穿基准线**且云层由薄转厚：多头行情启动。
- 迟行线在 26 期前价格上方：历史走势确认当前强势。

### 卖出/看空信号
- 价格在**云层下方**：整体空头，反抽云底/基准线是卖点。
- 转换线下穿基准线且云层转薄：空头行情展开。
- 迟行线在历史价格下方：确认弱势。

### 背离或其他高级信号
- **云层厚度 = 波动预期**：云厚说明多空分歧大、支撑阻力强；云薄则易突破。
- 价格穿越云层是"变色龙"式的状态切换，配合 RSI 背离判断真假突破。
- "乌云翻转 / 三武士"等 K 线形态在云层边界处效果更强。

## 一次实战解读

以下面回放的 120 根 K 线（示意数据，仅教学用）为例，用"价格 vs 基准线 + 两条线相对关系"三层看盘：

- **第 38 ~ 54 天（多头段）**：价格稳定运行在基准线上方，转换线也上穿基准线——多头结构成立，回调到基准线附近是顺势买点。
- **第 70 ~ 76 天（转弱段）**：价格跌破基准线、转换线回到基准线下方——多头结构被破坏，应离场观望。
- **第 88 ~ 93 天（再起段）**：价格重新站上基准线并走高（第 88 天收盘 ≈ 111，基准 ≈ 102）——多头结构重建。
- **第 114 天之后**：价格再次跌破基准线（收盘 ≈ 106，基准 ≈ 108）——进入弱态，反弹到云底附近是卖点。

**关键点**：一目均衡表是"整体框架"，别只看一条线——价格在云上/云下决定多空大方向，转换线与基准线的相对关系确认短线强弱，云层厚度反映波动预期。

## 实战用法

- **多周期过滤**：周线在云上、日线回踩云顶，顺势做多——这是最经典的一目用法。
- **入场三要素**：转换线金叉基准线 + 价格在云上 + 迟行线在高位，三者共振。
- **止损参考**：云层边界和基准线是天然的动态止损位。

## 常见误区

- <span class="qw-no">✕</span> 只看一条线：一目均衡表的精髓是"线 + 云 + 迟行线"整体配合。
- <span class="qw-ok">✓</span> 把它当成多周期一体化的框架而非单一信号。
- <span class="qw-no">✕</span> 云层被突破就立刻追：先确认是真突破还是"云薄假突破"。
- <span class="qw-ok">✓</span> 用 RSI/成交量等验证突破质量。
