# 枢轴点（Pivot Points）

## 一句话总结

枢轴点用前一个周期的最高、最低、收盘价算出当周期的中枢位（P）与多层支撑阻力（S1-S3、R1-R3），是日内交易者标注"作战地图"的标准工具。

<PlainTalk>枢轴点像在开盘前给今天的行情画一张「作战地图」：用昨天的高点、低点和收盘价，算出今天的中枢线 P，再向上下各画出几层支撑线（S1-S3）和压力线（R1-R3）。就像足球场上的中线和禁区线，中线之上是进攻半场、之下是防守半场，价格回踩到某条线附近常会停顿一下。它不是预言，只是帮你提前标出今天可能反复拉锯的关键价位。</PlainTalk>

## 公式

**经典法（Classic）：**

```
P  = (H + L + C) / 3
R1 = 2P − L         S1 = 2P − H
R2 = P + (H − L)    S2 = P − (H − L)
R3 = H + 2(P − L)   S3 = L − 2(H − P)
```

**变体：** 斐波那契法（以 P 为中心按 0.382/0.618 分档）、卡玛利拉法（按收盘偏离度分档）。

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 计算周期 | 前一日 | 枢轴来源 | 周线/月线用前周/前月 |
| 分档数 | S1-S3 / R1-R3 | 层级 | 激进者可加 S4/R4 |
| 算法 | 经典法 | 分档方式 | 可对比斐波/卡玛利拉 |

## 计算演示：手把手算枢轴点

用前一个周期的 H/L/C 先算中枢 P，再向上下推导各档支撑压力。以前一日 H=115、L=111、C=113 为例：

```
P  = (H + L + C) / 3 = (115+111+113) / 3 = 113
R1 = 2P − L = 226 − 111 = 115       S1 = 2P − H = 226 − 115 = 111
R2 = P + (H − L) = 113 + 4 = 117    S2 = P − (H − L) = 113 − 4 = 109
R3 = H + 2(P − L) = 115 + 2×2 = 119  S3 = L − 2(H − P) = 111 − 2×2 = 107
```

**关键理解**：P 是今天的"多空分水岭"——价格在 P 上方偏多、下方偏空；R/S 各档是提前标好的关键位，价格回踩/反抽到某档常会停顿，但不保证反转。日内交易者据此画作战地图、设止损目标。

## 信号解读

### 买入/看多信号
- 价格在 **P 或 S1-S2 处**获得支撑、出现反转形态：回踩买点。
- 价格站稳 R1 上方：多头确立，R2 成为下一目标。

### 卖出/看空信号
- 价格在 **R1-R2 处**受阻、出现反转形态：反抽卖点。
- 价格跌破 S1：空头确立，S2 成为下一目标。

### 背离或其他高级信号
- **P 是多空分界**：价格在 P 上方偏多、下方偏空，日内方向参考。
- R3/S3 为极端位：极端行情下"越过 R3 继续涨 / 跌破 S3 继续跌"是趋势性行情特征。
- 枢轴点与其他关键位（POC、斐波那契）重叠时，支撑/阻力更有效。

## 一次实战解读

以下面回放的 K 线（示意数据，仅教学用）为例。演示用最后一根 K 线（H≈106.6 / L≈103.2 / C≈103.2）算出枢轴框架，三条水平线就是提前画好的关键价位：

- **S1 ≈ 102.1（第一支撑）**：演示第 76 天收盘 102.0，正好落在 S1 附近——价格回踩到支撑位附近往往出现停顿或反弹。
- **P ≈ 104.3（中枢）**：第 93 天收盘 104.7，价格在中枢附近反复——P 是今天的多空分水岭，上方偏多、下方偏空。
- **R1 ≈ 105.5（第一压力）**：价格从 111 上方回落、经过 105 一带时多次受阻——压力位附近冲高常被压制。

**关键点**：枢轴点不预测方向，它是"提前画好的作战地图"。实战中把 S/R 当观察位，价格在关键位停顿 + 其他信号（RSI、成交量）共振时，胜率更高。

## 实战用法

- **日内作战地图**：开盘前画好 P/R/S，当天的回踩、突破、目标全以此为参照。
- **突破交易**：开盘后价格放量突破 R1，追多目标 R2；跌破 S1 同理。
- **枢轴点 + 成交量分布**：POC 与 P 重叠的区域是"双保险"支撑/压力。
- **多周期枢轴**：日线枢轴定方向，小时线枢轴找具体点位。

## 常见误区

- <span class="qw-no">✕</span> 把枢轴位当精确到分的点位：它是"区域"而非"单点"，进场要等确认。
- <span class="qw-ok">✓</span> 结合 K 线形态与量能在枢轴位附近做确认。
- <span class="qw-no">✕</span> 只用一套算法：不同品种/周期适用的算法不同，应回测对比。
- <span class="qw-ok">✓</span> 枢轴点是参考框架，不是独立信号系统，务必配合价格行为使用。
