# 叠加指标

叠加指标直接画在 K 线上，把趋势、支撑阻力、买卖点整合成一套"作战地图"，适合自上而下看盘。

| 指标 | 难度 | 一句话 |
|------|------|--------|
| [一目均衡表](./ichimoku) | <span class="dlv dlv-advanced">挑战</span> | 云层 + 多线组合，一个图看趋势/支阻/买卖 |
| [枢轴点](./pivot-points) | <span class="dlv dlv-beginner">入门</span> | 日内关键位计算，交易者的"作战地图" |

> 难度：入门 → 进阶 → 挑战。新手从枢轴点起步；一目均衡表是复合工具，建议掌握单指标后再学。

## 怎么选？

- 想做多周期趋势框架：**一目均衡表**
- 做日内交易找关键位：**枢轴点**
