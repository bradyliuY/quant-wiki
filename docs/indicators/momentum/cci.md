# CCI（商品通道指标）

## 一句话总结

CCI 衡量价格对统计均值的**偏离程度**，正负 100 是两个常见阈值，擅长捕捉周期性行情的高低点转折，尤其适合震荡市。

<PlainTalk>CCI 量的是「价格离它自己的平均水平有多远」。把价格想象成一个总爱离队乱跑的同学，均值是队伍的位置，CCI 就是老师手里那把尺子：离队超过一定距离（冲上 +100 或跌破 −100），说明这一侧走得过分用力，往往会被拉回队伍。它不问方向，只问「偏得多离谱」。</PlainTalk>

## 公式

```
TP = (H + L + C) / 3                    // 典型价格
MA = 最近 n 期 TP 的简单平均
MD = 最近 n 期 |TP − MA| 的平均          // 平均绝对偏差
CCI = (TP − MA) / (0.015 × MD)
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 20 | 统计窗口 | 日内用 14，波段用 20-30 |
| 上阈值 | +100 | 超买/强势 | 趋势市可放宽 |
| 下阈值 | −100 | 超卖/弱势 | 趋势市可放宽 |

## 计算演示：手把手算 CCI

CCI 的关键是"偏离度"：先算典型价格 TP，再看当前 TP 离最近一段 TP 的平均值有多远（用平均绝对偏差 MD 做标尺）。以下窗口为第 2–6 天：

<CalcDemo indicator="cci" period="5" title="CCI 计算演示" />

**演算核对**（第 6 天窗口）：

```
TP = (H + L + C) / 3
第 2 天 TP = (105+101+103)/3 = 103
第 3 天 TP = (106+102+104)/3 = 104
第 4 天 TP = (104+98+101)/3  = 101
第 5 天 TP = (107+103+105)/3 = 105
第 6 天 TP = (108+104+106)/3 = 106

MA = (103+104+101+105+106) / 5 = 103.8
MD = (|103−103.8|+|104−103.8|+|101−103.8|+|105−103.8|+|106−103.8|) / 5
   = (0.8+0.2+2.8+1.2+2.2) / 5 = 1.44
CCI = (106 − 103.8) / (0.015 × 1.44) ≈ 101.9
```

**关键理解**：当前 TP 高出均值越多、且这段偏离越稳定（MD 小），CCI 越大。+100 以上进入强势区、−100 以下进入弱势区，说的是"偏离已经过分"而非"必然反转"。

## 信号解读

### 买入/看多信号
- 从 −100 下方重新向上穿越 −100：超卖回归信号。
- 从 +100 上方回落至 +100 附近企稳再上：强势中继（趋势市）。

### 卖出/看空信号
- 从 +100 上方回落穿越 +100：超买回落信号。
- 跌破 −100 后反抽 −100 遇阻：弱势延续。

### 背离或其他高级信号
- **顶/底背离**：价格新高/新低而 CCI 未跟随，是周期转折预警。
- CCI 长期在 +100 上方说明进入强势趋势段，此时反向信号要打折。

## 实战用法

- **周期转折探测**：CCI 天生为周期市设计，在震荡行情找高低点很顺手。
- **CCI + 趋势判断**：ADX 低（震荡）时 CCI 的 ±100 穿越是优质波段信号；ADX 高时只追顺势的"回归上穿"。
- **CCI + 支撑阻力**：价格在关键位 + CCI 超卖，胜率叠加。

## 常见误区

- <span class="qw-no">✕</span> 把 CCI 当趋势指标追单：它衡量偏离，趋势中途追单容易买在均值回归点。
- <span class="qw-ok">✓</span> 判断行情性质（震荡 vs 趋势）后再决定是否采用。
- <span class="qw-no">✕</span> 忽略阈值随品种波动：不同品种 CCI 的"极值区"不同，应观察历史分布。
- <span class="qw-ok">✓</span> 结合背离 + 关键位，提高转折信号质量。
