# 随机指标 KD（Stochastic Oscillator）

## 一句话总结

随机指标把收盘价放进最近 N 期的高低点区间里"打分"，看价格在区间内的位置是否极端，快线 K 与慢线 D 的金叉死叉适合抓短线买卖点。

<PlainTalk>随机指标像是给价格配了一把「刻度尺」：把最近 9 天的最高价当成 100、最低价当成 0，看今天收盘价落在尺子的哪一格。读数接近 100，说明价格快顶到近期区间的天花板；接近 0，说明快贴到地板。它不关心涨了多少，只回答「价格在这段高低区间里已经走到哪个位置」，就像看一个人爬到了梯子的哪一级。</PlainTalk>

## 公式

```
RSV = (C − LLₙ) / (HHₙ − LLₙ) × 100     // 当前收盘在区间的位置
K   = 2/3 × K₋₁ + 1/3 × RSV              // RSV 的平滑
D   = 2/3 × D₋₁ + 1/3 × K                // K 的平滑
J   = 3K − 2D                             // 更敏感的辅助线
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| RSV 周期 | 9 | 区间取多长 | 短线用 5-7 |
| K 平滑 | 3 | 快线敏感度 | 越小越灵敏 |
| D 平滑 | 3 | 慢线平滑度 | 一般不动 |
| 超买/超卖 | 80 / 20 | 阈值 | 可改 85/15 |

## 计算演示：手把手算 KDJ

KDJ 分两步：先算 RSV（收盘价在最近 N 日高低区间里的位置分），再对 RSV 做两次平滑得到 K、D。以下窗口为第 2–6 天：

<CalcDemo indicator="kdj" period="5" title="KDJ 计算演示" />

**演算核对**（第 6 天窗口 HH=108、LL=98）：

```
RSV = (C − LL) / (HH − LL) × 100
    = (106 − 98) / (108 − 98) × 100 = 80

K、D 从 50 起步递推（每次取 2/3 旧值 + 1/3 新 RSV）：
第 6 天 K = ⅔ × 62.3 + ⅓ × 80 ≈ 68.2
第 6 天 D = ⅔ × 57.8 + ⅓ × 68.2 ≈ 61.2
J = 3K − 2D = 3 × 68.2 − 2 × 61.2 ≈ 82.1
```

**关键理解**：K、D 越高说明收盘价越贴近近期高位（超买），越低越贴近低位（超卖）。RSV=80 已进入强势区，K、D 追着 RSV 上移但永远慢半拍——这就是快线 K 与慢线 D 产生金叉/死叉的来源。

## 信号解读

### 买入/看多信号
- 超卖区（<20）金叉：K 上穿 D 是反弹买点。
- 低位金叉且 J 从负值向上：短线超跌反弹动能足。

### 卖出/看空信号
- 超买区（>80）死叉：K 下穿 D 是减仓信号。
- 高位 J > 100 后回落：短线过热，谨防急跌。

### 背离或其他高级信号
- **底背离**：价格新低、KD 低点抬高，短线止跌信号。
- **钝化**：单边强趋势中 KD 会在超买/超卖区长时间钝化、信号失灵——这是它与 RSI 共同的短板，也是它最大的风险。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，看下方窗格的 K 与 D：

- **第 52 天附近**：K 冲到 80 上方（K≈86）后下穿 D——高位死叉，提示超买后的回调。
- **第 66 天**：K 跌到 20 下方（K≈16）进入超卖区——短线跌幅透支，但"超卖 ≠ 立刻反转"，要等钝化结束再评估。
- **第 100 天附近**：K 在 20~30 区间上穿 D——离开超卖区后的金叉，比低位钝化里的交叉更可靠。
- **第 88 / 110 天**：K 在 60~80 高位区间反复交叉——震荡市里信号虽多，但大部分没有价值。

**关键点**：KDJ 在震荡市里极其灵敏，金叉死叉满天飞。过滤法则是——只在"20 以下超卖后回升的金叉"或"80 以上超买后回落的死叉"时才当信号用，其余区间的交叉仅作参考。

## 实战用法

- **短线交易**：KD 是短周期指标，适合日内/小波段，与 K 线形态配合做快进快出。
- **KD + 趋势过滤**：趋势向上时只在超卖金叉做多，超买死叉只减仓不做空。
- **KD + 成交量**：金叉伴随放量，反弹质量更高。

## 常见误区

- <span class="qw-no">✕</span> 强趋势里按超买超卖反向做：KD 钝化会让你一路逆势被套。
- <span class="qw-ok">✓</span> 单边市禁用 KD 的摆动信号，改用趋势指标。
- <span class="qw-no">✕</span> 只信 J 线：J 线极端化后没有参照意义，只有结合 K/D 才有效。
- <span class="qw-ok">✓</span> KD 适合"震荡 + 小波段"，先把行情性质分清楚再用。
