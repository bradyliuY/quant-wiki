# ROC（变动率指标）

## 一句话总结

ROC 就是"最近 N 期价格涨跌了多少百分比"——把今天的价格和 N 期前的价格比一比，算出涨跌幅。它是最直接的**动量测量计**：正数 = 在涨、负数 = 在跌，数值越大说明涨/跌得越猛。

<PlainTalk>把 ROC 想成"体重秤上的变化速度"：你不关心现在 70 公斤这个绝对值，而是在意"这一个月瘦了还是胖了、瘦了多少"。ROC 也是这个道理——它不看价格本身，只看**这段时间价格跑得多快**。动量就是速度，ROC 就是那支速度表：指针往上甩 = 正在加速上涨，往下掉 = 正在加速下跌。</PlainTalk>

## 公式

```
ROC(N) = (今天的收盘价 − N 期前的收盘价) ÷ N 期前的收盘价 × 100
```

N 默认 12（约两周）。**直觉**：把"今天的价格"和"N 期前的价格"连线，看这根斜线的陡峭程度——ROC 就是它的斜率百分比。

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 N | 12 | 对比的时间跨度 | 短线 6-9，波段 12-25 |
| 零轴 | 0 | 涨跌分界 | 正=涨、负=跌 |

**周期要匹配持仓周期**：短线交易用短周期 ROC（灵敏、信号多），波段用长周期（平滑、信号少但稳）——没有"最优"，只有"匹配"。

**与 RSI 的区别**：RSI 把动量"归一化"到 0-100 之间、永远不超界；ROC 是**百分比、无界**——强趋势里 ROC 可以冲到 +30、+50。RSI 看"在 0-100 里位置"，ROC 看"实际涨了多少"。

## 手把手算：ROC

ROC 是整个指标库里最简单的公式之一——只有一步减法、一步除法。以 N=2 为例，从第 3 天开始有值：

```
价格序列 = [100, 102, 105, 103, 108]

第 1 天  100（起点，无 N 期前数据）→ 无 ROC
第 2 天  102 → 无
第 3 天  105 vs 第 1 天 100 → ROC = (105−100)/100 × 100 = +5.0%
第 4 天  103 vs 第 2 天 102 → ROC = (103−102)/102 × 100 = +0.98%
第 5 天  108 vs 第 3 天 105 → ROC = (108−105)/105 × 100 = +2.86%
```

**关键理解**：ROC 只看"终点对起点的变化率"，中间怎么走不重要。第 4 天价格虽然从 105 跌到 103，但相对第 2 天还是涨的，ROC 仍是正的——这就是"动量还在"的信号。**ROC 的斜率（在往上走还是往下走）比单个数值更重要**。

## 信号解读

### 买入/看多信号
- **ROC 上穿 0 轴**：动量由负转正，趋势转强信号。
- **ROC 持续为正且上行**：上涨动能增强，趋势健康。
- **价格创新低、ROC 低点抬高**（底背离）：下跌动能衰减，潜在底部。

### 卖出/看空信号
- **ROC 下穿 0 轴**：动量由正转负，趋势转弱信号。
- **ROC 持续为负且下行**：下跌动能增强，弱势延续。
- **价格创新高、ROC 高点降低**（顶背离）：上涨动能衰竭，警惕回落。

### 其他
- **ROC 高位超买 / 低位超卖**：ROC 冲得过高（相对自身历史）可能短线过热，但强趋势里会钝化——配合 [RSI](./rsi) 判断更稳。
- **ROC 与 MACD 共振**：ROC 和 MACD 同向 = 动量确认；背离互相印证。

## 一次实战解读

以上面回放的 K 线（示意数据，仅教学用）为例，跟随副窗格的蓝色 ROC 曲线：

- **启动段**：价格突破上涨，ROC 快速上穿 0 轴并冲高——动量启动，是最早的转强信号。
- **趋势段**：ROC 在 0 轴上方反复但重心上移，价格沿均线上行——动量维持，趋势健康。
- **背离段**：价格继续创新高，但 ROC 高点明显低于前高（顶背离）——上涨的"速度"跟不上了，是减仓预警。
- **衰竭段**：ROC 下穿 0 轴并转负——动量确认转弱，与价格下跌互相印证。

**关键点**：ROC 是"速度表"，最有价值的用法是**看动量与价格是否同步**——价格新高而 ROC 不新高，说明开车的人已经松油门了。

## 实战用法

- **动量确认**：只在 ROC 与价格同向时顺势交易，背离时减仓观望。
- **背离交易**：ROC 顶/底背离作为反转"提前量"，与 [RSI](./rsi)、[MACD](../trend/macd) 互相验证。
- **参数匹配**：用 [ADX](../trend/adx) 判断趋势强弱，趋势强时用长周期 ROC 过滤噪声。
- **ROC + 均线**：价格站上均线 + ROC 上穿 0 轴双确认，入场质量更高。

## 常见误区

- <span class="qw-no">✕</span> 只盯 ROC 正负不看斜率：ROC 转负但负值在收窄，说明下跌在减速，别急着判空。
- <span class="qw-ok">✓</span> 结合趋势看：强趋势里 ROC 高位钝化是常态，别一超买就逆势做空。
- <span class="qw-no">✕</span> 周期与持仓不匹配：日内用 ROC(25) 会迟钝得毫无意义。
- <span class="qw-ok">✓</span> 忽略极端值：暴涨暴跌会让 ROC 冲到极端，先剔除异常再判断方向。

## 相关

- [RSI](./rsi)：归一化到 0-100 的动量指标
- [CCI](./cci)：动量 + 统计偏离
- [威廉指标](./williams-r)：RSI 的"兄弟"
- [MACD](../trend/macd)：双均线差的动量
- [ADX](../trend/adx)：判断趋势强弱，决定 ROC 周期
