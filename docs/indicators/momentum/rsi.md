# RSI（相对强弱指标）

## 一句话总结

RSI 用一段时间涨跌幅的比值衡量涨跌动能，读数 0-100，超买超卖与背离是它的两大用法，是最流行的动量/摆动指标。

<PlainTalk>RSI 就像把最近 14 天的「上涨力气」和「下跌力气」放到天平上比一比。涨得明显比跌得多，读数就高（买方占上风）；反过来读数就低。它把「最近到底谁在使劲」浓缩成一个 0–100 的数字——超过 70 或跌破 30，只是告诉你力道已经过于一边倒，是一声「注意」的哨响，并不是「马上要反转」的保证。</PlainTalk>

## 公式

```
RS = 周期内平均涨幅 / 周期内平均跌幅     // Wilder 平滑
RSI = 100 − 100 / (1 + RS)
等价：RSI = 平均涨幅 / (平均涨幅 + 平均跌幅) × 100
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 14 | 平滑窗口 | 短线用 9 更灵敏，长线用 21 |
| 超买线 | 70 | 涨幅透支 | 牛市可放宽到 80 |
| 超卖线 | 30 | 跌幅透支 | 熊市可放宽到 20 |

## 计算演示：手把手算 RSI

RSI 比 MA 多一步：先把每天的涨跌幅算出来，再比较平均涨幅与平均跌幅。用示例数据逐步展示：

<CalcDemo indicator="rsi" period="5" title="RSI 计算演示" />

**演算核对**（以 5 天为例，实际默认用 14 天）：

```
第 2 天涨幅 = 101.5 − 100.0 = +1.5
第 3 天涨幅 = 102.3 − 101.5 = +0.8
第 4 天跌幅 = 101.8 − 102.3 = −0.5
第 5 天涨幅 = 103.2 − 101.8 = +1.4
第 6 天涨幅 = 104.5 − 103.2 = +1.3

平均涨幅 = (1.5+0.8+1.4+1.3) / 5 = 1.00
平均跌幅 = 0.5 / 5 = 0.10
RS = 1.00 / 0.10 = 10.0
RSI = 100 − 100/(1+10) ≈ 90.9
```

**关键理解**：涨得多跌得少 → RSI 高（买方强势）；跌得多涨得少 → RSI 低（卖方强势）。所以 RSI 不是独立指标，它**衡量的就是最近这段行情的动能对比**。强趋势中 RSI 长期>70 是常态，这就是为什么"见 70 就卖"是新手陷阱。

## 信号解读

### 买入/看多信号
- **超卖反转**：RSI 跌破 30 后重新向上穿越 30，是反弹信号。
- 50 轴上方的回调：RSI 从强势区回踩 50 不破再向上，是多头中继。

### 卖出/看空信号
- **超买回落**：RSI 冲破 70 后跌回 70 以下，是回调警示。
- 50 轴下方的反抽：RSI 反抽 50 遇阻向下，空头延续。

### 背离或其他高级信号
- **顶背离**：价格创新高、RSI 高点走低，上涨动能衰减，常预示见顶。
- **底背离**：价格创新低、RSI 低点抬高，下跌动能衰竭，常预示见底。
- RSI 极端值（>90 / <10）在趋势行情中会"钝化"，长时间趴在高位反而是强趋势特征。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，跟随下方窗格的 RSI(14)：

- **第 40 ~ 50 天**：RSI 从 50 上方一路抬升、第 50 天附近升破 70 进入超买区——价格连续上涨、动能强，但追多的性价比已在下降。
- **第 52 天附近**：RSI 从 70 上方掉头下穿 70——上涨动能开始衰竭的早期提示，往往比价格跌破均线更早出现。
- **回落之后**：RSI 回到 50 附近震荡，代表多空重新拉锯；等它再次站上 50 且价格企稳，才是下一段做多信号的准备期。

**关键点**：RSI 不是"超买就卖、超卖就买"的开关。正确用法是"在 50 上方的强势区里等回调参与、在 50 下方的弱势区里等反弹离场"，超买超卖线帮你快速判断当前处于哪个区。

## 实战用法

- **RSI + 趋势过滤**：趋势向上时只做超卖买点、不做超买卖点（顺势而为）。
- **RSI + MACD**：两者同时背离共振，反转信号可靠性大增。
- **RSI + 均线**：价格站上 20 日均线且 RSI 回踩 50 企稳，是趋势中的进场点。

## 常见误区

- <span class="qw-no">✕</span> 见 70 就卖、见 30 就买：强势股 RSI 可以长期>70，过早下车。
- <span class="qw-ok">✓</span> 结合趋势：震荡市用超买超卖，趋势市用背离和 50 轴支撑。
- <span class="qw-no">✕</span> 只把 RSI 当随机摆动指标：它本质是动能指标，背离比超买超卖更值钱。
- <span class="qw-ok">✓</span> 用多重时间框架确认：日线 RSI 与小时线 RSI 同向时信号更强。
