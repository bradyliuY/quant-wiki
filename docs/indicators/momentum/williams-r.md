# 威廉指标（W%R）

## 一句话总结

威廉指标用"最近最高价离当前收盘有多远"衡量价格的超买超卖，本质是随机指标取反向坐标，擅长快速捕捉短线高低点。

## 公式

```
HHₙ = 最近 n 期的最高价
LLₙ = 最近 n 期的最低价
W%R = (HHₙ − C) / (HHₙ − LLₙ) × 100    // 常见取 −100 到 0，软件可切换
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 14 | 区间窗口 | 短线 10，波段 20 |
| 超卖区 | −80 以下 | 强超卖 | 趋势市放宽 |
| 超买区 | −20 以上 | 强超买 | 趋势市放宽 |

## 信号解读

### 买入/看多信号
- 从 −80 下方回升穿越 −80：超卖后的反弹信号。
- 价格创新低但 W%R 不再创新低（底背离）：短线见底。

### 卖出/看空信号
- 从 −20 上方回落穿越 −20：超买后的回调信号。
- 价格创新高但 W%R 不再创新高（顶背离）：短线见顶。

### 背离或其他高级信号
- W%R 与 KD 数学上几乎互为镜像（W%R = 100 − RSV），两者信号可互相印证。
- 双底形态：W%R 连续两次触及 −80 后回升，配合价格不破前低，反弹概率大。

## 实战用法

- **超买超卖系统**：W%R 适合做震荡市的短线进出，与 KD、RSI 同源，避免重复使用。
- **W%R + 趋势过滤**：上升趋势中等待 W%R 进入超卖区再买，把"回调"当机会。
- **W%R + ATR 止损**：W%R 信号入场后按 ATR 设止损，量化风险。

## 常见误区

- <span class="qw-no">✕</span> 与 RSI/KD 叠加使用：三者信息高度重叠，不产生额外价值。
- <span class="qw-ok">✓</span> 摆动指标挑一个用足，把精力花在趋势过滤和仓位管理上。
- <span class="qw-no">✕</span> 忽略坐标方向：不同软件 W%R 可能显示为 −100~0 或 0~100，先看清符号。
- <span class="qw-ok">✓</span> 用背离而非单纯超买超卖做反转，避免强趋势钝化陷阱。
