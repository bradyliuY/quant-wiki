# 📊 指标大全

按功能分类的完整技术指标词典，每个指标配动态图表演示。

## 指标分类

- **趋势指标**：回答"价格往哪走"
  - [移动平均线 MA](./trend/ma) · MACD · ADX · 抛物线 SAR
- **动量指标**：回答"走势有多强"
  - RSI · 随机指标 KD · CCI · 威廉指标
- **波动率指标**：回答"波动有多剧烈"
  - 布林带 · ATR · 肯特纳通道
- **成交量指标**：回答"谁在推动价格"
  - OBV · 成交量分布 · MFI
- **叠加指标**：叠加在 K 线上的复合指标
  - 一目均衡表 · 枢轴点
