# 💧 成交量指标

成交量指标回答"谁在推动价格"。通过量能与价格的配合，判断资金流向与推动力的真伪。

| 指标 | 一句话 |
|------|--------|
| [OBV](./obv) | 量能累计能量潮，"量在价先" |
| [成交量分布](./volume-profile) | 价位上的成交量堆积，钱堆在哪 |
| [MFI](./mfi) | 量价结合的 RSI，有钱才能推动 |

## 怎么选？

- 想看资金进出方向：**OBV**
- 想找支撑阻力 / 公允价：**成交量分布**
- 想看量价动能 / 背离：**MFI**
