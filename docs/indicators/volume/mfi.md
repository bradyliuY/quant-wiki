# MFI（资金流量指标）

## 一句话总结

MFI 是"成交量加权版 RSI"：同样算涨跌动能，但用"典型价格 × 成交量"代替简单价格差，从而反映推动价格的资金力量，超买超卖与背离是核心用法。

<PlainTalk>MFI 是给 RSI 的天平「称了斤两」：RSI 只比涨跌幅度，MFI 还要把每天的成交金额放上去。就像拔河不光数哪边人多，还得算每个人有多重——同样是涨 2%，靠天量推上去和靠地量磨上去，含金量完全不同。所以 RSI 和 MFI 意见不一致时，MFI 往往更接近「钱」的真实态度。</PlainTalk>

## 公式

```
TP = (H + L + C) / 3
MF = TP × 成交量
当日 TP > 前日 TP：计入正向资金流 (+MF)，否则 −MF
资金比率 MFR = 14 期 (+MF 之和) / 14 期 (−MF 之和)
MFI = 100 − 100 / (1 + MFR)
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 14 | 资金流窗口 | 与 RSI 对齐，便于对比 |
| 超买线 | 80 | 资金过热 | 牛市可放宽到 90 |
| 超卖线 | 20 | 资金枯竭 | 熊市可放宽到 10 |

## 计算演示：手把手算 MFI

MFI 是成交量加权版 RSI：把每天的"典型价格 × 成交量"当作资金流，涨的日子记正、跌的日子记负，再比两者总量。以下窗口为第 2–6 天：

<CalcDemo indicator="mfi" period="5" title="MFI 计算演示" />

**演算核对**（第 6 天窗口）：

```
MF = TP × 成交量
第 2 天 103×50  = 5150（收涨 → 计入 +MF）
第 3 天 104×60  = 6240（收涨 → +MF）
第 4 天 101×35  = 3535（收跌 → −MF）
第 5 天 105×80  = 8400（收涨 → +MF）
第 6 天 106×90  = 9540（收涨 → +MF）

MFR = Σ+MF / Σ−MF = (5150+6240+8400+9540) / 3535 = 29330/3535 ≈ 8.30
MFI = 100 − 100/(1+MFR) = 100 − 100/9.30 ≈ 89.2
```

**关键理解**：MFI 接近 80/20 与 RSI 含义类似，但用的是"钱"（量×价）。若价格涨、MFI 却不涨，说明上涨不是靠放量推动的——量价背离，可信度要打折。

## 信号解读

### 买入/看多信号
- **超卖回升**：MFI 跌破 20 后向上穿越 20，说明卖压资金衰竭、买盘资金进场。
- 价格在支撑位 + MFI 底背离：资金已经开始低吸。

### 卖出/看空信号
- **超买回落**：MFI 冲破 80 后跌回 80 以下，追高资金乏力。
- 价格在高位 + MFI 顶背离：聪明资金借涨出货。

### 背离或其他高级信号
- **MFI 背离比 RSI 背离更"贵"**：因为含成交量，更能反映真实资金流向。
- 价格横盘而 MFI 缓慢爬升：资金暗中吸筹，蓄势待发。
- MFI 在极端区钝化（趋势行情中长时间>80/<20）：强趋势特征，勿逆势。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，想象 MFI（含成交量的资金流）叠加的读法：

- **第 33 ~ 57 天（放量上涨段）**：MFI 会升破 80 并钝化——强趋势中"超买"可以持续，此时不做空，只等它跌回 80 以下提示追高资金乏力。
- **第 58 ~ 76 天（回调段）**：价格回落，若 MFI 的回落比价格更浅（底背离雏形），说明资金仍在低吸——这比纯价格企稳更早暗示底部。
- **第 95 天前后**：若价格再次上行而 MFI 不创新高，就是量价顶背离——上涨没有放量支撑，可信度打折。

**关键点**：MFI 是 RSI 的"含成交量版"，顶/底背离比 RSI 更"贵"（更能反映真实资金）。但它同样在强趋势里会钝化，趋势中要顺着钝化方向做，别逆势。

## 实战用法

- **量价背离确认**：价格新高 + MFI 不新高，比纯价格背离更可靠地提示顶部。
- **MFI + 趋势过滤**：上升趋势中 MFI 回踩 20-30 区域企稳是低吸点。
- **MFI + OBV**：MFI 确认资金强度，OBV 确认资金方向，两者配合看多空。

## 常见误区

- <span class="qw-no">✕</span> 把 MFI 当独立买卖系统：超买超卖信号在趋势中同样会钝化。
- <span class="qw-ok">✓</span> 结合趋势过滤与背离使用，才能发挥含成交量的优势。
- <span class="qw-no">✕</span> 忽略成交量数据质量：数据缺失或复权异常会直接污染 MFI。
- <span class="qw-ok">✓</span> 与 RSI 对照时，重点看 MFI 是否"多了一档量能信息"。
