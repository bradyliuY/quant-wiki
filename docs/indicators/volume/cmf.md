# CMF（蔡金资金流）

## 一句话总结

CMF 用"收盘价在当日高低点区间里的位置"结合成交量，衡量最近 N 期**资金是流入还是流出**，值域约在 −1 到 +1：正值 = 资金净流入（买盘占优），负值 = 资金净流出（卖盘占优）。

<PlainTalk>把 CMF 想成一支"资金的潮汐表"：每天收盘后，看当天的价格停在高位还是低位——**收盘越靠近当日最高、且量越大**，说明买盘真金白银把价格推在高处，是涨潮（资金流入）；**收盘越靠当日最低、量越大**，是退潮（资金流出）。CMF 就是把最近 20 天的涨潮退潮汇总成一条线：线在零轴上方 = 总体在涨潮，下方 = 总体在退潮。</PlainTalk>

## 公式

```
每根 K 线的资金流量乘数 MFM = [(收盘−最低) − (最高−收盘)] / (最高−最低)
资金流量 MFV = MFM × 成交量
CMF(N)      = Σ MFV(最近 N 期) / Σ 成交量(最近 N 期)
```

**直觉**：MFM 衡量"收盘靠近高位还是低位"——收盘在最高点，MFM = +1；收盘在最低点，MFM = −1；收盘在中间，MFM = 0。再乘上成交量：**小盘口猛拉一根大阳线，比缩量阴跌更能推动 CMF**。最后除以累计成交量，把"量的大小"归一化，让不同体量的标的可比。

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 N | 20 | 平滑资金流的窗口 | 短线 10、长线 40 |
| 零轴 | 0 | 流入/流出分界 | 正=流入、负=流出 |

**与 MFI 的区别**：MFI 用**典型价** (H+L+C)/3 算资金，CMF 用**收盘位置**在区间里的比例算资金——两者都是量价资金流，但 CMF 更强调"收盘定论"。看盘时可以互为验证，不必同时用。

## 手把手算：前 3 根 CMF

CMF 分成两步：先算每根的资金流量 MFV，再滚动求和：

```
第 1 天  H=102, L=99, C=101，量 100
         MFM = [(101−99) − (102−101)] / (102−99) = (2−1)/3 = +0.33
         MFV = 0.33 × 100 = +33

第 2 天  H=105, L=102, C=103.5，量 150
         MFM = [(103.5−102) − (105−103.5)] / 3 = (1.5−1.5)/3 = 0
         MFV = 0 × 150 = 0

第 3 天  H=104, L=100, C=100.5，量 120
         MFM = [(100.5−100) − (104−100.5)] / 4 = (0.5−3.5)/4 = −0.75
         MFV = −0.75 × 120 = −90

CMF(3) = (33 + 0 − 90) / (100 + 150 + 120) = −57 / 370 ≈ −0.15   // 3 期滚动
```

**关键理解**：第 2 天涨了但收在中间（MFM=0），对资金流没贡献；第 3 天跌且收在低位（MFM=−0.75），带量流出把 CMF 拖到负值。**CMF 看的是"收盘位置 + 量"的组合，不是简单的涨跌**。

## 信号解读

### 买入/看多信号
- **CMF 由负转正**（上穿零轴）：资金由流出转流入，偏多信号。
- **CMF 持续为正且上行**：资金持续流入，量价配合健康。
- **价格创新低、CMF 低点抬高**（底背离）：下跌被资金吸纳，潜在底部。

### 卖出/看空信号
- **CMF 由正转负**（下穿零轴）：资金由流入转流出，偏空信号。
- **CMF 持续为负且下行**：资金持续流出，弱势延续。
- **价格创新高、CMF 高点降低**（顶背离）：上涨缺量、动能衰竭，警惕回落。

### 其他
- **放量突破时 CMF 同步转正**：突破有效性最高的形态——价格突破 + 资金确认。
- **CMF 高位钝化**：持续高于 +0.3 可能过热，但强趋势中可维持较久，配合 [RSI](../momentum/rsi) 判断。

## 一次实战解读

以上面回放的 K 线（示意数据，仅教学用）为例，跟随副窗格的蓝色 CMF 曲线：

- **低位段**：CMF 长时间在零轴下方徘徊——资金总体流出，价格反弹缺乏承接，是弱势特征。
- **放量上攻段**：CMF 快速上穿零轴并冲高到 +0.2 上方——资金真金白银进场，与价格的放量突破互相印证，趋势最可靠的一段。
- **高位段**：价格继续创新高、但 CMF 高点明显低于前高（顶背离）——上涨的量能跟不上，是离场预警。
- **回落段**：CMF 下穿零轴，与价格下跌同步——资金流出确认，趋势转弱。

**关键点**：CMF 的核心用法是**"背离 + 零轴"**——看它有没有在价格新高/新低时给出相反信号，比看绝对值更有价值。

## 实战用法

- **确认突破**：价格突破关键位时，检查 CMF 是否同步转正/走高，过滤无量假突破。
- **背离交易**：CMF 顶/底背离作为反转"提前量"，与 [RSI](../momentum/rsi) 或 [OBV](./obv) 背离互相验证。
- **CMF + 趋势**：只在趋势方向与 CMF 一致的行情里交易——顺势 + 资金确认，双保险。
- **CMF + 成交量分布**：CMF 显示资金流向、成交量分布显示资金在哪个价位，配合定位支撑压力。

## 常见误区

- <span class="qw-no">✕</span> 只盯正负不看斜率：CMF 微正但持续走低，说明流入在衰减，同样要警惕。
- <span class="qw-ok">✓</span> 结合量能看趋势：CMF 的走势（上行/下行/背离）比绝对值重要。
- <span class="qw-no">✕</span> 把 CMF 当 [MFI](./mfi)：一个用收盘位置、一个用典型价，信号会有差异，别混用。
- <span class="qw-ok">✓</span> 忽略极端量：单日巨量会大幅摆动 CMF，先剔除异动再判断方向。
