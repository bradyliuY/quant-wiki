# 成交量分布（Volume Profile）

## 一句话总结

成交量分布把一段时间内每个价格水平上成交的量画成横向直方图，找出"钱堆在哪"，POC（最大成交价位）与价值区是判断支撑阻力和公允价格的核心。

<PlainTalk>成交量分布把一段时间里每个价格上成交的量，画成横向的「筹码沙山」：哪个价位成交最多，那座沙丘就堆得最高，最高的那根柱子就是 POC——市场用真金白银投票选出的「公允价」。价格跑出沙山覆盖的范围（价值区）太远，就像球离开重心太远，容易被拉回来；而沙山最厚的地方，既是支撑也是最难啃的压力。</PlainTalk>

## 公式

```
按价格档位累计成交量：
某价位成交量 = Σ 该价位（区间内）成交的所有量
POC  = 成交量最大的价格档
价值区 = 覆盖约 70% 成交量的价格区间（VAH / VAL）
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 区间周期 | 日/周/月 | 取哪段时间统计 | 短线用当日，波段用周 |
| 价格档宽 | 自动 | 分桶粗细 | 档太粗看不到细节 |
| 价值区占比 | 70% | 定义核心区 | 可调 68%-80% |

## 信号解读

### 买入/看多信号
- 价格回踩 **POC / 价值区下沿** 获得支撑放量反弹：低位筹码密集区支撑有效。
- 价格带量突破长期 POC 上方并站稳：筹码换手完成，上攻空间打开。

### 卖出/看空信号
- 价格反弹至 POC 下方受阻：高位套牢盘形成压力。
- 价格跌破价值区下沿：密集区由支撑转为压力，下跌加速。

### 背离或其他高级信号
- **堆量与窄带**：POC 处的巨量柱说明大量资金在此换手，是强支撑/压力。
- 筹码上移/下移（新 POC 相对旧 POC 的位置）可判断主力成本变化。
- 价值区逐渐收窄 = 多空达成一致，酝酿趋势启动。

## 实战用法

- **日内交易**：用当日成交量分布找 POC 作为日内公允价，偏离即回归。
- **波段交易**：周线分布的价值区是天然的止损位与目标位。
- **POC + 价格行为**：POC 附近出现反转形态（吞没、pin bar），共振入场。

## 常见误区

- <span class="qw-no">✕</span> 把某个价格档的巨量当成绝对支撑：分布是静态统计，筹码会随行情迁移。
- <span class="qw-ok">✓</span> 定期更新分布区间，结合最新 POC 判断。
- <span class="qw-no">✕</span> 混淆成交量分布（横向、按价格）与成交量柱（纵向、按时间）。
- <span class="qw-ok">✓</span> 记住一句话：成交量分布回答"在哪里成交"，成交量柱回答"何时成交"。
