# OBV（能量潮）

## 一句话总结

OBV 把每日成交量按涨跌方向累加（涨加跌减），形成"量能资金流曲线"，核心观点是"量在价先"——OBV 领先价格揭示资金真实进出方向。

<PlainTalk>OBV 像一本逐日记账的「资金流水本」：收涨的日子把当天成交量记为正数，收跌的日子记为负数，一天天累加成一条曲线。它的信条是「量在价先」——好比潮水先上涨，船才会被托起来。所以价格还没动、OBV 已悄悄抬高时，往往说明钱先进了场，价格随后才跟上。</PlainTalk>

## 公式

```
当日收盘价 > 前收盘价：OBV = OBV₋₁ + 当日成交量
当日收盘价 < 前收盘价：OBV = OBV₋₁ − 当日成交量
否则：OBV = OBV₋₁
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 无（累计） | 本质是累加曲线 | 可叠加 MA 平滑观察 |
| 趋势线 | — | 斜率的视觉参考 | 看 OBV 自身的趋势与背离 |

## 计算演示：手把手算 OBV

OBV 不复杂：把每天成交量按涨跌方向累加。涨一天记 +V，跌一天记 −V，一路加起来就是 OBV 曲线。

<CalcDemo indicator="obv" title="OBV 计算演示" />

**演算核对**（前 6 天）：

```
第 1 天  收盘 101（起点）→ OBV = 40
第 2 天  103 > 101 → OBV = 40 + 50 = 90
第 3 天  104 > 103 → OBV = 90 + 60 = 150
第 4 天  101 < 104 → OBV = 150 − 35 = 115
第 5 天  105 > 101 → OBV = 115 + 80 = 195
第 6 天  106 > 105 → OBV = 195 + 90 = 285
```

**关键理解**：OBV 本身是资金流方向的总账，看的是**斜率与背离**：OBV 一路新高而价格滞涨，说明资金提前进场；OBV 走平或下移而价格创新高，说明上涨缺乏承接。

## 信号解读

### 买入/看多信号
- **OBV 创新高而价格未创新高**：资金抢先入场，价格大概率补涨。
- OBV 上升趋势中价格回调不破 OBV 上升线：吸筹特征，回调做多。

### 卖出/看空信号
- **OBV 走低而价格走平/走高**：涨势缺乏量能支撑，是出货特征。
- OBV 跌破其上升趋势线：资金开始撤离，警惕价格跟随下跌。

### 背离或其他高级信号
- **OBV 顶背离**：价格创新高、OBV 高点降低，量价背离，上涨难持续。
- **OBV 底背离**：价格创新低、OBV 低点抬高，下跌被吸纳，潜在底部。
- 放量突破时 OBV 陡峭上行，验证突破有效性。

## 一次实战解读

以下面回放的 K 线（示意数据，仅教学用）为例，看下方窗格的 OBV 曲线：

- **前段（低位震荡）**：OBV 在低位来回、整体偏平——量能没有方向，价格的涨跌都缺乏资金确认。
- **第 58 天附近的回调**：价格回调时 OBV 也下探到区间低位——量价同步走弱。
- **第 76 天前后**：价格企稳回升，OBV 快速修复到零轴附近——下跌是缩量的，主力资金没有大规模撤离。
- **第 106 天之后**：OBV 转正并加速上行，与价格同步创新高——量价齐升，趋势最强的一段。

**关键点**：OBV 的用法重点在"相对走势"而非绝对值——价格创新高而 OBV 不创新高，说明上涨缺量、要警惕背离；价格横盘而 OBV 缓慢爬升，说明资金在暗中进场。

## 实战用法

- **确认突破**：价格突破关键位时检查 OBV 是否同步突破，防止无量假突破。
- **背离交易**：OBV 背离作为趋势反转的"提前量"，与 RSI 背离互相验证。
- **OBV + 均线**：OBV 与价格同时站上各自均线，量价共振。

## 常见误区

- <span class="qw-no">✕</span> 只盯 OBV 数值不看趋势：OBV 的绝对值无意义，趋势和背离才重要。
- <span class="qw-ok">✓</span> 比较"OBV 走势 vs 价格走势"的形态差异。
- <span class="qw-no">✕</span> 忽略异常量：突发巨量会一次性改变 OBV 形态，应先剔除异动再看。
- <span class="qw-ok">✓</span> 把 OBV 当确认工具，不单独预测方向。
