# VWAP（成交量加权平均价）

## 一句话总结

VWAP 是以**成交量**为权重算出来的平均价格——把"每个价位成交了多少量"加权平均，得到当天资金的"平均成本线"。机构用它做日内参照物：价格在 VWAP 上方 = 平均在赚，下方 = 平均在亏。

<PlainTalk>把 VWAP 想成全班同学的平均分，但"成绩好的同学权重更大"：成交量大的价位，对均价的贡献就大。简单说，VWAP 就是**当天大多数人实际成交的平均成本**。价格站上 VWAP，说明新买家成本高于平均、情绪偏多；跌破 VWAP，说明多数人已浮亏、情绪转空。机构盯盘第一眼看的往往就是它。</PlainTalk>

## 公式

```
典型价 TP = (最高价 + 最低价 + 收盘价) / 3
VWAP     = Σ(TP × 成交量) / Σ(成交量)      // 从开盘累计到当前
```

**与均线 MA 的区别**：MA 只对收盘价取算术平均（每根 K 线权重相同）；VWAP 按成交量加权（量大的价位权重高），更能代表"真实成本"——所以它是**成交量重心**，而不是纯价格重心。

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 日内累计 | 当天从开盘累到收盘 | 跨日重置，通常不跨日对比 |
| 典型价 TP | (H+L+C)/3 | 每根 K 线的代表价 | 也有人用收盘价，TP 更稳 |

**注意**：VWAP 是**日内指标**——第二天开盘就会重新从零累计。把它当"当天的战场分界线"用，别拿昨天的 VWAP 看今天的行情。

## 手把手算：前 3 根的 VWAP

VWAP 就是"加权平均"——每一步都只用乘法和加法：

```
第 1 天  H=102, L=99, C=101，量 100
         TP = (102+99+101)/3 = 100.67
         累计 PV = 100.67 × 100 = 10067，累计量 = 100
         VWAP = 10067 / 100 = 100.67

第 2 天  H=105, L=102, C=104，量 150
         TP = (105+102+104)/3 = 103.67
         累计 PV = 10067 + 103.67×150 = 25617，累计量 = 250
         VWAP = 25617 / 250 = 102.47

第 3 天  H=104, L=100, C=101，量 120
         TP = (104+100+101)/3 = 101.67
         累计 PV = 25617 + 101.67×120 = 37817，累计量 = 370
         VWAP = 37817 / 370 = 102.21
```

**关键理解**：第 3 天虽然价格回落（收盘 101），但 VWAP 只小幅下移（102.47 → 102.21）——因为前两天的**大量成交集中在更高的价位**。这就是 VWAP 与均线的本质差别：它尊重"量在哪里成交"，而不是只看价格本身。

## 信号解读

### 买入/看多信号
- **价格站上 VWAP**：日内平均成本上移，持筹者浮盈，偏多信号。
- **回踩 VWAP 不破**：价格回落到 VWAP 附近获得支撑（机构常在这里挂单接筹），是日内低吸点。

### 卖出/看空信号
- **价格跌破 VWAP**：平均成本转为浮亏，偏空信号。
- **反抽 VWAP 不过**：跌破后反弹到 VWAP 附近被压回（套牢盘解套抛压），是日内减仓点。

### 其他
- **放量突破 VWAP**：成交量放大推动价格站上 VWAP，是日内最可靠的转强信号（突破有效性靠量确认）。
- **VWAP 与价格严重偏离**：价格远离 VWAP 过多（如 ±2×ATR），短线有回归 VWAP 的引力——但强趋势里也可能"越偏越远"，需配合趋势判断。

## 一次实战解读

以上面回放的 K 线（示意数据，仅教学用）为例，跟随橙色 VWAP 线：

- **开盘段**：价格在 VWAP 下方运行，VWAP 缓步下移——早盘空头占优，平均成本不断走低，不宜抄底。
- **放量突破段**：价格放量上穿 VWAP，VWAP 由跌转平再转升——这是日内转强的第一信号，之后回踩 VWAP 不破都是低吸点。
- **趋势段**：价格沿 VWAP 上方运行、每次回调都受 VWAP 支撑——多头格局，持仓不动。
- **跌破段**：收盘跌破 VWAP 且反抽不过——日内转弱，离场观察。

**关键点**：VWAP 是"当日多空分界线"，和均线、布林带这类"跨日指标"配合使用效果最好——用日线趋势定方向，用 VWAP 定日内进出场时机。

## 实战用法

- **日内交易锚**：高抛低吸 VWAP（上方卖、下方买），是最常见的日内策略。
- **机构参照**：VWAP 附近常有机构挂单，突破 + 放量才有效，缩量穿透多为假突破。
- **VWAP + 布林带**：日线布林带定波动环境，日内 VWAP 定买卖点。
- **VWAP + ATR**：偏离 VWAP 超过 2×ATR 再考虑回归，避免在强趋势里过早逆势。

## 常见误区

- <span class="qw-no">✕</span> 把 VWAP 当跨日指标：它是日内累计，隔天就重置，别拿昨天的 VWAP 看图。
- <span class="qw-ok">✓</span> 只在日内使用，日线及以上周期看 [MA](../trend/ma) 或 [布林带](../volatility/bollinger-bands)。
- <span class="qw-no">✕</span> 把 VWAP 当支撑压力线：它是"平均成本"，不是订单密集区，震荡市里上下穿越很正常。
- <span class="qw-ok">✓</span> 结合成交量看突破：放量站上 VWAP 才可信，无量穿越大概率是噪声。
