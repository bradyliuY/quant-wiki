# 抛物线 SAR（停损转向指标）

## 一句话总结

SAR 用抛物线点画出跟随价格的追踪止损位，趋势中持续向价格方向移动，价格跌破/上穿 SAR 即提示离场或转向，是趋势交易的"安全垫"。

<PlainTalk>SAR 像一条越收越紧的狗绳：价格往哪边走，它就跟到哪边。价格每创出新高，它就把止损线往上提一点，而且越提越快（加速因子在帮忙），一路贴着价格的后脚跟。等价格一个回身跌破这条线，等于狗狗挣脱了绳子——趋势可能要掉头了。</PlainTalk>

## 公式

```
SAR(t) = SAR(t−1) + AF × (EP − SAR(t−1))
AF：加速因子，起始 0.02，每次创出新的极值 +0.02，上限 0.20
EP：当前趋势的极值（上升趋势为最高价，下降趋势为最低价）
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 加速因子 AF | 0.02 | 追踪快慢 | 趋势强可加大，震荡市应减小或不用 |
| AF 上限 | 0.20 | 追踪极限 | 越小越贴价格 |
| 起始 EP | 近两日极值 | 起点 | 一般不用动 |

## 计算演示：手把手算 SAR

SAR 是逐日递推的：每天在旧 SAR 的基础上，沿趋势方向"追一步"，追得快慢由加速因子 AF 决定。用示例数据演示上升趋势（首日最低价 98 为起点）：

```
SAR₁ = 98（起点 = 首日最低价），EP = 104（首日最高价），AF = 0.02

第 2 天：创出新高 105 → EP = 105，AF = 0.04
  SAR₂ = 98 + 0.04 × (105 − 98) = 98.28

第 3 天：创出新高 106 → EP = 106，AF = 0.06
  SAR₃ = 98.28 + 0.06 × (106 − 98.28) ≈ 98.74

第 4 天：未创新高 → EP、AF 不变
  SAR₄ = 98.74 + 0.06 × (106 − 98.74) ≈ 99.18

第 5 天：创出新高 107 → EP = 107，AF = 0.08
  SAR₅ = 99.18 + 0.08 × (107 − 99.18) ≈ 99.81
```

**关键理解**：SAR 一路贴着价格抬升，且每次创新高 AF 加速（0.02→0.04→0.06→0.08），SAR 追赶得越来越快——这就是"抛物线"名字的由来。直到某天最低价跌破 SAR，趋势翻转、SAR 重置到另一侧重新起步。

## 信号解读

### 买入/看多信号
- 价格从下方**上穿 SAR 点**：空头止损转向，是潜在买点。
- 上升趋势中价格始终运行在 SAR 点上方：多头持仓的安全参考。

### 卖出/看空信号
- 价格从上方**跌破 SAR 点**：多头离场信号，转空入场点。
- 下降趋势中价格在 SAR 点下方运行：宜空仓或持空。

### 背离或其他高级信号
- SAR 是**纯跟随**指标，天然适合给持仓画移动止损：每创新高上移 SAR，跌破即走。
- 趋势末端 SAR 频繁翻转（点在价格上下跳舞）是震荡信号，应停用。

## 一次实战解读

以下面回放的 K 线（示意数据，仅教学用）为例，跟随紫色的 SAR 曲线：

- **第 4 ~ 27 天**：SAR 频繁翻转（多次由下翻上、由上翻下）——这是震荡段，SAR 来回打脸，说明它只适合有趋势的行情。
- **第 38 ~ 54 天（单边上涨段）**：SAR 一路贴着价格下方跟随抬升、不再翻转——趋势持有期，跌破 SAR 才离场，让利润奔跑。
- **第 70 ~ 93 天**：SAR 再次震荡翻转——趋势结束的信号，多头应离场。
- **第 105 ~ 114 天**：SAR 重新从价格下方跟随上行——新一轮上升趋势启动。

**关键点**：SAR 是"追踪止损"工具，不是预测工具。它保证你在趋势里始终有个越来越紧的止损位（安全垫），代价是震荡市里会被反复止损。所以 SAR 最好配合 ADX 用——只在有趋势时采信它的转向信号。

## 实战用法

- **移动止损**：入场后每天把止损放在 SAR 点，让利润奔跑、风险可控。
- **SAR + 均线**：均线定方向，SAR 定具体离场位；两者同向才持仓。
- **SAR + ADX**：ADX > 20 时 SAR 信号才可靠，震荡市过滤掉翻转噪声。

## 常见误区

- <span class="qw-no">✕</span> 在震荡行情使用 SAR：点位来回翻转，止损必被扫。
- <span class="qw-ok">✓</span> 先确认趋势（ADX / 均线排列），再用 SAR 管理单边持仓。
- <span class="qw-no">✕</span> 把 SAR 当成完整买卖系统：SAR 是止损工具，入场要用趋势/突破信号。
- <span class="qw-ok">✓</span> SAR 与价格的距离就是当前的"趋势损耗预算"，距离骤增往往是趋势末段。
