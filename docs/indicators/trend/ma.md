# 移动平均线（MA / EMA / SMA / WMA）

## 一句话总结

移动平均线对一段时间内的收盘价做平均，把价格的短期波动"磨平"，用来判断趋势方向，是最基础也最常用的趋势指标。按权重方式不同分为 SMA、EMA、WMA 等。

<PlainTalk>均线就是把最近 N 天的收盘价加在一起取平均，再把这些平均值连成一条线。它像一张「摊平的手掌」——把单日上蹿下跳的价格噪音抹平，让你看清钱大体往哪个方向流。均线在价格下方、斜率向上，说明近期的买入成本在持续抬升，趋势偏多；反过来就是偏空。</PlainTalk>

## 公式

**SMA（简单移动平均）**

```
SMA(n) = (C₁ + C₂ + ... + Cₙ) / n
```

**EMA（指数移动平均，越近的价权重越大）**

```
α = 2 / (n + 1)
EMA(t) = α × C(t) + (1 − α) × EMA(t − 1)
```

**WMA（加权移动平均）**

```
WMA(n) = (n×C + (n−1)×C₋₁ + ... + 1×C₋₍ₙ₋₁₎) / (n + (n−1) + ... + 1)
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 n | 5 / 10 / 20 / 60 | 平滑度 vs 灵敏度 | 短线用 5-20，中线 20-60，长线 60-250 |
| MA 类型 | SMA | 权重策略 | 趋势行情用 EMA 反应更快，震荡行情用 SMA 更稳 |

## 计算演示：手把手算 MA

下面用一段示例收盘价，逐步演示 **MA5** 是怎么算出来的。绿色高亮是当前参与计算的窗口，跟随"下一步"观察窗口如何滑动。

<CalcDemo indicator="sma" period="5" title="MA5 计算演示" />

**演算核对**（第 5 天，即第一个能算出 MA5 的位置）：

```
MA5(D5) = (D1 + D2 + D3 + D4 + D5) / 5
        = (100.0 + 101.5 + 102.3 + 101.8 + 103.2) / 5
        = 508.8 / 5
        = 101.76
```

第 6 天窗口向前滑一格，丢掉 D1、纳入 D6：

```
MA5(D6) = (101.5 + 102.3 + 101.8 + 103.2 + 104.5) / 5
        = 513.3 / 5
        = 102.66
```

**关键理解**：MA 是"滑动窗口的平均"——每根新 K 线进来，最老的一根被移出，窗口永远保持 n 根。所以 MA 天然滞后 n 天，这也决定了它只做趋势确认、不做拐点预测。

## 信号解读

### 买入/看多信号
- 价格上穿均线（尤其是 20/60 日），且均线由走平转上翘，视为趋势转多。
- 短均线上穿长均线形成**金叉**，是多头排列启动信号。

### 卖出/看空信号
- 价格跌破均线、均线拐头向下，视为趋势转空。
- 短均线下穿长均线形成**死叉**，是空头排列确认。

### 背离或其他高级信号
- 均线**多头/空头排列**（短在上长在下 / 反之）用来确认趋势级别。
- 价格与均线乖离过大（偏离率超过历史阈值）预示回抽，可配合 RSI 超买超卖使用。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，只看 MA5 与 MA20 这一对组合的交替：

- **第 20 天附近**：MA5 下穿 MA20 形成死叉，价格在两条均线下方——趋势转弱，持仓者应离场。
- **第 32 天附近**：MA5 重新上穿 MA20 形成金叉，且价格站上两条均线——一段上升趋势启动。
- **第 58 天与第 95 天**：两次死叉回调，随后又在第 76 天、第 106 天分别金叉回升——这是典型的"震荡上行"行情，交叉信号来回交替。
- **第 117 天之后**：再次死叉且价格跌破 MA20，进入下降段。

**关键点**：均线交叉不是"每次都对"，它更像"跟随确认"——单边行情里金叉后一路持有能吃到主升段，来回震荡里却会反复挨打。所以实战中先要用 ADX 等判断是否有趋势，再决定是否用交叉信号入场。

## 实战用法

- **双均线组合**：如 MA5 上穿 MA20 做多、下穿做空，是趋势跟踪的入门策略，可配合 ADX 过滤震荡市。
- **均线 + 成交量**：上穿时若成交量放大，信号可信度更高。
- **均线 + 布林带**：布林带中轨即 20 日均线，带口收窄后用均线突破定方向。

## 常见误区

- <span class="qw-no">✕</span> 单条均线追涨杀跌：震荡市里均线反复穿越，来回挨打。
- <span class="qw-ok">✓</span> 先用趋势指标（ADX / MACD）确认有趋势，再用均线交叉入场。
- <span class="qw-no">✕</span> 所有品种共用一套周期：不同标的波动周期不同，应回测后选参。
- <span class="qw-ok">✓</span> 均线是"跟随型"指标，天然滞后，只做确认工具而非预测工具。
