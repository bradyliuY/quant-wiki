# MACD（指数平滑异同移动平均线）

## 一句话总结

MACD 用快慢两根指数均线的差（DIF）及其平滑线（DEA）刻画趋势的加速与减速，金叉死叉和红绿柱缩放是最常用的买卖信号。

<PlainTalk>MACD 可以想象成给一辆车装了两个仪表：快线(12)看短期油门、慢线(26)看中期车速。两者之差 DIF 就是「短期比中期快多少」——转正是油门盖过刹车，转负是刹车盖过油门。金叉=最近动能由弱转强，死叉=由强转弱。它的信号不是预测未来，而是描述动能正在往哪个方向变。</PlainTalk>

## 公式

```
DIF = EMA(快线, 12) − EMA(慢线, 26)
DEA = EMA(DIF, 9)                // DIF 的平滑线
MACD 柱 = 2 × (DIF − DEA)        // 国内软件常乘 2
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 快线周期 | 12 | 灵敏的一端 | 短线可缩至 6-8，变快但噪声多 |
| 慢线周期 | 26 | 趋势一端 | 中线可扩至 30-40 |
| 信号周期 | 9 | 平滑 DEA | 一般不动 |
| 零轴 | 0 | 多空分界 | 用 0 轴上方/下方区分强弱 |

快慢线参数决定灵敏度：周期越短，金叉死叉出现越早、也越频繁；周期越长，信号越滞后但越稳。对比标准 (12,26,9) 与灵敏 (8,21,5)：

## 计算演示：手把手算 MACD

MACD 是"两条均线的差再平滑一次"：先算 DIF（快线减慢线），再对 DIF 平滑出 DEA，两者之差就是柱。用示例数据逐步展示每一层：

<CalcDemo indicator="macd" title="MACD 计算演示（EMA12/EMA26/DEA9）" />

**演算核对**：

```
第 1 步：EMA12 = 最近 12 天收盘价的指数平滑
         EMA26 = 最近 26 天收盘价的指数平滑
第 2 步：DIF = EMA12 − EMA26
         → DIF > 0：短期均值在长期均值上方，多头占优
         → DIF < 0：空头占优
第 3 步：DEA = EMA(DIF, 9)，即对 DIF 序列再平滑一次
第 4 步：MACD 柱 = 2 × (DIF − DEA)
         → 柱转正 = DIF 上穿 DEA（金叉）的动能表现
```

**关键理解**：DIF 是"快慢均线的差距"，衡量**短中期动能差**；DEA 是它的平滑线，过滤噪声。柱体的红绿变化就是 DIF 与 DEA 的咬合——柱由负转正是**金叉**，由正转负是**死叉**，这就是 MACD 信号的全部来源。

## 信号解读

### 买入/看多信号
- **金叉**：DIF 上穿 DEA。零轴上方金叉（强势市场回调结束）比零轴下方金叉更可靠。
- **零轴上方**运行：多方主导，回调后 DIF 不破零轴再拐头是加仓点。

### 卖出/看空信号
- **死叉**：DIF 下穿 DEA，零轴下方死叉杀伤力更大。
- **红柱缩短 / 绿柱放大**：柱体是动能刻度，红柱连续缩短预示上涨衰竭。

### 背离或其他高级信号
- **顶背离**：价格创新高，DIF 高点却走低，是上涨动能衰竭的预警。
- **底背离**：价格创新低，DIF 低点抬高，是下跌动能衰竭的转机信号。
- 柱体面积与价格的背离（面积法）比点对点背离更稳。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，跟随下方窗格的 DIF 与 DEA：

- **第 31 天附近**：DIF 上穿 DEA 形成**金叉**，且此时 DIF 已在零轴附近——做多信号，柱由绿转红。
- **第 55 天附近**：DIF 下穿 DEA 形成**死叉**，柱由红转绿——多头动能衰竭，应止盈离场。
- **第 73 / 105 天**：再次金叉，行情延续上涨——但金叉一次比一次接近零轴甚至更低时，就要警惕 DIF 高点走低的**顶背离**（价格创新高、动能不创新高）。
- **第 115 天之后的死叉**：配合价格跌破前期低点，确认趋势转空。

**关键点**：MACD 的信号要分层看——金叉死叉给方向，红绿柱给动能强弱，零轴上方/下方给趋势级别。三者共振才是高质量信号，单看一个很容易被来回打脸。

## 实战用法

- **趋势确认**：先看 DIF 在零轴上方还是下方定多空基调，再等金叉死叉入场。
- **MACD + 均线**：价格站上 20 日均线且 MACD 零轴上方金叉，形成共振。
- **MACD + 成交量**：金叉伴随放量信号更可信；背离时若量价也背离，反转概率更高。

## 常见误区

- <span class="qw-no">✕</span> 只看金叉死叉不看零轴位置：震荡市里 MACD 会连续假金叉死叉。
- <span class="qw-ok">✓</span> 用零轴 + 背离过滤掉大部分震荡信号，只在趋势段交易。
- <span class="qw-no">✕</span> 把背离当立即反转信号：背离只表示动能减弱，可能横盘化解。
- <span class="qw-ok">✓</span> 背离后等待价格确认（突破/跌破关键位）再动手。
