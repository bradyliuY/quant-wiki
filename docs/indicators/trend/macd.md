# MACD（指数平滑异同移动平均线）

## 一句话总结

MACD 用快慢两根指数均线的差（DIF）及其平滑线（DEA）刻画趋势的加速与减速，金叉死叉和红绿柱缩放是最常用的买卖信号。

## 公式

```
DIF = EMA(快线, 12) − EMA(慢线, 26)
DEA = EMA(DIF, 9)                // DIF 的平滑线
MACD 柱 = 2 × (DIF − DEA)        // 国内软件常乘 2
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 快线周期 | 12 | 灵敏的一端 | 短线可缩至 6-8，变快但噪声多 |
| 慢线周期 | 26 | 趋势一端 | 中线可扩至 30-40 |
| 信号周期 | 9 | 平滑 DEA | 一般不动 |
| 零轴 | 0 | 多空分界 | 用 0 轴上方/下方区分强弱 |

## 信号解读

### 买入/看多信号
- **金叉**：DIF 上穿 DEA。零轴上方金叉（强势市场回调结束）比零轴下方金叉更可靠。
- **零轴上方**运行：多方主导，回调后 DIF 不破零轴再拐头是加仓点。

### 卖出/看空信号
- **死叉**：DIF 下穿 DEA，零轴下方死叉杀伤力更大。
- **红柱缩短 / 绿柱放大**：柱体是动能刻度，红柱连续缩短预示上涨衰竭。

### 背离或其他高级信号
- **顶背离**：价格创新高，DIF 高点却走低，是上涨动能衰竭的预警。
- **底背离**：价格创新低，DIF 低点抬高，是下跌动能衰竭的转机信号。
- 柱体面积与价格的背离（面积法）比点对点背离更稳。

## 实战用法

- **趋势确认**：先看 DIF 在零轴上方还是下方定多空基调，再等金叉死叉入场。
- **MACD + 均线**：价格站上 20 日均线且 MACD 零轴上方金叉，形成共振。
- **MACD + 成交量**：金叉伴随放量信号更可信；背离时若量价也背离，反转概率更高。

## 常见误区

- ❌ 只看金叉死叉不看零轴位置：震荡市里 MACD 会连续假金叉死叉。
- ✅ 用零轴 + 背离过滤掉大部分震荡信号，只在趋势段交易。
- ❌ 把背离当立即反转信号：背离只表示动能减弱，可能横盘化解。
- ✅ 背离后等待价格确认（突破/跌破关键位）再动手。
