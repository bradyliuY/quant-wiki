# 肯特纳通道（Keltner Channels）

## 一句话总结

肯特纳通道以 EMA 为中心、上下各加减两倍 ATR，用"真实波动"而非标准差来定带宽，与布林带互补，二者组合的"双挤压"信号很有名。

<PlainTalk>肯特纳通道像给价格挖的一条「隧道」：中间轨是 EMA 的路线，上下轨按最近的真实波动（ATR）各留两倍宽度当天花板和地板。路况颠簸，隧道自动加宽，让价格在里面自由走动；路况平稳，隧道就收窄。它和布林带的差别在于：布林带是被价格拉开的橡皮筋，肯特纳是按近期颠簸程度定宽的隧道。</PlainTalk>

## 公式

```
MID   = EMA(收盘价, 20)
上轨  = MID + 2 × ATR(14)
下轨  = MID − 2 × ATR(14)
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 中轨周期 | 20 | EMA 平滑 | 短线 10-15 |
| ATR 周期 | 14 | 波动度量 | 一般不动 |
| 通道倍数 | 2 | 带宽 | 可调 1.5-3 |

## 计算演示：手把手算肯特纳通道

肯特纳通道 = EMA 中轨 ± 2×ATR。中轨是均值，上下轨是"真实波动"的带宽。用示例数据示意（中轨取 EMA20 示意值 106，ATR(5) 用 4.8）：

```
MID = EMA(收盘, 20) ≈ 106（示意）
上轨 = MID + 2 × ATR = 106 + 2 × 4.8 = 115.6
下轨 = MID − 2 × ATR = 106 − 2 × 4.8 = 96.4
```

**关键理解**：与布林带（标准差定宽）不同，肯特纳用 ATR 定宽——波动越大通道越宽。两者带宽同时收窄（"双挤压"）常预示变盘。

## 信号解读

### 买入/看多信号
- 价格站上中轨且通道向上张口：多头趋势运行中。
- 价格触下轨后收回带内，中轨向上：趋势中的回调买点。

### 卖出/看空信号
- 价格跌破中轨、通道向下：空头主导。
- 价格触上轨后跌回带内：短线超买。

### 背离或其他高级信号
- **布林带挤压 (BB) + 肯特纳挤压 (KC)**：当布林带收进肯特纳通道内部，代表波动极度压缩，常是重大变盘前兆。
- 中轨（EMA）与布林带中轨（SMA）的交叉也可作为趋势方向确认。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，想象肯特纳通道（EMA20 ± 2×ATR）叠加的读法：

- **第 33 ~ 57 天（单边上涨段）**：价格贴着通道上轨运行、通道向上张口——强趋势，此时"触上轨"不是卖出理由，跌破中轨（EMA20）才提示趋势转弱。
- **第 60 ~ 95 天（震荡段）**：价格在通道内来回、触下轨后收回——"触下轨、中轨向上"是趋势中的回调买点。
- **第 96 天前后**：若布林带与肯特纳通道同时收窄（双挤压），代表波动极度压缩，常对应一波方向选择。

**关键点**：肯特纳用 ATR 定宽（跟随真实波动），布林带用标准差定宽。两者同时收窄是经典的"波动率爆发前兆"，突破方向入场后再用通道跟踪。

## 实战用法

- **波动率突破系统**：先用 BB/KC 双挤压确认波动极低，再等突破方向入场。
- **肯特纳 + 趋势过滤**：只在通道向上时做多触轨回踩，向下时做空触轨反抽。
- **通道跟踪**：价格贴着上轨运行=强趋势，跌破中轨即趋势转弱。

## 常见误区

- <span class="qw-no">✕</span> 与布林带二选一当买卖信号：两个通道用途不同（标准差 vs ATR），组合使用信息更全。
- <span class="qw-ok">✓</span> 双通道挤压才是肯特纳的高光用法。
- <span class="qw-no">✕</span> 在窄幅横盘反复打"触轨反转"：通道收窄时回归信号失效。
- <span class="qw-ok">✓</span> 通道越窄越要等突破，越宽越适合回归。
