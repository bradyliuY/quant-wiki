# 唐奇安通道（Donchian Channels）

## 一句话总结

唐奇安通道用「最近 N 天的最高价」和「最近 N 天的最低价」画两条通道线：价格突破上沿说明创出 N 天新高、突破下沿说明创出 N 天新低。它不预测涨跌，只告诉你「价格正处在什么极端位置」——是突破交易、海龟交易法的核心通道。

<PlainTalk>唐奇安通道就是给价格画的两条「极值警戒线」：上沿是最近 N 天的最高价、下沿是最近 N 天的最低价。价格一旦冲破上沿，就像比赛里跑出了新纪录——旧纪录被刷新，往往意味着一段新行情的开始。所以它的用法很简单：**突破上沿做多、跌破下沿做空**，赌「创纪录之后还能继续」。</PlainTalk>

## 公式

```
上沿 = 最近 N 期的最高价
下沿 = 最近 N 期的最低价
中轨 = (上沿 + 下沿) / 2     （可选，参考线）
```

通道本身只是「画框」：上沿上移说明多头在创新高，下沿下移说明空头在创新低。**通道宽度**（上沿 − 下沿）代表最近 N 天的价格波动范围。

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 N（入场） | 20 | 上沿突破的观察窗口 | 短线 10-15，长线 40-55 |
| 周期 N（离场） | 10 | 下沿回撤的离场窗口 | 比入场周期短一半，让利润奔跑 |
| 中轨 | 可选 | 上下沿的均值参考 | 多数软件不显示 |

**双周期是精髓**：海龟交易法用「20 日新高」入场（避免信号太频繁）、用「10 日新低」离场（避免利润回吐太多）——入场慢半拍、离场快半拍。

## 手把手算：5 天窗口的唐奇安通道

和布林带（均线±标准差）不同，唐奇安通道不涉及任何均值与方差的数学——它只是「取窗口里的极值」：

```
窗口 = 最近 5 天的最高价 = [102.3, 103.5, 104.1, 105.2, 104.8]

上沿 = max(102.3, 103.5, 104.1, 105.2, 104.8) = 105.2   // 5 天里最高的那根
下沿 = 同理取 5 天最低价中的最小值
中轨 = (上沿 + 下沿) / 2
```

**关键理解**：通道线不是「预测线」，而是「状态线」。它不会告诉你明天涨跌，只告诉你「当前价格是不是已经站上 N 天最高点」。一旦突破，历史统计上往往伴随趋势延续——这正是海龟交易法「追突破」逻辑的数学基础。

## 信号解读

### 买入/看多信号
- **价格突破上沿**：创出 N 天新高，趋势启动信号，顺势买入。
- **通道开口向上**（上沿持续抬升）：多头趋势健康，回调到中轨附近可加仓。

### 卖出/看空信号
- **价格跌破下沿**：创出 N 天新低，空头趋势信号，持有多单应离场。
- **通道开口向下**（下沿持续下移）：空头趋势延续，不宜抄底。

### 其他
- **通道收窄**：价格在窄幅区间横盘、N 天高低点靠拢，是「蓄势」——突破方向未定，等价格选出方向再跟。
- **与布林带的区别**：布林带用标准差（约 95% 价格在带内），唐奇安用真实极值（价格必然在通道内）——所以唐奇安的突破更「极端」，假突破也更频繁。

## 一次实战解读

以上面演示的 K 线（示意数据，仅教学用）为例，跟随上下两条通道线：

- **趋势段**：价格放量突破上沿后，通道持续上行、价格一路贴着上沿走——这是海龟交易最典型的一段，突破入场后只要不跌破下沿就持有。
- **震荡段**：通道横向收窄，价格在区间内来回、频繁触上沿又回落——此时追突破容易被「假突破」打脸，应降低仓位或等待通道重新开口。
- **回调段**：价格跌破下沿（10 日新低）触发离场——即使后来证明只是回调，规则也让你躲过更大的下跌。

**关键点**：唐奇安通道不追求「买在最低」，它只跟随「极值突破」。用双周期（20 入场 / 10 离场）可以过滤掉大部分假突破的损耗。

## 实战用法

- **海龟交易法**：唐奇安通道 + ATR 定仓位，是最经典的突破系统（见[海龟交易法则](../../strategies/trend-following/turtle-trading)）。
- **通道突破策略**：突破上沿入场、跌破下沿离场，是最直接的通道用法（见[通道突破](../../strategies/trend-following/channel-breakout)）。
- **唐奇安 + 成交量**：突破上沿时放量（> 1.2 倍 5 日均量）为有效突破，缩量突破多为假突破。
- **唐奇安 + ATR 止损**：入场后把止损放在「入场价 − 2×ATR」下方，而不是通道下沿——让止损距离与当前波动匹配。

## 常见误区

- <span class="qw-no">✕</span> 一突破就满仓：假突破很常见，突破必须配合仓位控制与止损。
- <span class="qw-ok">✓</span> 用双周期：入场 20 日新高、离场 10 日新低，别用同一个周期。
- <span class="qw-no">✕</span> 把通道当支撑压力：它是「极值线」不是「订单密集区」，震荡市里上下沿都会被反复刺穿。
- <span class="qw-ok">✓</span> 结合市场环境：只在趋势市做突破，震荡市里唐奇安信号最不可靠。
