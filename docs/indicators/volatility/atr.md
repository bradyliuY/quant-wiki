# ATR（平均真实波幅）

## 一句话总结

ATR 把单根 K 线的真实波动范围（含跳空修正）做平滑平均，给出"最近平均每天波动多少"，是设置止损、计算仓位、判断波动环境的基础工具。

<PlainTalk>ATR 是给行情量「浪高」的尺子：它只回答一个朴素问题——最近平均每天大概上下颠簸多少钱。浪高的海面，船得离岸远一点，止损也要放宽；风平浪静时，止损可以收得很紧。它不预测涨跌，只是提醒你今天该用多大的止损距离、下多大的注。</PlainTalk>

## 公式

```
TR = max(H − L, |H − C₋₁|, |L − C₋₁|)   // 真实波幅，含跳空修正
ATR(n) = 对 TR 做 n 期 Wilder 平滑（近似平均）
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 14 | 平滑窗口 | 越大越平滑、反应越慢 |
| 止损倍数 | 1.5-3×ATR | 止损距离 | 波动大/持仓久用大倍数 |
| 仓位公式 | 风险金 / (ATR×倍数) | 头寸规模 | 让每次风险一致 |

## 计算演示：手把手算 ATR

ATR 先算每根 K 线的真实波幅 TR（含跳空修正），再对窗口内 TR 取平均。以下窗口为第 2–6 天：

<CalcDemo indicator="atr" period="5" title="ATR 计算演示" />

**演算核对**（第 6 天窗口，TR 序列 4、4、6、6、4）：

```
TR = max(H − L, |H − C₋₁|, |L − C₋₁|)
第 2 天 TR = max(105−101, |105−101|, |101−101|) = max(4, 4, 0) = 4
第 3 天 TR = max(106−102, |106−103|, |102−103|) = max(4, 3, 1) = 4
第 4 天 TR = max(104−98,  |104−104|, |98−104|)  = max(6, 0, 6) = 6
第 5 天 TR = max(107−103, |107−101|, |103−101|) = max(4, 6, 2) = 6
第 6 天 TR = max(108−104, |108−105|, |104−105|) = max(4, 3, 1) = 4

ATR(5) = (4+4+6+6+4) / 5 = 24/5 = 4.8
```

**关键理解**：TR 单看会跳来跳去，平滑成 ATR 后才稳定可用——它回答"最近平均每天大约颠簸多少钱"。据此设定止损距离（如 2×ATR）或仓位（风险金 ÷ (ATR×倍数)），就是下面计算器在做的事。

## 信号解读

### 买入/看多信号
- ATR 不直接给买卖点，它是**环境指标**：ATR 骤增 = 波动爆发（变盘或趋势启动）。
- ATR 持续收窄 = 波动压缩，往往酝酿突破。

### 卖出/看空信号
- ATR 从高位快速回落 = 行情降温，是趋势末端信号之一。
- 高位 ATR + 价格滞涨 = 剧烈分歧，警惕反转。

### 背离或其他高级信号
- ATR 常与趋势指标**配合而非独立**：ADX 上升 + ATR 上升 = 趋势加强；ADX 回落 + ATR 回落 = 趋势收敛。
- "按 ATR 设置止损"比固定点数更科学：同一止损距离在不同波动环境下代表完全不同的风险。

## 一次实战解读

以上面演示的 150 根 K 线（示意数据，仅教学用）为例，看下方窗格的 ATR(14)：

- **整段行情**：ATR 大致在 3 ~ 4 之间波动——意味着"一天正常波动约 3~4 个价格单位"，这就是我们设置止损、止盈的刻度尺。
- **第 36 ~ 50 天**：K 线实体大、影线长，ATR 处于区间偏高位——高波动段，此时单笔止损要相应放大，仓位要缩小，否则一次正常波动就能扫掉止损。
- **第 60 ~ 95 天**：K 线变小、ATR 相对收敛——低波动段，适合用"ATR 收缩"确认震荡，等待突破后再顺势。
- **波动放大段**：ATR 重新抬头往往伴随趋势启动（向上或向下），此时用"价格 ± 2×ATR"作为动态止损，跟随行情移动。

**关键点**：ATR 不预测方向，它只告诉你"今天的正常波动有多大"。同一笔交易在 ATR 高和低的时候，风险天差地别——止损、止盈、仓位都应该用它做刻度。

## 实战用法

- **科学止损**：止损位 = 入场价 − 2×ATR（多头），给足波动空间又不至于过大。
- **动态仓位**：仓位 = 账户风险金额 /（ATR × 止损倍数），让每笔交易承担同样的风险。
- **波动环境**：ATR 高时降低仓位、放大止损；ATR 低时相反。

## 常见误区

- <span class="qw-no">✕</span> 用固定点数止损：不同波动环境下固定点数会"扫损"或"过大"。
- <span class="qw-ok">✓</span> 止损距离跟着 ATR 走，风险比例固定。
- <span class="qw-no">✕</span> 把 ATR 当买卖信号：它度量波动，不预测方向。
- <span class="qw-ok">✓</span> ATR 只做仓位与止损的"标尺"，方向交给趋势指标。
