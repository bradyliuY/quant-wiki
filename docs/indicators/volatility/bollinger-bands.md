# 布林带（Bollinger Bands）

## 一句话总结

布林带用 20 日均线为中轨、加减两倍标准差为上下轨，带宽随波动自动伸缩，既能测趋势（看中轨方向），也能测波动（带宽收窄预示变盘）。

## 公式

```
MID = SMA(收盘价, 20)
σ   = 最近 20 期收盘价的标准差
上轨 = MID + 2σ
下轨 = MID − 2σ
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 20 | 中轨平滑 | 短线 10-15 |
| 标准差倍数 | 2 | 带宽宽度 | 约 95% 概率在带内；3 更宽松 |
| 带宽 BW | — | (上轨−下轨)/中轨 | 量化波动收窄程度 |

## 信号解读

### 买入/看多信号
- 价格触及/穿越下轨后**收回带内**，且中轨仍向上：强趋势中的回调买点。
- **收口后开口向上**：波动收缩结束、向上突破，是趋势启动信号。

### 卖出/看空信号
- 价格触及上轨后跌回带内，且中轨走平/向下：超买回落。
- 收口后开口向下：向下变盘，宜离场。

### 背离或其他高级信号
- **带宽收窄（挤压）**是变盘前兆，但方向不确定——需等突破方向。
- 中轨（20 日均线）本身就是趋势方向参考；价格长期贴着上轨走=强势趋势。
- **带外运行**：强趋势中价格可持续"骑着"上轨/下轨走，此时触轨信号失效，属正常钝化。

## 实战用法

- **回归 vs 突破两套剧本**：带宽收窄后向上突破用趋势策略；带宽宽幅震荡时用触轨回归策略。
- **布林带 + 量能**：开口放量 = 有效变盘；开口缩量 = 假突破概率高。
- **布林带 + RSI**：价格触下轨同时 RSI 超卖，共振买点质量更高。

## 常见误区

- ❌ 触上轨就卖、触下轨就买：趋势市里"骑带"会让你错过主升浪。
- ✅ 先分清楚是震荡还是趋势，再选择回归或突破打法。
- ❌ 把带宽当绝对刻度：不同标的波动不同，带宽要横向比历史。
- ✅ 用带宽的历史分位判断"挤压程度"，结合放量确认突破。
