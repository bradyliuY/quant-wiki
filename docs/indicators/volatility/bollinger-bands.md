# 布林带（Bollinger Bands）

## 一句话总结

布林带用 20 日均线为中轨、加减两倍标准差为上下轨，带宽随波动自动伸缩，既能测趋势（看中轨方向），也能测波动（带宽收窄预示变盘）。

<PlainTalk>布林带的上下轨就是给价格画的两条「弹性围栏」，中间是 20 日均线。价格像被拉得很长的橡皮筋——碰得太远就想弹回中间。行情越平静，围栏收得越窄，像橡皮筋绷紧等待发力，所以带宽收窄之后常跟着一波放量突破。</PlainTalk>

## 公式

```
MID = SMA(收盘价, 20)
σ   = 最近 20 期收盘价的标准差
上轨 = MID + 2σ
下轨 = MID − 2σ
```

## 关键参数

| 参数 | 默认值 | 用途 | 调整建议 |
|------|--------|------|----------|
| 周期 | 20 | 中轨平滑 | 短线 10-15 |
| 标准差倍数 | 2 | 带宽宽度 | 约 95% 概率在带内；3 更宽松 |
| 带宽 BW | — | (上轨−下轨)/中轨 | 量化波动收窄程度 |

## 计算演示：手把手算布林带

布林带 = 均线 + 标准差。先算中轨（SMA），再算波动（σ），最后加减 2σ 得上下轨。用示例数据逐步展示：

<CalcDemo indicator="boll" period="5" title="布林带计算演示（周期 5 便于演算）" />

**演算核对**（5 天窗口，默认实战用 20 天）：

```
窗口 = [100.0, 101.5, 102.3, 101.8, 103.2]

中轨 = (100.0+101.5+102.3+101.8+103.2) / 5 = 101.76

σ = √( Σ(价格−中轨)² / n )
  = √( (1.76² + 0.26² + 0.54² + 0.04² + 1.44²) / 5 )
  = √( 8.44 / 5 ) ≈ 1.30

上轨 = 101.76 + 2×1.30 = 104.36
下轨 = 101.76 − 2×1.30 =  99.16
```

**关键理解**：σ 衡量的是**波动率**——最近这段行情价格偏离中轨有多远。波动大 → 带宽变宽；波动小 → 带宽收窄（挤压）。这就是"带宽收窄预示变盘"的数学来源：价格波动被压缩到极限，随时会释放。

## 信号解读

### 买入/看多信号
- 价格触及/穿越下轨后**收回带内**，且中轨仍向上：强趋势中的回调买点。
- **收口后开口向上**：波动收缩结束、向上突破，是趋势启动信号。

### 卖出/看空信号
- 价格触及上轨后跌回带内，且中轨走平/向下：超买回落。
- 收口后开口向下：向下变盘，宜离场。

### 背离或其他高级信号
- **带宽收窄（挤压）**是变盘前兆，但方向不确定——需等突破方向。
- 中轨（20 日均线）本身就是趋势方向参考；价格长期贴着上轨走=强势趋势。
- **带外运行**：强趋势中价格可持续"骑着"上轨/下轨走，此时触轨信号失效，属正常钝化。

## 实战用法

- **回归 vs 突破两套剧本**：带宽收窄后向上突破用趋势策略；带宽宽幅震荡时用触轨回归策略。
- **布林带 + 量能**：开口放量 = 有效变盘；开口缩量 = 假突破概率高。
- **布林带 + RSI**：价格触下轨同时 RSI 超卖，共振买点质量更高。

## 常见误区

- <span class="qw-no">✕</span> 触上轨就卖、触下轨就买：趋势市里"骑带"会让你错过主升浪。
- <span class="qw-ok">✓</span> 先分清楚是震荡还是趋势，再选择回归或突破打法。
- <span class="qw-no">✕</span> 把带宽当绝对刻度：不同标的波动不同，带宽要横向比历史。
- <span class="qw-ok">✓</span> 用带宽的历史分位判断"挤压程度"，结合放量确认突破。
