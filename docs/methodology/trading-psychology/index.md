# 交易心理

交易系统中最难量化的部分：**人**。即使策略、风控、回测全部到位，认知偏差与情绪失控仍会毁掉一切。交易心理的目标不是「战胜人性」，而是用规则与系统把人性对决策的影响降到最低。

## 导航

- [认知偏差](/methodology/trading-psychology/cognitive-biases)：确认偏误 / 锚定效应 / 过度自信 / 损失厌恶 / 处置效应
- [纪律执行](/methodology/trading-psychology/discipline)：止损纪律 / 仓位纪律 / 计划外交易 / 执行率统计
- [回撤期心理管理](/methodology/trading-psychology/drawdown-psychology)：回撤数学 / 心理阶段 / 归因 / 熔断机制

## 核心观点

1. **知道偏差 ≠ 免疫偏差**：偏差在压力下自动复发，只能靠规则对抗
2. **减少需要意志力的场景**：自动化止损、预设仓位、写交易计划
3. **回撤期先查执行，再查策略**：区分「策略问题」与「纪律问题」
4. **记录决策质量，而非只看结果**：正确流程比单次盈亏更重要
