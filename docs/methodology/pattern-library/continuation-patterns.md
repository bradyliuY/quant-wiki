# 中继形态识别

## 概述

中继形态（持续形态）出现在一段**已有趋势的中途**，是趋势的「中场休息」。与反转形态相反，中继形态完成后价格大概率沿原方向继续运行。因此识别中继形态的核心是：确认它出现在趋势途中，而非趋势末端。

本页覆盖：三角形（上升/下降/对称）、旗形、矩形、楔形。

## 上升三角形

上升三角形由**水平的压力线**和**上倾的支撑线**构成，是看涨中继形态，向上突破概率约 70%。

**识别条件**：

| 条件 | 标准 |
|------|------|
| 上沿水平 | 波动 < 2% |
| 下沿上倾 | 支撑线斜率 > 0 |
| 形成时间 | 10–30 天 |
| 量能 | 逐步萎缩，突破放量 |

**交易策略**：
- 入场：突破上沿 + 放量
- 目标价：上沿 + 三角形高度
- 止损：下沿下方；成功率约 70%

## 下降三角形

下降三角形由水平的**支撑线**和**下倾的压力线**构成，是看跌中继形态，向下跌破概率高。交易逻辑与上升三角形完全镜像：跌破下沿 + 放量做空（或回避多头），目标价 = 下沿 − 三角形高度，止损设于下沿上方。

## 对称三角形

对称三角形上下沿同时向中心收敛，是**方向不明**的中继形态——突破方向才是答案。识别要点：触碰边界的次数 ≥ 4 次（越多越可靠）、量能持续萎缩、在三角形的 2/3 处突破最有效（越接近顶点突破，力度越弱）。

> 对称三角形不预设方向，应**双向等待突破**：向上突破追多，向下突破做空/离场。

## 旗形

旗形是急涨/急跌后的短暂整理，由**旗杆**（先前的快速趋势）和**旗面**（反向小幅整理）构成，突破方向与旗杆一致。

**识别条件**：

- 旗杆涨幅 > 10%（快速趋势）
- 整理时间 < 20 天（时间短才有效）
- 整理幅度 < 旗杆高度的 50%
- 量能显著萎缩，突破时放大

**交易策略**：
- 入场：突破旗面上沿
- 目标价：突破点 + 旗杆高度
- 止损：旗面下沿

旗形的时间敏感性很强：整理超过 20 天往往演变为反转或矩形，可靠性下降。

## 矩形

矩形（箱体）是价格在两条水平线之间的震荡整理，可出现在趋势途中（中继）也可出现在顶部/底部（反转）。

**识别条件**：

- 上下边界水平（波动 < 2%）
- 边界触碰次数 ≥ 4 次
- 整理时间 10–40 天
- 量能递减

**交易策略**：突破上沿 + 放量入场；目标价 = 上沿 + 矩形高度；止损 = 下沿下方。矩形宽度越大，突破后目标空间越大，但假突破概率也随之上升。

## 楔形

楔形与三角形的区别在于：**上下沿同向倾斜**，且持续期更长（数周至数月）。

- **上升楔形**（看跌）：上下沿同时上倾，多出现在下跌中继或顶部反转，跌破下沿确认
- **下降楔形**（看涨）：上下沿同时下倾，多出现在上涨中继或底部反转，突破上沿确认

楔形突破后的目标测算方法与三角形一致（楔形高度投影）。

## 中继 vs 反转的判断框架

| 判断维度 | 中继形态 | 反转形态 |
|----------|----------|----------|
| 出现位置 | 趋势中段 | 趋势末端 |
| 趋势强度 | 趋势未破坏（均线仍顺排） | 趋势已被反复测试 |
| 量能 | 整理期缩量 | 末端放量滞涨/缩量下跌 |
| 突破方向 | 大概率沿原方向 | 反转型信号 |

## 常见误区

1. **把震荡当旗形**：无旗杆（无快速趋势）的整理不是旗形，只是区间震荡。
2. **对称三角形提前押方向**：应在突破时跟随，而非事先赌一边。
3. **忽略形态持续时间**：整理时间越长，演变为反转的概率越高，需动态重估。
4. **突破后不放量追单**：所有中继形态的突破都需要量能确认，否则视为假突破。
