# 形态识别库

经典技术形态的识别标准、置信度评估与交易策略。形态的价值在于**位置与量能**：同样一个形态，出现在趋势末端与半山腰，意义完全不同。

## 分类导航

- [反转形态](/methodology/pattern-library/reversal-patterns)：双底 / 双顶 / 头肩底 / 头肩顶 / 圆底 / 圆顶
- [中继形态](/methodology/pattern-library/continuation-patterns)：上升 / 下降 / 对称三角形，旗形 / 矩形 / 楔形
- [K 线形态](/methodology/pattern-library/candlestick-patterns)：锤子线 / 吞没 / 晨星黄昏星 / 十字星

## 使用建议

- **高优先级**：双底双顶、头肩底顶、上升三角形
- **中优先级**：旗形、矩形、圆底
- **低优先级**：单根 K 线形态（需与其他信号确认）

所有形态突破都必须验证**量能**与**时间周期**，形态失败（假突破）时应按规则止损，不抱侥幸。形态判断也可以作为 [100 分评分模型](/methodology/scoring-model) 中「形态识别」维度的输入。
