# 统计与概率基础

一句话：量化策略的地基是数学——期望值回答「长期能不能赚」，波动回答「过程有多颠」，相关性回答「组合怎么配」。

回测指标（夏普、回撤）、凯利公式、仓位管理、多因子——全部建立在概率与统计概念上。先有地基，再看上层。
