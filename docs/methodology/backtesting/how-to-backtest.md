# 回测的正确流程

## 概述

回测是在历史数据上模拟策略执行，用来回答一个关键问题：**这套规则在真实市场里是否大概率有效？** 但回测只是「模拟」，它与实盘的差距取决于流程是否严谨。一个设计糟糕的回测会给出漂亮却虚假的收益曲线，让你带着错误的信心进入市场。

本页给出回测的标准流程：从假设定义到上线的完整链路。

## 第一步：定义策略与假设

回测前先写清楚策略的完整规则，包括：

- **入场条件**：精确到指标数值、K 线关系、成交量阈值（如「收盘价上穿 MA20 且成交量 > 5 日均量 1.5 倍」）
- **出场条件**：止损、止盈、移动止损、时间止损
- **仓位规则**：固定仓位还是风险百分比
- **交易成本**：佣金、滑点、冲击成本（小市值标的滑点更高）
- **标的池**：范围、是否含退市股

模糊的条件（如「感觉趋势不错」）无法回测，必须翻译成可执行代码。

## 第二步：数据准备

**数据质量决定回测质量**：

| 检查项 | 说明 |
|--------|------|
| 复权处理 | 使用前复权/后复权，处理分红送股 |
| 停牌与退市 | 包含停牌区间与退市标的，避免幸存者偏差 |
| 数据边界 | 与真实可获取的数据一致（无未来数据） |
| 交易时段 | 对齐真实交易时间（开盘价成交 vs 收盘价成交） |

数据准备阶段最容易埋入未来函数，详见 [回测常见陷阱](/methodology/backtesting/common-pitfalls)。

## 第三步：信号与执行建模

信号在 **bar 收盘后**产生，最早只能在**下一根 bar** 成交——这是避免前视偏差的铁律。执行建模要回答：

- 信号触发当日收盘买入，还是次日开盘买入？（次日开盘更现实）
- 滑点按固定比例还是按波动率比例？
- 涨跌停、停牌时订单如何处理？

回测输出后，必须回答三个问题：

1. **绩效指标是否达标**：夏普、最大回撤、胜率、盈亏比——不是只看总收益
2. **收益来源是否可解释**：策略赚的是趋势/回归/事件的钱，还是「数据巧合」
3. **参数是否敏感**：微调参数绩效剧烈波动 → 过拟合风险

## 第五步：稳健性检验

- **样本外检验**：用未参与优化的时间段验证（详见 [样本外检验与滚动优化](/methodology/backtesting/walk-forward)）
- **参数敏感性**：绘制参数热力图，选择稳定平台区而非尖峰区
- **换市场检验**：同样的逻辑在美股/港股/商品上是否仍有效
- **成本压力测试**：滑点翻倍、费用翻倍后策略是否仍然盈利

## 第六步：小资金实盘验证

回测通过 ≠ 可以全仓上线。用最小仓位实盘运行 1–3 个月，对比：

- 实盘成交价格与回测假设的滑点差异
- 信号延迟与错过
- 执行纪律的偏差（心理因素，见 [交易心理](/methodology/trading-psychology/discipline)）

## 常见误区

1. **只看总收益**：年化 300% 但最大回撤 70% 的策略在现实中无法执行。
2. **回测周期过短**：穿越牛熊（至少一轮完整周期）的数据才具代表性。
3. **数据范围过窄**：只回测上涨段，策略在下跌段的表现完全是盲区。
4. **忽略成本**：高频策略对成本极其敏感，滑点与费用是「吃掉收益」的头号元凶。
