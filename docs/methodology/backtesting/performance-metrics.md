# 绩效指标

## 概述

绩效指标把收益曲线压缩成一组可比较的数字。单一指标会骗人——年化 500% 的策略可能伴随 90% 回撤——因此要**组合阅读**：收益类指标看「赚了多少」，风险类指标看「回撤多大」，风险调整类指标看「每一份风险换来多少收益」。

## 收益类指标

**累计收益率**：`(期末净值 / 期初净值) − 1`。

**年化收益率**：把区间收益折算到一年。`年化 = (1 + 累计收益)^(252 / 交易日数) − 1`（股票按 252 交易日，加密货币可 365）。

**胜率**：盈利交易 / 总交易。**注意**：胜率低不等于不赚钱——趋势系统胜率常低于 40%，靠盈亏比取胜。

**盈亏比**：平均盈利 / 平均亏损。与胜率共同决定期望：`期望 = 胜率 × 平均盈利 − (1 − 胜率) × 平均亏损`。期望 > 0 才是有效策略。

## 风险类指标

**最大回撤（Max Drawdown）**：净值从峰值到谷底的最大跌幅。

$$ \text{MaxDD} = \max \left( \frac{\text{Peak} - \text{Trough}}{\text{Peak}} \right) $$

最大回撤衡量策略的「疼痛阈值」——回撤 50% 需要 **100%** 涨幅才能回本，这是复利的残酷性。

**波动率**：收益率的标准差，衡量收益的起伏幅度。

## 风险调整类指标

**夏普比率（Sharpe Ratio）**：每承担一单位总风险获得的超额收益。

$$ \text{Sharpe} = \frac{R_p - R_f}{\sigma_p} $$

其中 $R_p$ 为策略年化收益，$R_f$ 为无风险利率，$\sigma_p$ 为收益波动率。**经验区间**：> 2 优秀，1–2 良好，< 1 一般。夏普的盲区：它惩罚「向上的波动」，且对尾部风险不敏感。

**卡玛比率（Calmar Ratio）**：每承担一单位最大回撤获得的年化收益。

$$ \text{Calmar} = \frac{\text{年化收益}}{\text{最大回撤}} $$

**优势**：直接回答「最大痛苦换多少收益」，比夏普更贴合交易者心理。**经验区间**：> 3 优秀，1–3 良好，< 1 一般。

**信息比率（Information Ratio）**：相对基准的超额收益 / 跟踪误差，常用于判断策略相比「买入持有」是否真的提供了信息。

## 指标速查表

| 指标 | 公式要点 | 评价标准 |
|------|----------|----------|
| 年化收益 | 几何年化 | 越高越好（结合风险看） |
| 胜率 | 盈利单 / 总单 | 结合盈亏比看 |
| 盈亏比 | 均盈利 / 均亏损 | ≥ 1.5 较健康 |
| 最大回撤 | 峰谷最大跌幅 | < 20%（年度） |
| 夏普比率 | 超额收益 / 波动率 | > 1 可用，> 2 优秀 |
| 卡玛比率 | 年化收益 / 最大回撤 | > 1 可用，> 3 优秀 |

## 综合评估示例

两个策略对比：

| 指标 | 策略 A | 策略 B |
|------|--------|--------|
| 年化收益 | 40% | 55% |
| 最大回撤 | 12% | 45% |
| 夏普比率 | 1.8 | 1.2 |
| 卡玛比率 | 3.3 | 1.2 |
| 胜率 | 55% | 38% |

策略 A 收益略低但**风险大幅更优**：卡玛 3.3 vs 1.2。若以「可执行性」为标准，A 明显优于 B——45% 的回撤意味着实盘中途极可能因心理崩溃而放弃。收益高但无法执行到底的策略等于不存在。

## 常见误区

1. **只看年化收益**：不结合回撤的收益数字没有意义。
2. **用算数平均算收益**：必须用几何平均（复利），算数平均高估长期收益。
3. **指标时间窗口过短**：夏普/卡玛至少需要跨一轮牛熊的数据才有意义。
4. **忽略无风险利率**：夏普分母中的无风险利率在低利率环境下差异巨大，横向对比时保持口径一致。
