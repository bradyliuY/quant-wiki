# 风险管理

风险管理的三大支柱：**仓位管理**控制单笔风险，**止损止盈**保护资金与利润，**组合管理**分散整体风险。一切交易决策都应先回答一个问题：最坏情况下我会亏多少，我能否承受？

## 导航

- [凯利公式](/methodology/risk-management/kelly-criterion)：在已知胜率与盈亏比下确定最优下注比例
- [仓位管理](/methodology/risk-management/position-sizing)：固定比例 / 风险百分比 / 波动率调整 / 金字塔建仓
- [止损策略](/methodology/risk-management/stop-loss)：固定百分比 / 技术位 / 时间 / 移动止损
- [止盈策略](/methodology/risk-management/take-profit)：分批止盈 / 移动止盈 / 目标价止盈
- [组合风险管理](/methodology/risk-management/portfolio-risk)：分散化 / 相关性 / 回撤控制

## 核心原则

1. **永不全仓**：保留现金就是保留选择权
2. **严格止损**：止损是纪律不是建议
3. **保护利润**：盈利后上移止损，不让盈利单变亏损单
4. **控制回撤**：单笔 < 2%，月度 < 10%，年度 < 20%
5. **记录复盘**：每笔交易、每个违规都进日志
