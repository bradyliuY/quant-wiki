# 凯利公式

## 概述

凯利公式（Kelly Criterion）回答了一个根本问题：**在已知胜率与盈亏比的前提下，最优单次下注比例是多少？** 它是资金管理的数学基石——押注过低浪费优势，押注过高则面临毁灭性回撤。

公式由信息论之父克劳德·香农的同事约翰·凯利于 1956 年提出，最初用于解决信息传输中的噪音问题，后被赌博与投资界广泛采用。

## 核心公式

```text
f* = (b × p − q) / b = (p × b − (1 − p)) / b
```

其中：

- f*：最优资金比例
- p：胜率（获胜交易占比）
- q = 1 − p：败率
- b：盈亏比（平均盈利 / 平均亏损）

## 逐步推导

以胜率 60%、盈亏比 2:1 为例：

1. 计算「优势」：b × p − q = 2 × 0.6 − 0.4 = 0.8
2. 除以盈亏比：f* = 0.8 / 2 = 0.4，即理论最优仓位 **40%**

公式的本质是**让盈利的期望增长最大化**。当 b × p − q > 0 时系统有正期望（值得下注），否则不应参与。

## 为什么用半凯利

理论凯利仓位在实际交易中几乎从不直接使用，原因：

- **参数误差放大**：胜率与盈亏比是估计值，估计偏差会线性放大到仓位偏差。实际胜率低于预期时，满凯利会严重超配
- **回撤波动剧烈**：满凯利下的资金曲线波动极大（理论回撤可达 50%+），心理上难以承受
- **序列风险**：实际交易存在连续亏损，满凯利下连亏会摧毁账户

行业惯例是使用 **半凯利（Half Kelly）**：`实际仓位 = 理论凯利 × 0.5`。更进一步，很多成熟交易者会在半凯利基础上设置绝对上限。

## 仓位上限与约束

| 约束项 | 建议值 |
|--------|--------|
| 单笔理论凯利 | 计算值 |
| 半凯利 | 理论值 × 0.5 |
| 单只标的持仓上限 | ≤ 20% |
| 单一板块总仓位 | ≤ 40% |
| 单笔最大亏损 | ≤ 账户 2% |

## 实战示例

某策略回测显示胜率 55%、平均盈利 1.5 倍于平均亏损：

```
f* = (0.55 × 1.5 - 0.45) / 1.5 = 0.10 → 理论 10%
半凯利 = 5%
```

若该标的风险较高（波动率 45%），再叠加波动率调整进一步压缩仓位。详见 [仓位管理](/methodology/risk-management/position-sizing)。

## 常见误区

1. **把凯利当圣杯**：凯利只解决「下多少」，前提是策略有正期望且参数估计准确。
2. **直接使用满凯利**：参数误差 + 回撤承受力，决定了必须打折使用。
3. **忽略上限**：不设单票/单板块上限，凯利公式会指向过度集中的组合。
4. **胜率与盈亏比是「估计值」**：样本量不足的估计会误导公式输出，务必用足够长的回测与实盘数据校准。
