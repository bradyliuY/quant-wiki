# 组合风险管理

## 概述

单笔交易的风控管住「点」，组合风控管住「面」。即使每一笔交易都严格执行仓位与止损，如果组合内所有持仓同涨同跌，一次系统性回撤仍可能重创账户。组合风险管理的目标是：**在风险分散的基础上控制整体回撤，让账户能够扛过不利时期。**

## 三大支柱

| 支柱 | 解决的问题 | 关键指标 |
|------|------------|----------|
| 分散化 | 单一标的/板块风险过度集中 | 持股数、板块集中度 |
| 相关性 | 表面分散、实则同涨同跌 | 收益率相关系数 |
| 回撤控制 | 账户最大亏损幅度可控 | 最大回撤、连亏次数 |

## 分散化检查

**数量**：持有 5–10 只标的较为合理。过少（< 5）分散不足，过多（> 10）管理精力分散且收益被摊薄。

**板块**：至少覆盖 3 个低相关板块。

**集中度红线**：

| 指标 | 红线 |
|------|------|
| 单只标的权重 | ≤ 20% |
| 单一板块总权重 | ≤ 40% |
| 同方向敞口 | ≤ 60% |

## 相关性管理

相关性（相关系数 ρ ∈ [-1, 1]）衡量两只标的是否同涨同跌：

- ρ < 0.3：低相关（分散效果好）
- 0.3–0.7：中等相关（可接受）
- ρ > 0.7：高相关（分散失效，需调整）

**示例**：持有 5 只银行股，数量上达标，但 ρ 普遍 > 0.8——遇到系统性风险时等同于重仓单一板块。真正的分散是**跨板块、跨资产、跨风格**。

**相关性计算**（收益率序列）：

$$ \rho = \frac{\sum (R_{1i}-\bar{R}_1)(R_{2i}-\bar{R}_2)}{\sqrt{\sum (R_{1i}-\bar{R}_1)^2 \cdot \sum (R_{2i}-\bar{R}_2)^2}} $$

## 回撤控制

回撤 = 净值从峰值到谷底的最大跌幅。回撤控制决定账户能否「活着」等到行情回来。

| 层级 | 回撤控制目标 |
|------|--------------|
| 单笔交易 | 最大亏损 < 账户 2% |
| 月度 | 最大回撤 < 10% |
| 年度 | 最大回撤 < 20% |

回撤超过阈值的应对机制：**降低总仓位**（而非加仓摊平）。许多成熟系统采用「亏损减速」规则——账户回撤每超过一个阈值，总仓位按比例下调，直到净值修复。

## 总仓位与市场环境

组合层面还需根据市场环境动态调整总仓位：

| 市场环境 | 总仓位 |
|----------|--------|
| 牛市 | 70–90% |
| 震荡市 | 50–70% |
| 熊市 | 20–40% |
| 黑天鹅/高波动期 | ≤ 20% 或现金 |

始终保持 ≥ 10% 现金作为安全垫。

## 实战示例

账户 100 万，持仓检查发现：

- 5 只标的全部为科技股，板块集中度 100%（超标）
- 两两相关系数均 > 0.7（高相关）
- 单只最大权重 30%（超标）

**调整**：将科技股权重压缩至 60% 以内，引入消费、公用事业与黄金 ETF（与科技股 ρ < 0.3），单只权重降至 ≤ 15%，板块集中度降至 ≤ 40%。调整后组合在模拟压力测试中的最大回撤从 28% 降至 15%。

## 常见误区

1. **数量不等于分散**：5 只同板块股票比 2 只跨板块股票的风险更高。
2. **忽视尾部风险**：相关性在危机中趋向于 1（齐涨齐跌），压力测试比历史相关性更可信。
3. **回撤期加仓**：回撤期应降低风险而非摊平，除非有明确的独立信号。
4. **只看组合不看单笔**：组合风控是叠加在单笔风控之上的第二道防线，不能替代止损。
