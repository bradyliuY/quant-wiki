# 止损策略

## 概述

止损是交易系统的**保险丝**：它把每笔交易的潜在损失锁定在预算之内，让你在市场证明你错误时及时退出。止损不是「认输」，而是让正确的事（限制损失）优先于错误的事（行情或许会回来）。

止损的核心原则：**止损是纪律，不是建议**。设定后不轻易移动（除非上移保护利润），止损出局后不立即反向买回。

## 四种主流止损方法

### 1. 固定百分比止损

按入场价的固定比例设置止损。

| 风险偏好 | 止损幅度 |
|----------|----------|
| 保守 | -5% |
| 平衡 | -7% |
| 激进 | -10% |

**优点**：简单明确，机械执行。**缺点**：未考虑标的位置与波动特征——低波动标的 5% 止损可能过宽，高波动标的又过窄。

### 2. 技术位止损

基于图表结构设置止损，更符合「市场会说错在哪」的逻辑：

- **支撑位止损**：止损 = 支撑位 × 0.98（支撑下方 2%）
- **均线止损**：跌破 5/20/60 日均线，分别对应短线/中线/长线
- **形态止损**：双底跌破第二低点、三角形跌破下沿、头肩底跌破右肩

**取位原则**：当多个技术位止损点同时存在时，取**最近的有效止损**（风险最小），并验证风报比是否达标。

### 3. 时间止损

当走势「迟迟不给答案」时主动退出：

- 持仓 30 天仍无盈利 → 考虑退出
- 持仓 60 天未达目标 → 强制退出

**原因**：资金效率低下、机会成本高、初期判断可能错误。时间止损尤其适合波段与中短线系统。

### 4. 移动止损（吊灯止损）

随盈利推进逐步上移止损，实现「让利润奔跑」：

| 盈利区间 | 止损位置 |
|----------|----------|
| 盈利 < 5% | 保本价（入场价） |
| 盈利 5–10% | 成本 + 3% |
| 盈利 10–20% | 成本 + 5% |
| 盈利 > 20% | 最高价 − 10% |

移动止损把「保护利润」自动化：行情继续涨，止损跟着上移；行情回撤到止损线，机械离场。

## 止损位与风报比

止损位决定了风险敞口，入场前必须验证风报比：`风报比 = (目标价 − 入场价) / (入场价 − 止损价)`。

| 风报比 | 评级 | 建议 |
|--------|------|------|
| > 1:3 | 优秀 | 强烈推荐 |
| 1:2 – 1:3 | 良好 | 推荐 |
| 1:1.5 – 1:2 | 一般 | 可接受 |
| < 1:1.5 | 较差 | 不推荐 |

**最低要求**：风报比 ≥ 1:2 且胜率 ≥ 50%。

## 实战示例

标的现价 ¥35.50，支撑位 ¥33.00：

1. 技术位止损：¥33.00 × 0.98 ≈ ¥32.34（支撑下方 2%）
2. 固定止损：-7% → ¥33.02
3. 取更严者：¥33.00 附近
4. 风报比验证：目标 ¥40.00，风险 7%，收益 12.7%，风报比 1:1.8 达标
5. 结合仓位管理：单笔风险 2%，止损距离 7%，仓位 ≈ 28.6%

## 常见误区

1. **止损后立即买回**：止损是「这单判断错误」的证据，立即买回等于否定自己的系统。
2. **向下移动止损**：只有向上移动（保护利润），绝不能因为「快到了」而放宽。
3. **止损位设在整数关口**：整数位恰好是市场博弈密集区，容易被扫损，止损应略低于关键结构位。
4. **止损过近（噪音触发）**：止损应设在「判断失效」的位置，而非「正常波动」的位置，否则会被频繁扫出局。
